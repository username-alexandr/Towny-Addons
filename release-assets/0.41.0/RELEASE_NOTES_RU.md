# NeverLand Towny Suite 0.41.0 — Folia

Миграция всех 40 аддонов на планировщики Folia. Опубликованы те же проверенные JAR и архивы, которые подготовлены для ручного тестирования.

- Операции с игроками и сущностями выполняются в их потоках; изменения мира учитывают владение регионом.
- Общие реестры защищены от конкурентного доступа. Банковские наблюдатели и аудит отделены от общего монитора.
- Административное отключение замораживает зависимые модули и закрывает хранилища; время отключения не считается провалом.
- Команды наград сохраняются в устойчивой очереди. Неоднозначные результаты доступны администратору через `/nltadmin` и `/nltoutbox`.

## Скачать

- **NeverLandTownySuite-0.41.0-plugins.zip** — готовые JAR, инструкция, контрольные суммы и краткий отчёт.
- **NeverLandTownySuite-0.41.0-full.zip** — исходники, модели, готовые JAR и документация.
- **NeverLandTownySuite-0.41.0-sources.zip** — исходники и сборочные инструменты.

JAR также приложены отдельно. SHA256SUMS.txt содержит контрольные суммы вложений.

## Проверено

40 модулей собраны; пройдены 128 исполняемых Java-тестов, 41 контракт API, 7 проверок отказов хранилища и 9 Python-тестов. На Folia 26.2 build 7 / Java 25.0.2 пройдены 111 серверных проверок, проваленных проверок нет. Все опубликованные JAR совпадают по SHA-256 с файлами серверного теста.

Источники результатов: [отчёт проверок](https://github.com/username-alexandr/Towny-Addons/blob/v0.41.0/docs/FOLIA_VALIDATION.md), [машиночитаемый отчёт](https://github.com/username-alexandr/Towny-Addons/blob/v0.41.0/docs/FOLIA_VALIDATION.json), [журнал пробника](https://github.com/username-alexandr/Towny-Addons/blob/v0.41.0/docs/FOLIA_NATIVE_PROBE.txt).

## Установка и ограничения

Остановите сервер, сделайте резервную копию и замените прежние JAR, сохранив конфигурации и игровые данные. Среда проверки: Folia 26.2, Java 25, Towny 0.103.2.0. Подключённые провайдеры и расширения также должны поддерживать Folia.

Серверный тест выполнен без игроков и реального экономического провайдера. Полное прохождение игровых сценариев и нагрузочная проверка не выполнялись.

В Ideologies списание через `COMMAND` из регионального потока Folia блокируется до списания. Используйте `TOWN_BANK`, `PLAYER_VAULT` с совместимым провайдером или `ITEM`. Строительство и лагеря требуют загруженного участка с подходящим владельцем региона. Неоднозначные команды наград REVIEW требуют сверки перед ручным повтором.
