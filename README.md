# NeverLand Towny Addons

Монорепозиторий аддонов Towny для проекта NeverLand. Релиз `0.22.0` объединяет исходники и готовые JAR-файлы 27 модулей.

В 0.22.0 усилена надёжность городской лавки: сохраняемые платежи и выдача покупок, общие контракты API, диагностика интеграций и записи, строгая загрузка Archaeology и единый запуск всех исполняемых тестов. См. [обновление](docs/UPDATE_0.22.0_RU.md).

## Совместимость

- Paper/Purpur `26.2`
- Towny `0.103.2.0`
- Java `25` на сервере
- целевой bytecode Java `17`
- ItemsAdder и PlaceholderAPI подключаются опционально там, где они поддерживаются; vanilla-функции работают без ItemsAdder, настроенные кастомные существа и предметы требуют соответствующего плагина

## Структура

- `modules/` — исходный код каждого аддона;
- `shared/treasury/` — бюджетные платежи и классификация денежных операций в шести аддонах и Treasury+;
- `shared/policies/` — правила производства, содержания, торговли, сборов и армии в семи модулях;
- `shared/specialization/` — проверка направления и бонусы в 11 модулях;
- `shared/research/` — бонусы исследований в Builds, Resources, Population, Logistics, Trade и Research;
- `shared/upkeep/` — проверка обслуживания и питания в Builds, Resources, Districts, Logistics, Events и Power;
- `shared/districts/` — интеграция бонусов районов, включаемая в Builds, Population, Resources и Power;
- `shared/localization/` — общий русский словарь, включаемый в JAR семи модулей;
- `dist/plugins/` — проверенные готовые JAR-файлы;
- `assets/models/` — исходный пакет 37 импортированных моделей, встроенных в NeverLandTownyBuilds;
- `docs/` — команды, миграция и отчёт о тестировании;
- `scripts/` — проверка состава релиза;
- `.github/workflows/` — CI и автоматическая публикация GitHub Release.

## Установка

1. Установите совместимые версии Paper/Purpur, Towny и Java.
2. Скопируйте необходимые JAR-файлы из `dist/plugins/` в каталог `plugins/` сервера.
3. Установите обязательные зависимости, перечисленные в `plugin.yml` выбранного аддона.
4. Перезапустите сервер и настройте созданные конфигурационные файлы.

Перед обновлением рабочего сервера сделайте резервную копию мира, базы Towny и каталогов конфигурации аддонов.

## Сборка

Модули с `build.gradle.kts` собираются Gradle, остальные — Maven. Собирайте их внутри полного дерева репозитория: части модулей требуется соседний каталог `shared/localization/`. Builds, Population, Resources и Power также используют `shared/districts/`. Отдельный плагин для этих общих классов устанавливать не нужно. CI выполняет сборку на Java 25 и запускает статическую проверку релизной матрицы:

```bash
python3 scripts/verify_release.py
```

Готовые файлы публикуются в разделе Releases вместе с SHA-256 контрольными суммами.
