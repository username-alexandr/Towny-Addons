# CraftoUI Folia 0.9.15 — выбор участка с территории города

Патч `claim-map.patch` применяется к исходникам CraftoUI 0.9.16 (клиент) + 0.9.14 (сервер) и требует NeverLandTownyStick 0.2.4. Он меняет только сервер: кнопка свободного соседнего участка открывает карту Stick с уже выбранным участком. Клиент Fabric 0.9.16 остаётся совместимым.

Кнопка показывает причину, если игрок стоит вне своего города, участок не граничит с городом, достигнут лимит или отсутствуют права. Stick и Towny повторно проверяют границы, полномочия, смету и платёж при создании и исполнении плана.

Исходный архив: `CraftoUI-0.9.16-Source-and-JARs.zip`. Применение: из корня исходников `patch -p1 < claim-map.patch`; затем собрать серверный JAR и проверить действие в игре на Folia 26.2. Не заменять исходный клиентский JAR.
