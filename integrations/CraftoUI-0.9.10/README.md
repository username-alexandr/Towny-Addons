# CraftoUI 0.9.10

Дерево зданий и исследований открывается кнопкой в «Мой город» и «Развитие города». Ближайшие закрытые ветви видны с условиями; если Research временно недоступен, здания остаются на экране. Обновление сохранённых меню добавляет кнопку, не сбрасывая остальные настройки.

**Обновить клиентский и серверный JAR; для дерева зданий нужен NeverLandTownyBuilds 0.11.5. Loader оставить 0.19.4, Java 25.** Мод опционален.

[Установка и проверка дерева](docs/UPDATE-0.9.10.md). [Изменения 0.9.9](docs/UPDATE-0.9.9.md).

Исходники, конфигурации и Gradle Wrapper находятся здесь; проверенные JAR выпускаются отдельно в CI. Полный игровой прогон с Towny/Vault ещё не выполнен.
