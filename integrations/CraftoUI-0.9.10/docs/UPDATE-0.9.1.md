# CraftoUI 0.9.1 — кнопки и создание города

## Что изменено

- «Где ловить рыбу» перенесено из сетки заказов в нижнюю строку, после «Мои заказы» и «Лимит наград». Кнопка доступна на каждой странице. При нажатии вызывается исходное действие Contracts, показывающее состояние рыбалки рядом с игроком; инструкции сохраняются в подсказке.
- В главном административном окне скрыта лишняя карточка-заголовок «Управление сервером» с незерской звездой. Это проверенный неактивный слот 4 AdminMenu$Screen; разделы управления остаются доступными.
- В главном меню появился пункт «Создать город» для игроков, которые ещё не состоят в городе. Он открывает сразу поле названия. После проверки и подтверждения сервер вызывает собственную команду Towny `town new <название>` от имени игрока.
- Если Towny требует оплату, его настоящее подтверждение со стоимостью показывается в том же меню. CraftoUI не задаёт цену и не списывает средства самостоятельно. При подтверждении используются исходный запрос и транзакция Towny; «Назад» отменяет именно этот запрос. Проверяются текущие права, принадлежность к городу, владелец команды, сессия и актуальность подтверждения. Повторный пакет не повторяет оплату.
- Штатные проверки Towny определяют допустимость названия, мира, текущего места, расстояния до других городов, достаточность денег и ограничения сервера.

## Установка

Заменить обе части CraftoUI на `CraftoUI-Fabric-26.2-0.9.1.jar` и `CraftoUI-Folia-26.2-0.9.1.jar`, оставив по одному JAR. Minecraft 26.2, Java 25, Fabric Loader **0.19.4**. Мод опциональный. Проверка запуска выполнена с Fabric API 0.161.0+26.2 и вложенной MixinExtras 0.5.5.

В Pterodactyl штатно остановить сервер перед заменой плагина. В GML заменить клиентский JAR в профиле и обновить файловый манифест средствами вашей панели. Папку plugins/CraftoUI/ сохранить. Обновление стандартных main.json, hub.json и command-ui.json выполняется автоматически с резервной копией в backups/0.9.0/. Для обычного игрока нужны `craftoui.use`, `craftoui.commands`, `towny.command.town.new`; Towny должен быть включён.

Если главное меню сильно изменено вручную, добавить кнопку с `action: "ui:create-town"` и `requiresNoTown: true` по примеру из config/menus/hub.json. Для изменённого списка команд есть форма Towny/create-town в config/command-ui.json. Исключённые администратором модули и формы не включаются принудительно.

Путь игрока: главное меню → Создать город → ввести название без пробелов → Проверить действие → Подтвердить → при платном создании подтвердить условия Towny. Результат исходного обработчика появится в интерфейсе и чате. Участок выбирается текущим положением игрока в момент отправки команды Towny.

API JAR нужен разработчикам интеграций; отдельно устанавливать его в plugins/ не требуется. В полном архиве есть исходники, API, Gradle Wrapper, конфиги, темы и протокол. Общие инструкции планировщика и остальных интеграций: UPDATE-0.9.0.md.

## Реально пройденные проверки

- Gradle Wrapper 9.5.1, JDK 25.0.2: собраны настоящие клиентский, серверный и API JAR.
- JUnit: 91 common + 218 server = **309**, без ошибок и пропусков. Включены новая форма, кириллица в названии, недопустимые аргументы, условия видимости/прав и идемпотентная миграция главного меню.
- Нижняя панель: **964** проверки, 90 PNG. На разных размерах GUI и в двух темах проверено отсутствие рыбалки среди карточек, наличие трёх кнопок на обеих страницах и вызов настоящего raw-slot 47 при клике. «Мои заказы» остаётся raw-slot 45, лимит наград — безопасным информационным окном.
- Стандартные меню: **1208** проверок, 128 PNG. Панели/формы: проверены прямое открытие формы, передача названия с действующим токеном сессии, подтверждение Towny, защита от повторного клика и отмена через Назад; сценарии на логическом GUI до 320×180. PNG и журналы содержат синтетические данные и явные игровые/сетевые адаптеры.
- По неизменённым JAR Suite 0.52.1: **196** контрактных проверок владельцев, классов и команд и **61** проверка реальных API Builds/Contracts. Команда и право создания города сверены по исходникам Towny; ссылки и SHA исходных файлов сохранены в town-creation-source.json.
- Реальный Fabric/Knot bootstrap: Loader 0.19.4, CraftoUI 0.9.1, MixinExtras 0.5.5; ContainerEventHandler успешно трансформирован до открытия окна игры.

Текущая проверка: validation/0.9.1/. Исторические результаты предыдущего выпуска хранятся отдельно и не считаются повторным прогоном.

## Ограничения

Полный графический клиент и живой Folia не запускались. Создание реального города, списание через ваш Vault и полный сетевой сценарий игрока в этом прогоне не проверялись. Стоимость и ответы не имитируются в рабочих JAR: они поступают от оригинального Towny. Наличие кнопки не гарантирует, что сервер разрешит основать город в выбранном месте.

Для визуальных тестов используются рендереры проекта с AWT и явными платформенными адаптерами; это не скриншоты запущенного Minecraft. Целевой комплект аддонов Suite 0.52.1 сохраняет статус playtest.
