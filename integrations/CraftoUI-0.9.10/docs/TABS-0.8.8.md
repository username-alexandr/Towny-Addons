# CraftoUI Fabric 0.8.8 — остальные вкладки

Обновлено оформление похожих экранов, которые ещё использовали одинаковые длинные кнопки и не помещались при большом GUI Scale. Новая версия продолжает дизайн 0.8.7.

## Проверенные разделы и изменения

| Раздел | Изменение |
|---|---|
| Поиск и избранное | Компактные карточки, отдельное закрепление, выделенная вкладка, понятное пустое состояние. До четырёх столбцов на широком окне; число уменьшается вместе с доступной шириной. |
| Панель контрактов | Карточки с конкретной целью и прогрессом, отметка «На панели», отдельные стрелки порядка. Настройки раскрываются по кнопке; режим выбора, размер, строки, уведомления и позиция сохранены. |
| Сводка | События в отдельных блоках; готовые награды выделены. «События города» открывает историю города; сервер продолжает проверять доступ. |
| Старый экран сведений города | Сведения разбиты на показатели, стройки, материалы, задания и выплаты. Это резервный экран для прежней интеграции; современная сводка города остаётся отдельной. |
| Настройки | Разделы «Оформление» и «Панель контрактов», пояснения и видимые текущие значения. |
| Действия аддонов | Карточки разделов и действий, этапы «Разделы → Параметры → Подтверждение», серверные варианты ввода, заметная основная кнопка, отдельный результат. |
| Карта участков | Общие вкладки и нижняя навигация, прокручиваемая карта. На маленьком окне пояснение цветов перенесено ниже карты. Участки и кнопки отправляют прежние серверные идентификаторы. |
| Подбор и список заказов | Общие вкладки и прокрутка; маленькое окно больше не отбрасывает карточки ниже видимой области. Предметы, названия/цвета редкости и флаг зачарованного блеска сохранены. |
| Позиция HUD | Кнопки положения и заголовок согласованы с темой; перетаскивание и сохранение координат сохранены. |

Проверены также MenuScreen и AddonScreen: это отдельные конфигурационные/инвентарные раскладки с карточками, предметами, рынком и превью построек. В этом выпуске их содержимое и геометрия не переписывались. Личные `/orders` по-прежнему открываются через исходный серверный маршрут, а подборщик не добавлен в городскую навигацию.

## Поведение

Область содержимого прокручивается отдельно от заголовка, вкладок и нижней навигации. Клавиатурный фокус прокручивает выбранный элемент в область просмотра; элементы вне неё не перекрывают нижние кнопки. На особенно низком логическом разрешении длинную карточку приходится прокручивать частями.

При обновлении списка и серверных подсказок сохраняются текст и позиция курсора. Старые подсказки другого поля/запроса отбрасываются. Подтверждение отправляет только билет сервера и блокирует повторное выполнение. Возврат из подтверждения отменяет билет. Исправление переходов между кадром и тиком из 0.8.6 сохранено.

Формы остаются универсальными: меню передаёт поля и идентификаторы существующему серверному обработчику. Права, правила приглашений/должностей и выполнение команд определяет сервер. Интеграции и протокол не изменены; клиент остаётся необязательным.

## Установка

Закройте Minecraft. Замените прежний CraftoUI Fabric JAR в `mods/` профиля GML на **CraftoUI-Fabric-26.2-0.8.8.jar**. Обновите файл распространяемого профиля и синхронизируйте лаунчер. Не оставляйте несколько CraftoUI JAR. Настройки и данные сохраняйте.

**Нужен только новый клиент. Сервер и API остаются 0.8.5**, перезапускать сервер для этого обновления не требуется. Minecraft 26.2, Java 25, Fabric Loader 0.19.4+, Fabric API 0.161.0+26.2.

## Реальные проверки и доказательства

- Fabric JAR скомпилирован с оригинальными библиотеками Minecraft 26.2 и Fabric, Java 25.0.2 / Gradle 9.0.0. Wrapper 9.5.1 включён, но здесь не запускался.
- **161 проверка новых вкладок**: 136 проверок границ нижней навигации (17 состояний × 2 темы × 4 размера) и 25 проверок поведения. Проверены поиск, избранное, закрепление и локальная прокрутка, настройки/возврат, сохранение ввода и курсора, устаревшие подсказки, поля и подготовка действия, однократное подтверждение, отмена, устаревшие кнопки, карта, карточки заказов, предмет легендарной редкости и флаг блеска, положение HUD, последовательный ввод и Backspace, отсутствие городской вкладки без членства.
- **95 проверок страниц 0.8.7 и 19 проверок жизненного цикла** повторно пройдены на текущих исходниках. Отдельный воспроизводитель прежнего вылета также успешно выполняет свои 19 сценариев; они не считаются дополнительными уникальными тестами.
- Получены **219 PNG**: 138 новых отрисовок и 81 повторная отрисовка городских страниц. Используются настоящие классы экранов/компонентов, AWT-адаптер и bitmap-шрифт оригинального Minecraft. Логические размеры: 871×447, 520×340, 320×240, 320×180; темы dark/classic. Выбранные широкие и узкие состояния просмотрены визуально.
- Gradle проверил задачи тестов common/server: **191 модульный тест (78 + 113)** имеет успешный сохранённый результат без ошибок и пропусков; эти неизменённые задачи в данном выпуске использовали `UP-TO-DATE`, а не новый прогон. XML включены с исходными временными отметками.
- Проверены `fabric.mod.json`, целостность ZIP, состав JAR без тестовых адаптеров и SHA-256. Серверный JAR побайтно совпадает с 0.8.5.

Доказательства: `validation/0.8.8/panel-tests.log`, `build-crash.log`, `lifecycle-0.8.8.log`, `summary.json`, `junit/`, `previews/`. Воспроизводимый инструмент: `tools/panel-preview/`.

## Ограничения

Полный графический Minecraft, настоящий ввод устройств, GML и сетевое подключение к Folia в этом прогоне не запускались. Примеры используют тестовые данные и явные двойники платформы/транспорта. Это предпросмотры из кода отрисовки, не снимки запущенной игры. Предметы в адаптере показываются оригинальными текстурами; настоящий GPU-эффект блеска не воспроизводится — проверяется его флаг в ItemStack. Геометрия самого HUD в тестах заменена двойником; его существующий рендер не изменялся. Серверные операции аддонов повторно на живом сервере не выполнялись. Собственные ресурс-паки и нестандартные шрифты отдельно не испытывались.
