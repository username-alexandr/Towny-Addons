# CraftoUI 0.9.6 — личные заказы и компактные действия

«Все действия»: поле поиска больше не перехватывает фокус сразу при открытии; подпись остаётся видимой до ввода. Карточки снова занимают до трёх колонок, описания переносятся на две строки, вертикальный промежуток между строками уменьшен. Нижние кнопки «Назад» и «Обновить» выровнены по одной строке с отступом от разделителя. Проверены общие координаты нижних кнопок для экранов меню, города, аддонов, настроек и позиционирования панели при разных размерах окна; в узком окне выбор положения панели перестраивается в два столбца.

В доске `/orders` кнопка «Мои заказы» теперь открывает собственный экран CraftoUI с актуальными личными заказами. Нажмите на конкретный заказ, затем «Сдать и получить награду» и подтвердите условия. Проверки предметов, прогресса, срока, прав и выплаты остаются у Contracts; интерфейс использует его публичные `uiSnapshot` и `uiExecute` с повторной проверкой данных. Из списка можно вернуться к доске через «Назад». Если аддон не предоставляет это API или UI недоступен, обычная кнопка аддона сохраняет прежнее поведение. Игроки без мода продолжают пользоваться `/orders mine` и чат-командами.

В главной шапке восстановлена иконка лупы рядом с «Поиск», в узком окне остаётся одна иконка. В справке исправлены подсказка внизу и путь к настройке панели контрактов. Справочные карточки не являются кнопками, поэтому прежняя фраза о подсказке при наведении была неверной. В настройках техническая строка про GUI Scale заменена понятным пояснением. При обновлении неизменённого `menus/help.yml` сохраняется резервная копия в `backups/0.9.5/menus/help.yml`; пользовательский файл не перезаписывается.

## Установка

Замените оба CraftoUI JAR версии 0.9.5 на 0.9.6 и перезапустите сервер и клиент. Не храните старые копии рядом. Minecraft/Folia 26.2, Java 25, Fabric Loader 0.19.4, Fabric API 0.161.0+26.2. Мод остаётся необязательным для подключения к серверу.

## Проверки и ограничения

`./gradlew release` собрал клиент, сервер и API, 322 модульных теста завершились без ошибок. Fabric Knot 0.19.4 / MixinExtras 0.5.5 загружен до открытия игрового окна; лог в `validation/0.9.6/bootstrap/bootstrap.log`. Полный Folia-сеанс, фактическую сдачу заказа на работающем сервере и визуальный рендер на клиентской видеокарте в этой среде провести нельзя. Для сдачи через UI нужен совместимый NeverLandTownyContracts с публичными `uiSnapshot` / `uiExecute` и доступ игрока к CraftoUI.
