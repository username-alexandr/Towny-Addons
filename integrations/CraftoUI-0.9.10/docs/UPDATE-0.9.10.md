# CraftoUI 0.9.10 — доступ к дереву развития

В 0.9.9 дерево было доступно только через кнопку на сводке города; стандартные разделы «Мой город» и «Развитие города» открывали обычные списки. Теперь в обоих разделах есть отдельная кнопка «Дерево развития». На старом сервере кнопка добавится в сохранённые меню при запуске, с резервными копиями в `plugins/CraftoUI/backups/0.9.10/menus/`. Остальные пользовательские кнопки и темы сохраняются. Если меню существенно переделано и в нём нет исходной сетки `modules`, добавьте кнопку с действием `ui:tree` вручную.

Новый город видит ратушу и ближайшие закрытые ветви с требованиями. Дальние ветви открываются по мере строительства. Исследования показываются после необходимых научных зданий; пустая вкладка объясняет, почему их пока нет. Если Research отключён или его данные не прочитались, дерево зданий остаётся доступным.

Установка: на остановленном сервере замените `CraftoUI-Folia-26.2-0.9.9.jar` на `CraftoUI-Folia-26.2-0.9.10.jar`; в клиентском профиле замените `CraftoUI-Fabric-26.2-0.9.9.jar` на `0.9.10`. Не держите две версии одного плагина в `plugins/` или две версии мода в `mods/`. Не перезаписывайте свои конфиги. Нужны NeverLandTownyBuilds 0.11.5, Folia/Minecraft 26.2, Java 25, Fabric Loader 0.19.4 и Fabric API 0.161.0+26.2. Клиентский мод по-прежнему необязателен для входа.

Проверка: открыть `Мой город → Дерево развития` или `Мой город → Развитие города → Дерево зданий и исследований`. Проверить вкладки «Здания» и «Исследования», подсказки ближайших ветвей, затем перезагрузить сервер и убедиться, что кнопка не продублировалась. При ошибке каталога посмотреть состояние Builds и файл `plugins/NeverLandTownyBuilds/projects.yml`; для исследований — состояние Research и `technologies.yml`. Живой тест этих действий с игроком на Folia не заменяется модульными тестами.
