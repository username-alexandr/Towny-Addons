# CraftoUI 0.9.4 — понятные разделы и команды

## Что исправлено

- Ответ на нажатие кнопки привязан к конкретному запросу. Запоздавший ответ «Город» больше не открывается после нажатия «Настройки». Сервер указывает назначение только для видимых кнопок, клиент дополнительно сверяет ответ с последним нажатием.
- «Жители и власть» доступны через «Главное меню → Мой город». Личная история операций остаётся в «Работа и торговля». Повторяющиеся ссылки удаляются из новых и установленных меню. Перед изменением установленного JSON создаётся резервная копия в `plugins/CraftoUI/backups/0.9.3/`.
- В «Все действия» кнопки получают русские названия и короткое описание необходимых данных. Точное имя команды и шаблон параметров показываются при наведении. Когда поля заполнены, подсказка на кнопке проверки показывает сформированную команду, а на кнопке подтверждения — окончательный вызов. Проверки прав и выполнение остаются на сервере.
- Для корневых команд установленного аддона используется описание из зарегистрированной команды Bukkit. Технические названия аддонов и строки `/root ...` больше не выводятся как подписи карточек. Для административных команд и Towny предусмотрены отдельные понятные заголовки. Новые команды аддона подхватываются автоматически как действия его раздела; специфичные формы можно добавлять в `command-ui.json`.

## Установка

Замените оба CraftoUI JAR на 0.9.4, оставив на сервере один Folia JAR, а у клиента — один Fabric JAR. Перезапустите сервер и клиент. Требования: Minecraft/Folia 26.2, Java 25, Fabric Loader 0.19.4 и Fabric API 0.161.0+26.2. Клиентский мод по-прежнему необязателен для подключения. Аддоны Suite можно обновлять независимо; подписи команд используют их актуальные описания.

## Проверки и ограничения

Проект собран через Gradle Wrapper на исходных Minecraft 26.2, Paper API и Fabric Loader. Модульные тесты и отдельный запуск Knot до открытия игрового окна приведены в `validation/0.9.4/`. Полный Folia-сеанс с пользовательскими данными и реальными правами игроков здесь не запускался. Если собственная конфигурация намеренно использовала удалённую дублирующую кнопку, при запуске она будет сохранена в резервной копии. Остальные пользовательские поля конфигурации остаются нетронутыми.
