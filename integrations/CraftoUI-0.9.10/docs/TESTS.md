**15 базовых сценариев** — [smoke-results.json](../validation/reports/smoke-results.json): отсутствие обязательного мода, команда status без него, согласование протокола, реальные имя/UUID, исключение серверных действий/прав из схемы, запрет недоступной кнопки, поддельная сессия, открытие профиля, refresh, повтор sequence, неизвестный компонент, повреждённый кадр без разрыва игры, действие закрытой сессии, неправильный путь вместо ID, несовместимая версия без отключения игрока.

**10 API-сценариев** — [api-smoke-results.json](../validation/reports/api-smoke-results.json): запрет/выдача/отзыв права экрана, регистрация меню отдельным плагином, асинхронный provider со снимком данных, действие на потоке игрока с проверкой `Bukkit.isOwnedByCurrentRegion`, повторная проверка отозванного права при клике, успешный reload, сохранение предыдущего каталога при испорченном JSON, очистка обновлений сессии при отказе согласования.

**7 сценариев моста** — [native-smoke-results.json](../validation/reports/native-smoke-results.json):

1. WELCOME выбирает новый `hub`.
2. Hub и четыре пользовательские категории открываются из конфигов.
3. Разрешённый holder получает подсказку карточного оформления с настоящим заголовком и размером.
4. Holder склада получает начальный режим сетки.
5. Такой же заголовок с неразрешённым holder не перехватывается.
6. Клиент без `native-menus-v1` оставляет обычный инвентарь и не получает сообщение 8.
7. Подключение без мода открывает исходный инвентарь и не получает UI payload.
