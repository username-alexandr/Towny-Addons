# CraftoUI 0.7.0 — город, заказы и совместные цели

Обновить клиент и сервер до 0.7.0. Для новых интеграционных методов установить прилагаемые **Builds 0.8.29**, **Contracts 0.3.23**, **Companies 0.1.15**. Основа этих аддонов — исходники Towny-Addons `release/v0.42.0`, commit `2aec261f6c488c1856ef0c17d4d6ff448ef7dfdc`. Изменения аддонов: [исходники на GitHub](https://github.com/username-alexandr/Towny-Addons/tree/codex/craftoui-0.7.0-integrations), commit `8cd6f545f0259b58a6f4a3ec2df83aa2b167baa9`. TreasuryPlus 0.1.16 не изменён. Towny проверяется на 0.103.2.0.

## Что добавлено

- Кнопка «Город» открывает связанные страницы: город, материалы, входящие, карта, общая цель, заказы. Стройки открывают настоящий экран соответствующего проекта; контракты — собственные условия и действия; казна — журнал TreasuryPlus.
- Материалы подсчитываются по реальному чертежу и блокам в загруженных регионах. Показаны остаток установки, городской склад, инвентарь игрока и необходимое пополнение. Открытый склад не принимается за достоверный снимок.
- В Builds материал после установки возвращается. Поэтому для физической установки нужен один подходящий предмет каждого типа. Оплата фонда запуска/улучшения остаётся отдельной операцией аддона. Замена DEEPSLATE_TILES → COBBLED_DEEPSLATE_SLAB берётся из публичного ConstructionSupply.
- Входящие показывают только собственные действующие приглашения. Компании получили команду `/company decline <UUID>`. Принятие и отклонение вызывают настоящие обработчики аддонов. Для Companies используется публичный uiJoin после явного подтверждения в CraftoUI; повторная команда /company confirm не требуется. Изменение городских рангов и должности в компании вызывает небольшое уведомление.
- Карта показывает 9×9 участков с перемещением по соседним областям, цветом принадлежности, владельцем и границами в блоках. Размер участка берётся из Towny. Изменять выбранный участок можно, стоя на нём. Покупка группы участков проходит через исходные действия Towny, где видна цена всей группы.
- Мэр или игрок с `craftoui.goals.manage` закрепляет одну общую цель своего города: действующую стройку либо городской контракт. У контрактов личный вклад берётся из их журнала; у стройки считаются сохранившиеся блоки, поставленные после закрепления. Старые блоки никому не приписываются. Снятие закрепления не удаляет стройку и ресурсы.
- `/orders` и кнопка заказов открывают новую доску при согласованном `civic-v1`. Источник — текущая суточная доска аддона, а не полный каталог шаблонов. Фильтры: тип, редкость, минимальная награда, порядок, наличие предметов. Предметы в инвентаре помогают выполнить только поставку; добыча, охота и рыбалка требуют игровых действий.
- Перед принятием, сдачей, отменой заказа и действиями с участком показываются последствия. Подтверждения одноразовые, на 30 секунд. Клиент не передаёт команды, стоимость или UUID цели вместо серверного выбора. У заказов снимок повторно сверяется под тем же монитором, что и изменение. Динамические подтверждения Towny доступны отдельной карточкой с исходным текстом и проверками Towny.

## Обновление

1. Остановить сервер и сохранить резервную копию `plugins/` с данными аддонов.
2. Заменить старые JAR CraftoUI, Builds, Contracts и Companies. Не оставлять рядом два JAR одного плагина. Существующие конфигурации и данные не удалять.
3. Запустить Folia 26.2 на Java 25. Для клиента использовать Minecraft 26.2, Fabric Loader **0.19.4 или новее**, Fabric API 0.161.0+26.2.
4. В профиле GML/Crafto Launcher заменить клиентский JAR в распространяемой папке `mods`. Серверные JAR туда не помещать. Новых обязательных клиентских зависимостей нет.
5. В Pterodactyl выбрать Java 25, загрузить серверные JAR в `plugins`, затем перезапустить. `/craftoui reload` перезагружает конфигурацию меню, но не заменяет Java-классы установленного плагина.
6. Открыть главное меню клавишей M либо `/menu`, выбрать раздел города; быстрый доступ — K. Заказы доступны через `/orders`.

**Файлы:** клиентский JAR — в `mods`; Folia JAR и три JAR из `release/addons` — в `plugins`. `CraftoUI-API-0.7.0.jar` предназначен разработчикам; его не нужно помещать в `mods` или `plugins`.

Игрок без мода продолжает пользоваться исходными командами и инвентарными меню. Мод на сервере без CraftoUI не требует установки плагина для подключения. Наличие новых страниц согласуется отдельной возможностью протокола; старый клиент не получает неизвестный тип пакета.

## Данные и ограничения

- `plugins/CraftoUI/civic-state.json`: общая цель, принадлежность учтённых блоков, последняя известная должность. Записывается атомарно; повреждённый файл не перезаписывается автоматически. Перед переносом сохранить вместе с остальными данными.
- Файловые снимки аддонов обновляются с кэшем до 8 секунд; после принятия/отклонения приглашения компании кэш сбрасывается. Уведомления проверяются не чаще одного раза за 8–10 секунд на подключённого клиента. Перед изменением права и условия проверяются заново.
- Незагруженные чанки не загружаются принудительно ради интерфейса. За проход проверяется максимум 256 блоков одного чанка, с бюджетом 2 мс между чтениями; продолжение переносится на следующий тик своего региона. Просроченные задачи прекращаются. Неполный подсчёт обозначается явно. Доска заказов и приглашения не запускают сканирование построек.
- История TreasuryPlus содержит только переданные ему операции бюджета. Это не обещание полного банковского журнала всех плагинов сервера.
- Установленные до закрепления блоки не дают личного вклада. Вклад отражает текущее наличие подходящих блоков, а не число повторных установок. Обновления блоков внешними редакторами мира, которые обходят Bukkit-события, требуют отдельной интеграции для точной атрибуции.
- Общая цель — организационный приоритет; сама по себе она не создаёт новый платёж, награду или склад.
- Экран не выполняет произвольные клиентские команды и не обходит собственные ограничения Towny/аддонов. Если аддон отключён или не предоставил данные, выводится причина.
- Остальные формы аддонов и существующие инвентарные меню сохраняют их собственные подтверждения. Точная стоимость неизвестного стороннего действия не вычисляется по тексту кнопки.

Реально выполненные проверки и ограничения испытательного стенда перечислены отдельно в `TESTS-0.7.0.md`.
