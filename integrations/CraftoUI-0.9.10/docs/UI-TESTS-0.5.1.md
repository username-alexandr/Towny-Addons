# Проверки CraftoUI 0.5.1

## Сборка и автоматические тесты

Сборка Java 25 / Gradle 9.5.1 завершилась успешно. Клиент компилировался против оригинального необфусцированного Minecraft 26.2 через `directMinecraft`, с Fabric Loader 0.19.4 и Fabric API 0.161.0+26.2. Сервер использует Paper API 26.2.build.121-stable, Folia-совместимые планировщики сохранены.

67 тестов, 0 ошибок, 0 пропусков: common 29, server 38. XML и сводка: `validation/ui-0.5.1/junit/`, `unit-tests.json`. Новые проверки покрывают адаптивную геометрию на 320×240, 427×300, 640×360, 640×450, 400×700, 1920×1080 GUI-единиц при масштабах .75, 1, 1.25; уменьшение колонок; сохранение пользовательских меню и резервных копий; повторную миграцию и CRLF; совместимость настройки рынка со старыми конфигами.

Проверены ZIP CRC каждого JAR, настоящие `.class`, версия 0.5.1 в fabric.mod.json / plugin.yml, минимальный Loader 0.19.4, folia-supported: true. Полный журнал: `validation/ui-0.5.1/build.log`.

## Границы проверки

При этом прогоне не проверялись денежные покупки, возврат денег, получение наград и все ветви всех 38 аддонов. Каталог и пустой рынок проверены, новое активное предложение с реальным резервом склада в этом прогоне не создавалось. В тестовом стенде не установлен провайдер Vault.

Подключение vanilla без мода и Fabric без серверного CraftoUI было проверено в 0.5.0; результаты сохранены в `validation/upgrade-0.5.0`. В 0.5.1 эти сетевые обработчики не изменялись, но новая ручная проверка этих двух комбинаций не проводилась. Не следует считать старые журналы новым прогоном.

В изолированной среде отмечены ошибки недоступных Mojang/Realms endpoints, отсутствующего аудиоустройства и курсора X11; они не являются падением CraftoUI. Автоматическая проверка прервала дополнительный запуск из-за bStats-телеметрии зависимостей; перед повторным запуском она отключена в тестовом `plugins/bStats/config.yml`, в стенд добавлена обязательная проверка `enabled: false`. Сам CraftoUI bStats не использует.

Повторный стенд с отключённой телеметрией завершился штатно (`Harness stopped cleanly`). На нём проверены настройки и `/orders`. Запуск с bStats больше не требуется.
