# CraftoUI 0.8.11 — требования к загрузчику NLT

Клиент собран с Fabric Loader 0.19.5 и объявляет его минимальной версией. Версия клиента увеличена до 0.8.11. Minecraft остаётся 26.2, Java — 25, Fabric API — 0.161.0+26.2. Сервер CraftoUI и API остаются 0.8.5. Исходники меню и сетевой протокол не изменены.

## Почему необходимо обновить загрузчик

В предоставленном `latest(3).log` загружены CraftoUI 0.8.10, Loader 0.19.4, MixinExtras 0.5.4 и Fabric Mixin 0.17.4. Падение происходит в `FactoryRedirectWrapperMixinTransformer.transform` при преобразовании `ContainerEventHandler`: список значений аннотации приводится к `AnnotationNode`.

Разработчик MixinExtras описывает исправление несовместимости `@Redirect`, скомпилированных с Fabric Mixin 0.17.4, в версии 0.5.5. Fabric Loader 0.19.5 включает MixinExtras 0.5.5. Это соответствует стеку ошибки; конкретный мод с такой аннотацией журнал не называет. У CraftoUI нет собственных mixin-конфигураций, и он не включает MixinExtras внутрь своего JAR.

Официальные источники:

- https://github.com/LlamaLad7/MixinExtras/releases/tag/0.5.5
- https://github.com/FabricMC/fabric-loader/releases/tag/0.19.5

Обновление CraftoUI само по себе **не обновляет Fabric Loader**. Новое ограничение версии позволяет Fabric сообщить о старом загрузчике при проверке зависимостей. Исправленный код MixinExtras поставляется с загрузчиком.

## Обновление профиля NLT в Crafto Launcher / GML

1. Закрыть игру. Сохранить текущую конфигурацию профиля NLT для отката.
2. В серверной конфигурации **клиентского профиля NLT** установить Fabric Loader **0.19.5**, оставив Minecraft **26.2** и Java **25**. Это настройка лаунчера, а не Folia-плагина.
3. Пересобрать/обновить профиль штатным средством установленной версии GML, чтобы обновились библиотеки загрузчика и его описание запуска. Простое добавление Loader JAR в `mods/` не подходит. Не подменять только номер версии в старом описании, сохраняя старые библиотеки.
4. При установке этого выпуска заменить прежний клиентский CraftoUI JAR на `CraftoUI-Fabric-26.2-0.8.11.jar` в `mods/`. Оставить одну версию CraftoUI. Отдельный MixinExtras JAR устанавливать не требуется.
5. Синхронизировать/опубликовать обновлённый профиль NLT средствами панели. Получить его через лаунчер на одном тестовом клиенте, затем проверить обычный повторный запуск. Пользовательские `options.txt` и `config/craftoui.json` сохранять.
6. В свежем `latest.log` проверить `fabricloader 0.19.5`, `mixinextras 0.5.5`, `craftoui 0.8.11`. Проверить появление главного экрана Minecraft, подключение и открытие меню.

Для устранения именно этой ошибки CraftoUI 0.8.10 также можно оставить: критическое изменение — Loader 0.19.5. Выпуск 0.8.11 фиксирует корректное требование в самом моде и актуализирует инструкции.

Названия полей панели зависят от версии GML. Конфигурация и доступ к действующей панели NLT не предоставлены; этот выпуск не означает, что профиль уже изменён или опубликован у игроков. Параметры и порядок обновления подготовлены для применения администратором.

## Сервер и игроки без мода

Folia-плагин 0.8.5 не заменяется. Проверки наличия мода, разрешения и возможность входа без CraftoUI не изменены. Требование Loader относится только к клиенту, который устанавливает CraftoUI.

## Проверки

Выполнено для 0.8.11:

- Реальная сборка `:client:build :common:test` на Java 25.0.2 / Gradle 9.0.0 с Minecraft 26.2, Fabric API 0.161.0+26.2 и Loader 0.19.5: `BUILD SUCCESSFUL`. Задача `common:test` была `UP-TO-DATE`; прежние тесты не запускались повторно.
- Проверены контрольные суммы официальных библиотек. Из настоящих JAR загрузчика извлечены MixinExtras 0.5.4 (Loader 0.19.4) и 0.5.5 (Loader 0.19.5).
- Настоящий `@Redirect` скомпилирован против Fabric Mixin 0.17.4. Прямой вызов исходного преобразователя MixinExtras 0.5.4 воспроизводит `ClassCastException` на строке 18. На 0.5.5 та же аннотация проходит.
- На 0.5.5 проходят одиночные и массивные `@At`, обычный вызов, `NEW` и массив с несколькими точками. Одиночная старая форма проходит также на 0.5.4. Тест вызывает реальные библиотеки, но не запускает Minecraft.
- Настоящий Fabric `VersionPredicate` отклоняет 0.19.4 и принимает 0.19.5 для объявленного ограничения.
- Все записи нового клиентского JAR побайтно совпадают с 0.8.10, кроме `fabric.mod.json` (версия 0.8.11 и Loader ≥0.19.5). Проверены ZIP CRC, отсутствие встроенных тестов и MixinExtras. Серверный JAR сохранён побайтно.

Результаты текущей сборки и проверки артефактов находятся в `validation/0.8.11/`. Проверки UI предыдущих выпусков сохраняют исходные версии и не являются новым графическим прогоном.

Полная Windows-сборка NLT, графический запуск Minecraft и обновление реального профиля GML здесь не проверены. Если после обновления останется сбой, нужен свежий журнал запуска: старый журнал содержит только Loader 0.19.4.
