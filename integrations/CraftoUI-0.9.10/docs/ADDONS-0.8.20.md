# CraftoUI 0.8.20 — интеграция NeverLandTowny 0.51.0

Обновить клиентский мод и серверный плагин CraftoUI. Minecraft **26.2**, Java **25**, Fabric Loader **0.19.4**, Fabric API **0.161.0+26.2**, вложенный MixinExtras **0.5.5** сохранены. За основу взят CraftoUI 0.8.19 из актуального комплекта аддонов; изменения 0.8.18 и 0.8.19 сохранены.

Целевая версия аддонов — **NeverLandTowny 0.51.0**, коммит [`4022915`](https://github.com/username-alexandr/Towny-Addons/commit/4022915b64cc5578f875a7a977f989e07378e4f3). Проверены реальные JAR из `NeverLandTowny-0.51.0-Personal-Orders-and-Placement.zip`. Исходники и описание обновления: [Towny-Addons](https://github.com/username-alexandr/Towny-Addons/blob/4022915b64cc5578f875a7a977f989e07378e4f3/docs/UPDATE-0.51.0.md).

Добавлены **9 точных классов нативных окон** и **21 форма действия**. Для каждого сохранён исходный владелец команды/меню. Кнопки категорий не продублированы в главном меню; единственный новый пункт стандартной сетки — «Стиль города» в развитии. Остальные функции доступны в соответствующих аддонах и поиске. Неустановленный аддон не становится обязательной зависимостью.

Сохранены адаптивная сетка и страницы, темы, описания, исходные предметы редкости, Shift/правая кнопка, права, подтверждения и история возврата. Новые нативные окна используют существующий клиентский рендерер. Одноразовые окна стиля/часов при необходимости открываются заново через проверенную команду своего аддона; использованный объект меню не восстанавливается из кеша. «Назад», Esc и закрытие Civic из 0.8.18 сохранены.

## Исправления совместимости данных

Новые палитры Builds хранятся в полном идентификаторе архитектуры, например 1006/2006. Прежний UI принимал только базовые значения и сообщал, что такие стройки недоступны. Теперь базовую версию проверяет публичный `BuildingStyle.baseArchitecture` аддона, а генератор получает исходный сохранённый идентификатор. Прогресс, список недостающих материалов и вклад считаются по правильному плану. Неизвестный стиль или будущая базовая версия не заменяются средневековым планом. Старые площадки сохраняют прежнюю архитектуру.

Предпросмотр получает план через прежний публичный `buildingPreview(Player, Inventory)` Builds; его выбор стиля и серверные проверки сохранены. Даты в городской летописи показываются по Москве, как расписания аддонов.

Управление размещением сохранено из 0.8.19: **Shift + ПКМ чертежом или `/nltplace`** открывает меню. Стрелки и колесо не перехватываются для перемещения постройки. Большую строительную плашку мод не возвращает.

## Установка

1. Закрыть игру и штатно остановить Folia в Pterodactyl. Сохранить папки настроек/данных.
2. Заменить прежний CraftoUI в `plugins/` на `CraftoUI-Folia-26.2-0.8.20.jar`. Оставить один JAR плагина.
3. В профиле NLT лаунчера GML/Crafto заменить мод на `CraftoUI-Fabric-26.2-0.8.20.jar`. Loader оставить **0.19.4**; Fabric API оставить совместимый с 26.2. Не оставлять несколько версий CraftoUI.
4. Если комплект 0.51.0 уже установлен, другие JAR для этого обновления UI менять не нужно. Основные проверенные версии: Builds 0.9.1, Contracts 0.5.1, SiegesPlus 0.6.1, Companies/Chronicles 0.2.0. Обновление UI не устанавливает отсутствующие аддоны.
5. Существующую папку `plugins/CraftoUI/` сохранить. Стандартные файлы обновятся с резервной копией в `backups/0.8.19/`. Свои команды, подписи, темы и права сохраняются. Не нужно копировать примеры поверх рабочих конфигов.
6. Полностью запустить сервер и игру. Проверить стиль, личные заказы, материалы здания, зарплаты, вклад жителей и часы нападения. Возврат, Esc и обновление проверить после переходов между этими разделами. Bukkit `/reload` не использовать.

Для своего макета развития при необходимости добавить кнопку с `action: "quick:city-style"`; новый быстрый переход уже доступен в поиске. Намеренно исключённые модули/классы и ограничения корней команд миграция не включает заново. Свой обработчик с совпавшим ID формы не заменяется.

API JAR находится в `release/` полного архива и предназначен разработчикам; в `plugins/` его не устанавливать. Интерфейс API регистрации меню не менялся. Полная инструкция — [INSTALL.md](INSTALL.md).

## Ограничения

Полный графический Minecraft, пользовательская сборка NLT/GML и живой Folia в этом прогоне не запускались. Нативные платежи, рейд, создание города и выплаты компаний заново на сервере не выполнялись. UI проверен через явные адаптеры платформы, инвентаря и сети; это не скриншоты игрового подключения. Реальный API-прогон Builds не использует игрока/мир и не заменяет игровой тест прогресса стройки.

Суммы, владение городом/компанией, доступность материалов, защита от рейдов и результаты операций определяют аддоны. Дополнительная проверка CraftoUI не обходит их подтверждения и условия. На очень малом GUI большие списки занимают несколько страниц. Мод остаётся опциональным, механизм входа игроков без мода не изменялся.
