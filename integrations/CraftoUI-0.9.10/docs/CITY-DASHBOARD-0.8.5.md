# Экран города — CraftoUI 0.8.5

Новый экран открывается прежним способом: главное меню → «Мой город» → «Экран города». Для оформления установите **сервер и клиент 0.8.5**. Основа выпуска — 0.8.4; управление стройками, сдача материалов, личная история, предметная редкость и навигация аддонов сохранены.

## Что видит игрок

Вверху — название города, роль и четыре самостоятельных показателя: казна, жители, занятые участки, доступный лимит захвата. Большие суммы разделяются пробелами; безлимитный захват подписан словами. Недоступный баланс не подменяется нулём.

Действия разделены по смыслу:

- **Развитие города:** постройки, материалы, общая цель.
- **Управление и события:** карта участков, казна, история города, приглашения.

«Подбор заказов» убран из экрана города и верхней навигации городских страниц. Кнопка «Личные заказы» в главном меню и разделе заработка по-прежнему открывает настоящий `/orders`.

Ниже расположены три фильтра содержимого:

- **В работе:** активные стройки и городские контракты.
- **Здания:** строящиеся и завершённые здания. Улучшаемое здание показывается один раз.
- **Контракты:** только городские задания, сначала выполненные условия; рядом показан личный вклад.

Карточка показывает название, тип, числовой прогресс и полосу выполнения. По нажатию открываются прежние подробности и действия. Неизвестный прогресс имеет пояснение вместо фиктивных 0%. Завершённая постройка подписана «Построено». Полное название и пояснения доступны при наведении. Очень длинные строки ограничены для сетевого пакета; оригинальные записи аддона сохраняются.

## Размеры и навигация

Карточки перестраиваются в 1–3 столбца по доступной ширине GUI. Текст не уменьшается ради размещения всех кнопок. При большой GUI Scale появляется вертикальная прокрутка: колёсико, Page Up/Down, Home/End. При переходе клавиатурного фокуса скрытая карточка прокручивается в область просмотра. За границами области прокрутки карточки не принимают клики.

Страницы списка переключаются стрелками внизу. «Назад» из карты, материалов, целей, истории и приглашений возвращает на предыдущий экран; выбранный фильтр города сохраняется. «В игру» закрывает меню. Обновление данных сохраняет прокрутку, пока она помещается в новый размер содержимого.

Цвета берутся из текущей серверной темы или выбранной игроком тёмной темы. Для города используются небольшие рисованные пиктограммы; предметные иконки и градации редкости заказов не заменяются.

## Доступ и обновление

Игрок без города не получает городской экран; сервер направляет его к приглашениям. При выходе из города старые действия блокируются. Недоступные разделы объясняют причину. Все переходы используют выданные сервером идентификаторы; клиент не отправляет команды из карточек.

Замените старые CraftoUI JAR новыми: Folia — в `plugins/`, Fabric — в `mods/` профиля GML. Перезапустите сервер и игру, сохраните папки конфигураций и данные аддонов. API JAR предназначен разработчикам и не устанавливается как плагин. Этот архив не содержит сторонних аддонов. Для самого нового оформления их обновлять не требуется.

Java 25, Minecraft/Folia 26.2, Fabric Loader ≥0.19.4, Fabric API 0.161.0+26.2. Старый клиент получает прежний список города; новый клиент со старым сервером также использует прежний список. Новое оформление включается только с новой парой.
