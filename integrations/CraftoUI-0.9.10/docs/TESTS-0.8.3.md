# Проверки CraftoUI 0.8.3 — 25.10.2026

## Сборка

Сервер и клиент собраны из актуального исходного комплекта 0.8.2 с сохранением изменений 0.8.0–0.8.2. Использованы Java Zulu 25.0.2, Gradle 9.0.0, Minecraft 26.2, Fabric Loader 0.19.4, Fabric API 0.161.0+26.2, Paper API 26.2.build.121-stable.

Команда: `gradle --no-daemon --console=plain -PdirectMinecraft=/path/to/original/minecraft-client release`. Это предусмотренная проектом прямая компиляция с оригинальными библиотеками необфусцированного Minecraft 26.2. Полная сборка завершилась `BUILD SUCCESSFUL`. Wrapper 9.5.1 сохранён в исходниках; в этом прогоне использован установленный Gradle 9.0.0.

Новые тесты проверяют классификацию городских меню и команд (включая namespace, регистр и параметры), доступность личных функций и приглашений, явное условие собственного экрана, объединение каталога с сохранением старых ключей, отличие разных команд и владельцев, клиентские вкладки и перенос избранного без удаления временно недоступных записей. ## Folia

Запущен отдельный Folia 26.2 build 7 (`14b7fee`) на `127.0.0.1:25595`, с новыми тестовыми данными. Настоящие плагины: Towny 0.103.2.0, Builds 0.8.33, Council 0.1.15 и выпускаемый CraftoUI 0.8.3. Итог: **PASS 28 checks**, завершение процесса с кодом 0.

Проверены отсутствие Resident и отсутствие города при выданных городских правах, скрытие городских разделов, сохранение личных заказов и раздела торговли, отказ прямого открытия городского меню, фильтрация поиска, вступление в настоящий Towny Town, обновление уже открытого меню, устранение специально добавленного дубля городской кнопки, единственная запись склада и её старый ключ избранного, сохранение токена при неизменном поиске, отказ старого перехода и поддельной скрытой кнопки после выхода, три повторных цикла вступления/выхода без накопления кнопок, переход к приглашениям при запросе городской сводки без города и обращение к EntityScheduler.

Точный список и журнал: `validation/town-menus-0.8.3/runtime/`. Исходник стенда: `tools/town-menu-probe/`. Тестовый JAR не входит в комплект установки.

Towny API, Resident/Town, меню CraftoUI, кодирование/разбор пакетов и проверка действий настоящие. Player, InventoryView, инвентарь и EntityScheduler имитируются. Задачи тестового EntityScheduler исполняются на глобальном планировщике Folia; проверка не доказывает владение региональным потоком настоящего подключённого игрока.

Предварительный прогон выявил отсутствие альтернативного ключа у объединённой быстрой ссылки. После исправления быстрые действия включаются в объединение, ссылка остаётся одной, а её альтернативный ключ передаётся клиенту. Окончательный прогон выше прошёл полностью.

В серверном журнале присутствует ошибка получения публичного ключа Mojang из-за сетевого/DNS-ограничения стенда. Проверка работала в offline-режиме только на loopback; это не проверка входа через online-аутентификацию.

## Что не проверено

Графический Minecraft-клиент, реальный вход по сети, GML/Pterodactyl, разные GUI Scale и операционные системы, все внутренние операции аддонов и нагрузка 100 игроков не прогонялись. Штатный `hub.json` не содержал одинаковых кнопок; точный пользовательский вид повтора без скриншота не воспроизведён. Проверена общая защита от повторных назначений в конфигурации и повторных изменений членства. Исторические проверки в других документах не являются новым прогоном 0.8.3.
