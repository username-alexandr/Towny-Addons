# CraftoUI 0.6.2 — данные города

Серверный патч от 22 октября 2026 года. Клиент остаётся **0.6.1**, его JAR побайтно совпадает с предыдущим выпуском; протокол 1 не меняется.

## Причины пропусков

1. `CityBuildReader` допускал только NeverLandTownyBuilds 0.8.27. Совместимый Builds 0.8.28 отклонялся до чтения данных, раздел ресурсов оставался пустым.
2. Городские задания и HUD личных заказов допускали только Contracts 0.3.20/0.3.21. Совместимый Contracts 0.3.22 блокировался номером версии. Общее сообщение ошибочно объединяло эту причину с отсутствием аддона или прав.
3. Сумма награды читалась только из устаревшего `pending.players`. Contracts переводит такие суммы в журнал `payments`; прежний интерфейс после миграции показывал 0.
4. Для площадок всегда применялся текущий генератор и архитектура 6. Это могло давать неверные требования для старых сохранённых площадок.

## Исправления

- Совместимость определяется нужными полями сохранений и доступностью публичного API аддона. Номер релиза больше не является списком разрешений.
- Проверяются структура и значения данных. Поддерживаются известные схемы: городские контракты 3, личные заказы 1/2. Неизвестная схема не превращается в пустой список.
- Чертёж строится через публичный `generateForArchitecture` с `architecture-version` конкретной площадки. Старые сохранения без этого поля используют версию 1 по правилам аддона.
- Ресурсный раздел всегда содержит данные или объяснение недоступности. Для заданий отдельно отображаются отказ прав, выключенный аддон и ошибка чтения; последняя записывается в журнал не чаще раза в минуту.
- Награда считается по правилам публичного `ContractRepository.pendingPlayer`: старый остаток плюс собственные `REWARD` в состояниях `READY`/`PENDING`. `DONE`, `REJECTED`, `RESERVE`, `REFUND` и чужие платежи исключены.
- Дисковое чтение остаётся асинхронным, блоки читаются через RegionScheduler своего чанка. Чанки принудительно не загружаются. Права и проверка принадлежности городу сохранены.

## Сборка и автоматические проверки

Задача Gradle `release` успешно выполнена на Java 25.0.2 / Gradle 9.5.1 через документированный `-PdirectMinecraft`, с настоящими Minecraft/Paper API. Итоговая сборка инкрементальная; изменённый сервер скомпилирован заново. Обычный путь Loom в этом прогоне не проверялся.

**102 JUnit-теста: 0 ошибок, 0 пропусков.** XML и сводка находятся в `validation/ui-0.6.2/junit/` и `junit-summary.json`. Новые проверки покрывают независимость от номера релиза, повреждённые структуры, сохранённую архитектуру, неизвестную архитектуру и выбор собственных ожидающих наград из журнала. Остальные тесты относятся к существующим протоколу, меню, навигации, правам и формам команд.

Хеши итоговых JAR — в `release/SHA256SUMS.txt`; проверка ZIP CRC, версии и Java class major — в `validation/ui-0.6.2/jar-validation.json`. Выпускные JAR не содержат тестовых плагинов.

## Установка

Остановите сервер, удалите предыдущий серверный JAR именно CraftoUI, загрузите `CraftoUI-Folia-26.2-0.6.2.jar` в `plugins/` и запустите Folia. Сохраните папку настроек CraftoUI и данные аддонов. Клиент 0.6.1 и сами аддоны для установки этого патча заменять не требуется. Для чистой установки клиент 0.6.1 включён в `release/` общего архива.

## Проверка в настоящем клиенте и Folia

Linux/Xvfb/Mesa, Minecraft 26.2, Fabric Loader 0.19.4, Fabric API 0.161.0+26.2, клиент CraftoUI 0.6.1, Folia 26.2 DEV-14b7fee, Towny 0.103.2.0, Builds 0.8.28, Contracts 0.3.22. Contracts 0.3.22 собран из имеющихся исходников аддона с настоящими Paper/Towny/PlaceholderAPI, без заглушек. Проверен итоговый серверный JAR SHA-256 `c790636310582815c94bee6e2ea66e743550f36df5910eb26ac335e289ce3190`.

Для изолированного сервера подготовлены тестовые сохранения города, площадки и контрактов. Настоящие аддоны загрузили эти данные; блоки считались из настоящего мира. Это тестовые сценарии, а не данные рабочего сервера пользователя. Сумма 25,50 была перенесена самим аддоном из старого поля в `payments` и прочитана исправленной сводкой.

| Towny | Занято 1, лимит 32, доступно ещё 31, жителей 4 |

Итоговые скриншоты находятся непосредственно в `runtime/`.

## Границы проверки

- Прогон подтверждает отображение сохранений и чтение блоков с указанными версиями. Он не подтверждает все будущие форматы, типы площадок и архитектуры; старые архитектуры проверялись модульно, не отдельным игровым миром.
- На стенде нет экономического провайдера. Казна показывает «Экономика недоступна»; настоящая выплата 25,50 не выполнялась. Предупреждения и исключения других аддонов об отсутствии EconomyAdapter сохранены в журнале и не относятся к успешной проверке экономики.
- Остаток материалов означает блоки, которые ещё нужно поставить, без вычитания складских запасов. Для выгруженных чанков используется сообщение о неполных данных. Ограничения: 12 активных площадок, 24 000 блоков и 64 чанка на площадку, кэш 8 секунд.
- Переход кнопкой «Назад» в этом прогоне не подтверждён: контрольный кадр после одного клика остался на сводке. Успешная проверка перехода относится к 0.6.1; клиентская навигация в патче не менялась.
- Клиентские файлы не менялись. Проверки vanilla-клиента без мода и клиента без серверного плагина относятся к предыдущим выпускам; в этом патче они не повторялись.
- Не проверялись Windows/macOS, рабочий сервер пользователя, WAN/прокси, GML/Pterodactyl через панель, установленный LuckPerms с БД, нагрузка и все бизнес-операции 40 аддонов.
