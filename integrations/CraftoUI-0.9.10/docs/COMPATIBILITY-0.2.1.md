# CraftoUI: совместимость клиента 0.2.1

Клиент **0.2.1** работает с **Fabric Loader 0.19.4**. Серверный плагин и API остаются **0.2.0**; для этого исправления обновлять их не требуется.

## Причина и исправление

В клиенте 0.2.0 минимальная версия Loader была привязана к использованной при разработке версии 0.19.5. Нужных только этой версии вызовов CraftoUI не содержит. Требование снижено до 0.19.4, мод пересобран с этой зависимостью. В Gradle отдельно задан `client_version=0.2.1`, добавлены inputs для версий Loader/Fabric API при обработке ресурсов.

Сравнение JAR 0.2.0/0.2.1 показало изменение только `fabric.mod.json`; Java-классы побайтно одинаковы. Минимум Java 25, Minecraft 26.2 и Fabric API 0.161.0+26.2 сохранён.

## Реально выполненные проверки

Локальный стенд: Minecraft 26.2, JDK 25.0.2, Folia 26.2 build 7, Linux/Xvfb/Mesa. Для протокольной авторизации использован offline mode исключительно на изолированном стенде. Сторонние модпаки, GML/Pterodactyl и производственный сервер не изменялись.

| Клиент | Сервер | Проверенный результат |
|---|---|---|
| Fabric Loader 0.19.4 + Fabric API + CraftoUI 0.2.1 | Folia с CraftoUI 0.2.0 и NeverLandTowny | Игра загрузилась, вход прошёл; M открыл главный экран; `/town builds` и клик открыли меню и вложенную категорию |
| Оригинальный vanilla-клиент без Fabric и CraftoUI | Folia с CraftoUI 0.2.0 | Вход прошёл; `/craftoui status` сообщил отсутствие мода; `/town builds` открыл обычный инвентарь; `/list` выполнена после этого |
| Fabric Loader 0.19.4 + CraftoUI 0.2.1 | Folia без CraftoUI-плагина | Вход прошёл; нажатие M сохранило игру и показало недоступность меню на данном сервере; `/list` выполнена |

Сервер последнего сценария использовал отдельный каталог плагинов без CraftoUI и тестового ApiProbe. Другие серверные аддоны могли оставаться установленными. Это проверка отсутствия CraftoUI, а не запуск пустого vanilla-сервера.

Подтверждения: `validation/compatibility-0.2.1/results.json`, журналы клиентов/серверов и снимки `loader194-hub.png`, `loader194-builds-submenu.png`, `vanilla-builds.png`, `vanilla-still-connected.png`, `no-plugin-world-after-M.png`, `no-plugin-still-connected.png`. Сценарий проверки находится в `compatibility.py`; он привязан к локальному стенду, не является установщиком.

В логах сохранены предупреждения локальной среды об аудио, недоступной авторизации/Realms и известном отсутствии провайдера экономики Towny. Они не относятся к проверке минимальной версии Loader или обязательности CraftoUI. Экономика и остальные бизнес-сценарии этим исправлением не перепроверялись. Исторические проверки выпуска 0.2.0 находятся в `TESTS.md`.

## Установка

1. Закрыть игру и лаунчер.
2. В клиентском профиле GML заменить `CraftoUI-Fabric-26.2-0.2.0.jar` на `CraftoUI-Fabric-26.2-0.2.1.jar`. В mods/ должна остаться одна версия CraftoUI.
3. Синхронизировать профиль и перезапустить лаунчер. Loader 0.19.4 можно оставить.
4. Серверный CraftoUI-Folia 0.2.0 и конфиги меню менять не требуется.

Мод опционален для подключения к серверу. Без него доступны обычные меню аддонов. С установленным модом можно входить на серверы без CraftoUI-плагина; кастомный интерфейс там недоступен. Fabric-мод нужен только на клиенте, Folia-плагин устанавливается отдельно в plugins/ сервера.
