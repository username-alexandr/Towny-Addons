# Проверки CraftoUI 0.7.0

Дата: 22 октября 2026. Это проверки новой сборки; старые каталоги validation относятся к прошлым версиям.

## Сборка и автоматические проверки

- Java 25.0.4.1, Gradle 9.5.1, настоящий клиент Minecraft 26.2 и его зависимости с проверкой официальных SHA1.
- `test build`: успешно. Common — 50 JUnit-тестов, server — 64, всего **114**, 0 ошибок / пропусков.
- Покрыты расчёт материалов, отрицательные координаты участков, фильтры поставки, одноразовые подтверждения и срок действия, недоступные действия, конфликт двух закреплений, сохранение цели/должности, защита повреждённого хранилища.
- Учёт вклада проверен через Bukkit-события с тестовыми объектами: старые блоки не приписываются, повторное событие не удваивает вклад, разрушение убирает вклад, новое закрепление не наследует прежний вклад. Это не имитация полноценного игрового размещения на живом сервере.
- Builds 0.8.29 — 35 исполняемых smoke-проверок; Contracts 0.3.23 — 6; Companies 0.1.15 — 1. Это их штатный `smokeTest`, не JUnit. Всего **42**.
- API, Fabric и Folia JAR содержат скомпилированные классы и метаданные 0.7.0. Контрольные суммы прилагаются.

## Стенд

Настоящие Folia 26.2 build 7, Fabric Loader 0.19.4, Fabric API 0.161.0+26.2, Towny 0.103.2.0, новые Builds / Contracts / Companies и TreasuryPlus 0.1.16. Изолированный локальный сервер, тестовый мир и тестовые игроки. Графика — Xvfb/Mesa, кириллица из штатных ресурсов Minecraft.

Протокольный тестовый плагин вызывает реальные обработчики CraftoUI и установленных аддонов, а не заменяет их фиктивными ответами. Он не входит в папку release и не предназначен для рабочего сервера.

## Подтверждено на сервере

- Реальная карта Towny: 81 выбираемая ячейка.
- Текущая суточная доска заказов и детали выбранного сервером заказа.
- Предпросмотр принятия, принятие реального заказа, игнорирование подставленного клиентом идентификатора.
- Отклонение повторного подтверждения и поддельного ключа действия.
- Предпросмотр отмены; выход с предпросмотра аннулирует подтверждение; настоящая отмена заказа.
- Материалы читаются из реальной стройки и инвентаря.
- В клиенте проверены городская сводка, остаток материалов, карта, границы участка и причина запрета удаления главного участка; закрепление общей стройки с предпросмотром и отображение её прогресса.
- Приглашение компании отклонено через UI; в настоящем companies.yml удалено только приглашение этого игрока. Отдельный протокольный прогон подтвердил немедленное удаление записи из возвращаемого интерфейсу снимка.
- В итоговом прогоне приняты приглашения компании и Towny для двух настоящих подключённых игроков. Проверены реальные членства и удаление использованного приглашения из свежего ответа UI. Протокольный тест вызывает те же серверные операции, что кнопки клиента.
- В клиенте наблюдалась карточка «Ваши должности изменились … Сотрудник» после вступления в компанию.
- Возврат из исходного меню Builds в выбранную карточку стройки CraftoUI проверен; закреплённая цель сохранилась после перезапуска.
- Отображение доски заказов проверено при 1600×1000 и после изменения окна до 1024×720, GUI Scale 2. Вкладки перестроились в 3 столбца, пагинация и нижние кнопки остались в пределах окна. Все возможные разрешения и GUI Scale не перебирались.

## Необязательная установка

- Чистый Minecraft 26.2 без Fabric/CraftoUI вошёл на сервер с плагином 0.7.0; `/orders` открыл обычный сундуковый интерфейс. Клиент не упал.
- Minecraft 26.2 + Fabric Loader 0.19.4 + CraftoUI 0.7.0 вошёл на Folia, запущенную с пустым каталогом плагинов. Журнал подтверждает `Initialized 0 plugins`. Нажатие M не прервало соединение; выход выполнен штатно.
- Пробная `/say` на сервере без плагинов была отклонена штатными правами не-оператора; она не считается успешно выполненной командой. Это не ошибка подключения CraftoUI.

## Выявленные и исправленные проблемы

- Список приглашений мог показывать удалённую запись до следующего обновления кэша. Теперь кэш сбрасывается после действия с приглашением.
- На промежуточном стенде произошёл keepalive timeout с watchdog-снимком во время сканирования блоков. Сканирование разбито на ограниченные региональные порции; истёкшие задачи прекращаются; страницы заказов и приглашений больше не инициируют подсчёт построек. В интерактивном прогоне также наблюдался watchdog-снимок внутри ожидания EDF-планировщика Folia без кода CraftoUI в стеке. Эти паузы не позволяют считать стенд нагрузочным тестом. Отдельный автоматический прогон приглашений завершился успешно.

- Нативная команда компании требовала дополнительное `/company confirm`. Для подтверждённого действия CraftoUI добавлен публичный `uiJoin` с проверками состояния и прав; повторный прогон подтвердил настоящее вступление.

## Границы проверки

- На стенде нет рабочего банка / экономического провайдера. Реальное начисление награды, платная покупка участка и полный банковский журнал не считаются проверенными.
- Групповые покупки участка сохраняют исходный процесс Towny. История TreasuryPlus содержит только его операции.
- Не выполнялось нагрузочное испытание с сотнями игроков, прокси, GML-синхронизацией или рабочим сервером пользователя.
- Внешние редакторы мира, обходящие Bukkit-события, могут потребовать отдельного адаптера учёта вклада.
- В окружении отключён звук и недоступны Realms / сервисы авторизации Mojang; это отмечено в журналах. Тестовые подключения выполняются только локально.
