# CraftoUI 0.5.2

Поиск и избранное используют компактную сетку: до четырёх столбцов, шаг строки 24 GUI-единицы вместо 28, кнопка избранного шириной 20 вместо 24. Число столбцов зависит от ширины после применения Minecraft GUI Scale: 696 и более — четыре, от 520 — три, от 344 — два, меньше — один. Рабочая область ограничена 720 GUI-единицами. Обрезанные подписи доступны в подсказке; страницы и сортировка избранного сохранены.

В разделе **главное меню → Заработок** добавлена отдельная кнопка **Личные заказы**, выполняющая `orders`. Существующая кнопка «Контракты» продолжает открывать городские контракты (`town contracts`). Оба пункта нужны: это разные окна аддона. В поиске «Личные заказы» уже были; их идентификатор `link:orders` и сохранённое избранное не изменены.

Кнопка ссылается на `quick:orders`: это та же серверная запись из `quick-actions.json`, которую использует поиск. Команда фиксирована серверной конфигурацией, требует `neverland.orders.use` и включённый `NeverLandTownyContracts`. Прежнее окно закрывается перед запуском, историю возврата обслуживает существующий механизм CraftoUI. Клиент передаёт только идентификатор кнопки. Если интеграция отсутствует или нет права, кнопка недоступна.

В настройках назначения клавиш категория теперь называется **CraftoUI** на русском и английском. Исправлен ключ локализации `key.category.craftoui.menu`; ранее использовалось устаревшее `key.categories.craftoui.menu`. Назначенные игроком клавиши сохраняются.

## Обновление

Замените клиентский и серверный JAR на 0.5.2 и перезапустите игру и Folia. Minecraft 26.2, Java 25, Fabric Loader 0.19.4+, Fabric API 0.161.0+26.2 остаются прежними. Не удаляйте папки настроек.

Неизменённый `plugins/CraftoUI/menus/economy.json` из 0.5.1 обновится автоматически; оригинал сохранится в `plugins/CraftoUI/backups/0.5.1/menus/economy.json`. Сравнение точное, допускается разница CRLF/LF. Если вы редактировали этот экран, он сохранится без перезаписи. В таком случае добавьте в `children` сетки `modules`:

```json
{
  "id": "orders",
  "type": "button",
  "text": "Личные заказы",
  "tooltip": "Открыть личные задания — /orders",
  "action": "quick:orders",
  "icon": "minecraft:paper"
}
```

После ручной правки выполните `/craftoui reload`. Запись `orders` должна присутствовать в `quick-actions.json` (есть в стандартном комплекте с 0.5.0). Любое быстрое действие теперь можно поставить на конфигурационную кнопку через `quick:<id>`; пространство `quick:` зарезервировано для этих записей. Нельзя объявлять второе действие с тем же идентификатором в `actions.json`.
