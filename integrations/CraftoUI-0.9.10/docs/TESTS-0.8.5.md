# Проверки CraftoUI 0.8.5 — 25.10.2026

## Сборка и модульные проверки

Оба JAR и API собраны настоящим Java 25.0.2 / Gradle 9.0.0. Клиент компилировался с оригинальными библиотеками Minecraft 26.2 в режиме `directMinecraft`. Исходники содержат Gradle Wrapper 9.5.1; в этом прогоне использован установленный Gradle 9.0.0. `release` завершён успешно.

**188 тестов: common 75 + server 113; 0 ошибок, 0 пропусков.** Проверены:

- Перестроение при 9 ширинах, 6 высотах и 5 размерах списка: 270 комбинаций, без пересечения карточек и выхода за ширину.
- Достижимость карточек прокруткой при большом GUI Scale, возврат фокуса к сводке.
- Реальные числовые поля и безлимитные участки; форматирование больших сумм без потери дробной части.
- Разделение активных/готовых зданий и контрактов, порядок выполненных заданий, личный вклад.
- Отсутствие личного подборщика среди городских переходов.
- Неизвестные данные, причины блокировки, отсутствие исполняемых ключей у отключённых действий и скрытие недоступного баланса.
- Действия только текущей страницы, сохранение городских переходов на каждой странице, корректность подтверждений Towny при вставке в начало списка.
- Максимальная страница с 12 длинными кириллическими записями укладывается в реальный лимит протокола 28 КиБ.
- Все прежние тесты конфигураций, протокола, навигации, редкости, истории и построек из исходного выпуска.

## Настоящий Folia, тестовый игрок

**43 проверки пройдены** на Folia 26.2 DEV-14b7fee с Towny 0.103.2.0 и Builds 0.8.34. Исходник проверки — `tools/city-dashboard-probe/`, результаты — `validation/0.8.5/`.

Проверены членство Towny и обновление кнопок при вступлении/выходе, искусственный дубль назначения, поиск и избранное, блокировка устаревших переходов, новый пакет города, число жителей из Towny, семь различных городских действий, отсутствие Chronicles с объяснением, настоящий маршрут карты Towny, «Назад» из карты и приглашений, сохранение выбранного фильтра, отказ неизвестному фильтру, старый формат для старого клиента и уход с городской страницы после выхода из города.

Towny, CraftoUI, чтение данных, сериализация и маршруты настоящие. Player, InventoryView и EntityScheduler — явные тестовые двойники; callback игрока выполняется через GlobalRegionScheduler. Это **не** проверка настоящего сетевого входа или владения региональным потоком подключённого игрока. Первоначальный запуск стенда не загрузил проверку из-за лишней зависимости тестового плагина от Council; зависимость удалена, успешный прогон выполнен отдельно.

## Отрисовка

`tools/city-preview/run.py` компилирует настоящий `CityCardButton`, `FlatButton` и `CityDashboardLayout` с AWT-адаптером. Bitmap-шрифты берутся из оригинального клиентского JAR, который в архив не включён. Получены 16 PNG: dark/classic, 800×460, 520×340, 320×240, 320×180 логических GUI-пикселей, начало и конец прокрутки. Во всех вариантах автоматически проверены границы наведения. Выборочно просмотрены широкая тёмная, средняя светлая и узкая прокрученная раскладки.

Адаптер воспроизводит рисование карточек, но не движок Minecraft, полный Screen lifecycle, реальное управление мышью/клавиатурой, tooltip positioning или все особенности шрифтов ресурс-паков. Предпросмотр использует пример данных.

## Не выполнялось

Полный графический запуск Minecraft с подключением, GML/Pterodactyl-развёртывание, нагрузочные испытания и повторная проверка каждой операции всех аддонов. Форматирование города не добавляет новые данные к источникам: прогресс незагруженных строек остаётся неизвестным; казна и летопись зависят от прав и интеграций.
