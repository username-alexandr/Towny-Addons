# История разработки планировщика

Рабочая ветка объединена с CraftoUI 0.8.20 и выпущена в составе 0.9.0. Актуальные установка, возможности и проверки: [UPDATE-0.9.0.md](UPDATE-0.9.0.md). План открывается из раздела «Развитие города», сводки и поиска.

Ниже описаны исторические проверки до выпуска; они не выполнялись заново как живой Folia-прогон 30 октября.

# Планировщик развития — рабочая версия

CraftoUI 0.9.0-dev добавляет цели строительства, зависимости и общую смету через Builds 0.11.0. Уже сданные материалы и общий склад учитываются отдельно. Данные неполного расчёта не выдаются за подтверждённые.

В разделе последствий теперь читаются Upkeep 0.2.2 и Power 0.2.1: содержание всего города до/после, ресурсы в точных единицах, ранее выставленные счета, производство и потребность энергии, условия запуска и недоступные данные. Просмотр ничего не покупает и не расходует заряд. Нужны прежние права просмотра соответствующих аддонов; они проверяются до и после фонового чтения.

285 серверных/common/API проверок проходят, включая 9 новых проверок расчётного ответа и представления условий. Runtime API проверены в Towny-Addons отдельно на настоящей Folia (Builds 30+30, Upkeep/Power 18+5). Сетевой клиент и визуальное размещение нового экрана в игре ещё не проверены; клиент в этом архиве не изменён.

Создание обеспеченных заказов из плана подключено через API Contracts: см. DEVELOPMENT-PROCUREMENT.md. Folia: 20 + 7 проверок реальных серверных JSON-действий, точной оплаты, возврата и полного перезапуска. Планы пока хранятся в текущем сеансе игрока; при смене города очищаются. Этот архив содержит исходники и проверенный серверный JAR, но не является полным релизом всего пакета NeverLand.

Сборка: tools/build-direct-server.py, Java 25, официальные runtime-зависимости Folia, LuckPerms API 5.4, JUnit console 1.12.2. Скрипт очищает свои выходные классы перед каждой сборкой и сохраняет протокол. Зависимости не включены в архив.
