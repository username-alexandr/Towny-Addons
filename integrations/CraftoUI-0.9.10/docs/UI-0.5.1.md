# CraftoUI 0.5.1 — темы и адаптивные меню

Поиск и избранное показывают две колонки при ширине содержимого от 440 единиц GUI. На более узком окне остаётся одна колонка, вкладки располагаются в два ряда. Количество строк и страниц пересчитывается при изменении окна и GUI Scale. Названия обрезаются с многоточием, полный текст доступен в подсказке.

Профиль стал ниже: 330 вместо 460 единиц, шаг строк 24 вместо 44. Профиль, помощь и главное меню используют тёмную серверную тему по умолчанию. Персональные экраны и настройки наследуют последнюю полученную тему. Встроенная тёмная палитра больше не затирает серверные цвета. Явные ресурс-паки сохраняют приоритет: `assets/craftoui/themes/<id>.json`. Встроенный резерв находится в `assets/craftoui/defaults/dark.json`.

Автоматическая подсказка появляется только у обрезанного однострочного текста или кнопки. Многострочный текст больше не показывает длинную полосу при наведении. Подсказки ограничены шириной и высотой окна.

JSON/YAML-экраны вписываются по ширине. Если содержимое не помещается по высоте, прокручивается центральная область; заголовок, «Назад», закрытие и нижняя панель остаются на месте. Колесо сначала прокручивает вложенный список, затем экран; Page Up / Page Down прокручивают экран.

Карточки аддонов пересчитывают число колонок, строк и размер описания. В списках рынка навигация расположена слева, товары справа, описание под товарами. Если предложений нет, выводится отдельное сообщение. Все товары и цены берутся из настоящего инвентаря аддона; страницы CraftoUI перелистывают полученные ячейки, а кнопки аддона переключают страницы сервера. Окна покупки и подтверждения сохраняют обычный вид карточек.

В `addons.json` модуль NeverLandTownyMarket получает `"layout": "market"`; старый конфиг без поля использует тот же режим. `"layout": "cards"` возвращает обычные карточки. Разделение применяется только к 54-ячеечным спискам с известными названиями рынка; изменённые названия потребуют обновления адаптера. F6 переключает оригинальную сетку предметов. Нажатия используют штатные inventory-пакеты и серверные проверки аддона.

## Обновление

Замените оба JAR 0.5.1, перезапустите сервер и игру. Не удаляйте конфиги. При запуске плагин сравнит `menus/profile.json`, `main.json` и `help.yml` с неизменёнными шаблонами 0.5.0. Совпавшие файлы обновляются, оригиналы сохраняются в `plugins/CraftoUI/backups/0.5.0/menus/`. CRLF распознаётся. Любые другие изменения, включая собственные размеры, подписи и темы, сохраняются. Для такого профиля примените нужные размеры из новых примеров вручную.

Fabric Loader 0.19.4+, Fabric API 0.161.0+26.2, Minecraft/Folia 26.2, Java 25. Без мода доступны обычные меню плагинов. Мод без серверного CraftoUI не блокирует подключение.

## Ограничения

- Произвольные авторские координаты JSON/YAML не превращаются автоматически в другую композицию: экран масштабируется по ширине и прокручивается по высоте.
- Каталог рынка показывает фактическое содержимое текущего серверного окна. CraftoUI не создаёт товары и не объединяет невидимые серверные страницы.
- На минимальном окне часть длинных подписей сокращается; описание и подсказки позволяют прочитать полный текст.
- Новые рисованные иконки в этот выпуск не включены: их дизайн требует отдельного предварительного просмотра.
- Это обновление интерфейса, а не аудит всех денежных операций и всех 38 аддонов.
