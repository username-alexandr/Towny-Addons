# CraftoUI Fabric 0.8.7 — понятные городские страницы

Переработаны страницы приглашений, материалов, целей, истории города и казны, подробностей строек/контрактов/участков и подтверждений. Общий список больше не выглядит как столбец одинаковых длинных кнопок.

## Что изменилось

- Ограниченное по ширине окно, заметный заголовок, пояснение назначения раздела и выбранная вкладка.
- Собственные линейные значки для городской навигации. Предметы и градации редкости заказов сохранены.
- Приглашения и записи представлены карточками: на широком экране два столбца, на узком один. Данные без действия не выглядят активной кнопкой.
- «Приглашений нет» и другие одиночные информационные состояния оформлены отдельным блоком. Входящие приглашения показываются перед статусом игрока.
- У недоступных действий видны замок и причина. Нажатие на такую карточку выводит причину, не отправляя действие серверу.
- Подробности переносятся; длинные подписи и причины доступны в подсказке. Короткая карточка не дублирует себя во всплывающей строке.
- Текст сервера в верхней сводке переносится полностью, без прежнего обрезания одной общей строки. Тело страницы прокручивается отдельно; нижние кнопки и вкладки остаются на месте.
- Колёсико, Page Up / Page Down, Home / End; переход клавиатурного фокуса прокручивает карточку в область просмотра.
- Цвета берутся из текущей темы. Для светлой темы текст акцента затемняется с учётом её основного цвета текста.
- Сохранено исправление 0.8.6: полученный ответ и раскладка обновляются до кадра; прежние кнопки не выполняются с новым токеном.

Сводка города, географическая карта, специальная сетка заказов и нативные окна аддонов сохраняют свои отдельные раскладки. Это обновление общего типа городских страниц, показанного на присланном скриншоте, а не замена всех экранов проекта.

## Установка

Закройте игру. Замените прежний клиентский CraftoUI JAR в `mods/` профиля GML на **CraftoUI-Fabric-26.2-0.8.7.jar**, обновите файл распространяемого профиля и синхронизируйте лаунчер. Не оставляйте несколько версий CraftoUI. Настройки сохраняйте.

**Сервер и API остаются 0.8.5; сервер перезапускать для этого обновления не нужно.** Minecraft 26.2, Java 25, Fabric Loader 0.19.4+, Fabric API 0.161.0+26.2. Протокол и проверки действий на сервере не менялись. Необязательность клиентского мода сохранена.

## Реально выполненная проверка

1. Настоящий Fabric JAR собран с оригинальными библиотеками Minecraft 26.2 (не с тестовыми двойниками), Java 25.0.2 и Gradle 9.0.0. Комплектный Wrapper 9.5.1 в этом прогоне не запускался.
2. **191 модульный тест: common 78, server 113; ошибок, сбоев и пропусков нет.** Серверные тесты выполнены при первой сборке этого изменения; последняя сборка повторно использовала неизменённый успешный результат. XML находятся в `validation/0.8.7/junit/`.
3. **19 проверок жизненного цикла** на производственном исходнике CivicScreen: ответ между тиком и кадром, переходы между городом и страницами, устаревшие ответы и контролы, подтверждение, возврат, изменение членства, размеров и ошибки.
4. **95 проверок новых страниц**: положение навигации и нижних кнопок в двух темах и четырёх размерах, серверный идентификатор приглашения, защита от второго клика, причина запрета, локальная прокрутка без запроса к серверу, видимость фокуса, обрезка области мыши, сброс прокрутки, билет подтверждения, членство, пассивные сведения, длинные подсказки и предыдущая страница.
5. **81 PNG отрисовки настоящего CivicScreen и настоящих городских компонентов** через AWT-адаптер. Использован bitmap-шрифт из оригинального Minecraft JAR. Размеры в логических пикселях: 871×447, 520×340, 320×240 и 320×180; темы dark и classic. PNG записаны с масштабом 2 для удобства просмотра. Визуально просмотрены выбранные широкие и узкие состояния, приглашения, запрет действия, материалы и подтверждение.
6. Проверены версия внутри `fabric.mod.json`, целостность ZIP, состав JAR без тестовых адаптеров и SHA-256. Серверный JAR сравнен побайтно с выпуском 0.8.5.

Журналы, сводка JSON, XML и PNG находятся в `validation/0.8.7/`. Скрипты: `tools/civic-page-preview/`, `tools/city-lifecycle-test/`; чистая геометрия: `CivicPageLayoutTest`.

## Границы проверки

Графический Minecraft с настоящим игроком и подключением к Folia в этом прогоне не запускался. AWT-превью используют примеры данных и явные двойники экрана, ввода и транспорта; они показывают новую отрисовку, но не являются снимками запущенной игры. Все правила действий, приглашения и права остаются серверными. Собственные ресурс-паки и нестандартные шрифты отдельно не испытывались. При очень большом GUI Scale длинные страницы требуют прокрутки, а вкладки используют значки с названиями в подсказках.
