# CraftoUI Fabric 0.8.10 — единое поведение новых меню

Изменение относится к недавно добавленным экранам CraftoUI. Старые конфигурационные меню MenuScreen и нативные меню аддонов AddonScreen в этом выпуске не изменялись.

## Что сделано

- Новая сводка города переведена в общий компактный макет: центральное окно, затемнение игрового мира, закреплённые заголовок и нижние кнопки. Полноэкранная раскладка города больше не используется.
- Казна, жители, участки, городские действия, стройки и контракты прокручиваются внутри окна. Ссылки на историю, карту и другие разделы сохранены без добавления дублирующей строки городских вкладок.
- Для истории, казны, приглашений, материалов, целей, карты, заказов и подробностей сохранён общий компактный макет. Колёсико сначала прокручивает содержимое, затем переключает страницы. На строке пагинации оно сразу переключает страницу.
- Page Up / Page Down теперь также переходят между страницами городских экранов после достижения края содержимого. Длинные документы перелистываются локально.
- Кнопки предыдущей/следующей страницы отключаются на границах и при ожидании ответа сервера. Смена раздела сбрасывает накопленную дробную дельту колеса.
- Поиск/избранное, панель контрактов, личная сводка, настройки и формы действий используют общий макет и обработку колёсика из 0.8.9; они повторно проверены с текущим клиентом.

Максимальный размер общего окна — 640×400 логических GUI-пикселей. На небольшом логическом разрешении окно занимает большую долю экрана, чтобы сохранить доступ к содержимому. Редактор положения HUD остаётся рабочей областью для перетаскивания панели по игровому экрану, а не страничным меню.

Протокол, права, маршруты `/orders`, предметные обозначения редкости, источники городских данных и серверные операции не изменены.

## Установка

Закройте Minecraft и замените прежний CraftoUI в профиле GML на **CraftoUI-Fabric-26.2-0.8.10.jar**. Оставьте один JAR этого мода и синхронизируйте профиль лаунчера. Настройки сохраняйте.

**Нужно обновить только мод. Сервер и API остаются 0.8.5.** Перезапуск сервера для этой правки не требуется.

## Проверки

- Настоящий Fabric JAR собран с Minecraft 26.2, Fabric Loader 0.19.4 и Fabric API 0.161.0+26.2. Java 25.0.2, Gradle 9.0.0; `BUILD SUCCESSFUL`. Wrapper включён, но здесь использовалась установленная Gradle.
- **400 новых проверок**: настоящая сводка города, история, казна, приглашения, материалы, цели, подтверждение и длинный документ. Проверены границы окна и нижних кнопок, прозрачность затемнения, прокрутка, отсутствие дублирующих переходов, границы кликов, точные параметры запроса страницы, ожидание ответа и клавиатурная пагинация.
- Повторно пройдены **19** проверок жизненного цикла, **95** проверок городских страниц, **161** проверка личных вкладок и форм, **110** проверок колёсика/компактного окна. Используются настоящие классы интерфейса и явно обозначенные двойники платформы и транспорта.
- Получены **295 PNG**: 223 прежних сценария и 72 новых состояния. Для новой сводки и городских вкладок использованы dark/classic и логические размеры 829×563, 520×340, 320×240, 320×180. Просмотрены широкий город, его прокрученная часть и компактный вариант. Изображения содержат искусственные примеры данных, это не снимки игры.
- Common не изменялся: Gradle использовал успешный сохранённый результат **80** модульных тестов (`UP-TO-DATE`), новый прогон не заявляется. Серверные тесты в этом выпуске не запускались.
- Проверены версия в `fabric.mod.json`, целостность JAR/ZIP, отсутствие тестовых двойников в JAR, полнота исходников и Wrapper. Серверный JAR побайтно совпадает с 0.8.5.

Доказательства: `validation/0.8.10/build.log`, `regressions.log`, `recent-menus.log`, `summary.json`, `previews/`. Новый воспроизводитель: `tools/panel-preview/RecentMenusProbe.java`, запускается общим `tools/panel-preview/run.py`.

## Ограничения

Настоящий графический Minecraft, физический ввод мыши/клавиатуры, GML и подключение к живому Folia в этом прогоне не запускались. UI-тесты проверяют раскладку и обработчики через явные двойники; настоящие Minecraft/Fabric-библиотеки используются отдельно при сборке выпуска. Нестандартные шрифты и пользовательские ресурс-паки отдельно не проверялись.
