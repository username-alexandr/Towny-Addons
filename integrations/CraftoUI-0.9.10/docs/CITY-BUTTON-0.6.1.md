# Отдельная кнопка экрана города — 0.6.1

В разделе «Город» появилась кнопка **«Экран города»** в нижней строке между «Все разделы» и «Мой профиль». Она сразу открывает существующую вкладку с казной, участками, стройками, ресурсами и городскими заданиями. «Назад» и Esc возвращают в раздел «Город». Доступ из быстрого меню K также сохраняется.

## Установка

Замените клиентский и серверный JAR CraftoUI на 0.6.1, затем полностью перезапустите игру и Folia. Настройки не удаляйте. Стандартный `plugins/CraftoUI/menus/town.json` обновляется автоматически; предыдущий файл сохраняется в `plugins/CraftoUI/backups/0.6.0/menus/town.json`. Повторный запуск не изменяет эту резервную копию.

Меню с собственными изменениями сохраняется. В таком случае добавьте в его массив `components` кнопку с действием `ui:city`, выбрав свободное место. Для стандартного расположения:

```json
{
  "id": "city-overview",
  "type": "button",
  "text": "Экран города",
  "action": "ui:city",
  "x": 206,
  "y": 410,
  "w": 208,
  "h": 28
}
```

Затем выполните `/craftoui reload`. Действие `ui:city` регистрируется автоматически; менять `actions.json` не требуется. Проверяется право `craftoui.city`. На старом клиенте, не объявляющем `city-screen-v1`, кнопка недоступна; обычная игра и остальные возможности сохраняются.

## Проверки

Сборка `release` выполнена на Java 25 / Gradle 9.5.1 с настоящими Minecraft 26.2 и Paper API, через существующий режим `-PdirectMinecraft`. **96 JUnit-тестов, без ошибок и пропусков**. Новые проверки охватывают сохранение резервной копии при миграции, повторный запуск и сохранность изменённого пользователем меню. Проверена загрузка новой кнопки в полном каталоге конфигураций.

Источник результатов: `validation/ui-0.6.1/build.log`, `unit-tests.json`, `junit/`. Хеши JAR: `release/SHA256SUMS.txt`. Подробные исторические проверки команд, модов и аддонов остаются в отчёте 0.6.0; они не считаются повторёнными этим небольшим выпуском.

На настоящем Fabric-клиенте 26.2 / Loader 0.19.4 и сервере Folia 26.2 проверен переход «Город → Экран города → Назад». Открылась непосредственно вкладка города с данными тестового UiActionsTown; возврат восстановил раздел с кнопками. Снимки: `runtime/town-city-button.png`, `runtime/city-opened-from-town.png`, `runtime/back-to-town.png` в папке проверки 0.6.1. Проверялись именно выпускные JAR; их хеши записаны при запуске в `runtime/harness.log`.

На сервере использовался прежний стандартный `town.json`: после запуска он совпал с новым шаблоном, а резервная копия — с прежним. Графическая проверка: 1600×1000, GUI Scale 2, тёмная серверная тема, размытие включено. Стенд завершён штатно.

Ограничения этого прогона: экономика тестового сервера отключена, а существующий адаптер городских строек не поддерживает установленную на стенде версию Builds; соответствующие строки показывают недоступность данных. В этом выпуске изменён переход к экрану, его источники данных не перерабатывались. Проверки опциональности клиента и всех сценариев аддонов из 0.6.0 повторно не выполнялись.
