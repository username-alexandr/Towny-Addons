# Проверки CraftoUI 0.7.1

Дата: 23 октября 2026 года.

## Выполнено

- Сборка настоящих API, Fabric и Folia JAR из исходников: Java 25.0.4.1, Gradle 9.5.1, Paper API 26.2.build.121-stable, оригинальный Minecraft 26.2 и библиотеки с проверкой SHA-1 по официальному манифесту. Использован предусмотренный проектом `-PdirectMinecraft` (Minecraft 26.2 не обфусцирован); без заглушек Minecraft API.
- 126 JUnit-тестов: common — 50, server — 76. Новые 12 тестов покрывают изоляцию истории по UUID города, сортировку, реальные поля/кириллицу/UTC, дубликаты, отличие пустой истории от недоступного источника, отсутствие города, неизвестные категории, длинные записи и ограничение payload, страницы за пределами 128 записей, повреждённые записи, старый Builds, совместимый API и неверную сигнатуру метода.
- Клиентские изменения скомпилированы против настоящего Minecraft API. Это проверка компиляции, а не визуальный игровой тест.
- Сигнатуры и потоковая безопасность чтения Chronicles сверены с публичными `TownyChroniclesApi`, `ChronicleService.entries`, `ChronicleRepository.entries`, `ChronicleEntry`, `ApiServices.primaryThread` и `SuiteState` в исходниках аддона. `entries` копирует список под общей блокировкой данных и не обращается к игрокам/миру. CraftoUI читает этот снимок в асинхронной задаче, затем проверяет город и права в EntityScheduler игрока.
- Проверены ZIP CRC, метаданные версий/зависимостей и SHA-256 поставляемых JAR. Предыдущие CraftoUI JAR не входят в новый каталог `release/`. Аддоны из 0.7.0 не пересобирались, их байты сохранены.

Журнал итоговой сборки и JUnit XML находятся в `validation/city-history-0.7.1/`. Хеши — в `release/SHA256SUMS.txt`.

## Не выполнялось для 0.7.1

- Запуск Minecraft/Folia с новой версией, проверка наведения в игре, настоящего Chronicles ServicesManager и перехода в старый Builds.
- Установка на сервер пользователя, замена файлов GML/Pterodactyl, нагрузочные тесты.

Не следует считать успешные игровые тесты 0.7.0 повторно пройденными для 0.7.1. Их отдельные материалы сохранены в прежнем каталоге проверки.
