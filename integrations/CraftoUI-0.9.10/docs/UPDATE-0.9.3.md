# CraftoUI 0.9.3 — создание города и пример стиля

## Исправленный маршрут

В форме «Создать город» подтвердите `/town new <название>`. Аддон Builds откроет выбор стиля, затем отдельный экран подтверждения стиля. После нажатия «Подтвердить» Builds повторит команду Towny; CraftoUI перехватит новое подтверждение Towny и откроет его в интерфейсе. Финальное подтверждение выполняет **исходную** команду Towny, с её проверками денег, участка, прав и названия. Кнопка «Назад» отменяет текущую заявку. Без клиентского мода остаются обычные окна Builds и подтверждение Towny в чате.

## Небольшой город в выбранном стиле

На экране подтверждения стиля справа появляется изометрический пример ратуши, кузницы и рынка. Колесо мыши над изображением поворачивает город. Фактические планы берутся из `BlueprintCatalog.preview` установленного NeverLandTownyBuilds; клиент получает только ограниченные PNG. При отключённом Builds или недоступном предпросмотре сама форма выбора и подтверждение остаются работоспособны.

CraftoUI также ищет завершённые экспорты билдера по адресам `plugins/NeverLandTownyBuilds/blueprints/source/<стиль>/<проект>/1.schem` … `5.schem` для проектов `town_hall`, `forge`, `market`. Стиль: `medieval`, `modern`, `fantasy`. Когда все пять файлов присутствуют, стабильны не менее двух секунд и первый уровень читается безопасным Sponge-reader аддона, новый облик появляется в примере при следующем открытии окна. Неполные и повреждённые файлы не меняют действующий пример. Чтение файлов и рендер выполняются асинхронно; схема не передаётся клиенту как NBT или путь к файлу.

**Граница интеграции:** Builds 0.11.3 загружает строительные схемы и закрепляет версии только при полном запуске. Предварительное изображение свежего экспорта до перезапуска означает «готово для проверки», а не «уже можно строить по новой схеме». Для фактической стройки зарегистрируйте все пять уровней каждого проекта в `blueprints.yml` и перезапустите сервер согласно документации Builds. Текущая версия CraftoUI не меняет данные Builds и не выполняет горячую замену закреплённых стройплощадок.

## Обновление

Уберите прежние CraftoUI JAR, установите оба JAR версии 0.9.3 и полностью перезапустите сервер и клиент. Minecraft/Folia 26.2, Java 25, Fabric Loader **0.19.4**, Fabric API 0.161.0+26.2. NeverLandTownyBuilds 0.11.3 — версия интеграции, которую проверили по байткоду; старые версии без публичного `BlueprintCatalog.preview` продолжат работать без изображения.

## Проверки и пределы

`./gradlew clean release`: компиляция Fabric, Folia и API на настоящих зависимостях, модульные тесты. Проверено устройство и слоты CityStyles 0.11.3: выбранный стиль в слоте 13, подтверждение в слоте 20 и повтор `/town new` после выбора. Проверка Fabric Knot 0.19.4 / MixinExtras 0.5.5 — см. `validation/0.9.3/bootstrap/bootstrap.log`. Полный вход в пользовательский Folia-сервер, покупка города, работа с реальными `.schem` билдера и GPU-рендер на клиенте в этой среде не проведены. На реальном сервере проверьте маршрут с тестовым игроком без города и достаточным балансом, а также вариант без мода.
