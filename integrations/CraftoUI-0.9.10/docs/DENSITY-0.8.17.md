# CraftoUI 0.8.17 — описания и плотность меню

Обновить Fabric-мод и Folia-плагин CraftoUI до 0.8.17. Для превью всех стандартных зданий использовать NeverLandTownyBuilds 0.8.39 из комплекта. Fabric Loader **0.19.4**, Minecraft **26.2**, Java **25**, Fabric API **0.161.0+26.2** сохранены. Вложенный MixinExtras 0.5.5 остаётся в моде. Отдельно устанавливать его не требуется.

## Исправления по скриншотам

| Проблема | Изменение |
|---|---|
| Плотный чёрный блок описания заказа | Карточка в текущей теме. Заголовок, отдельные колонки подписей и значений, цвет редкости и награды, абзацы примечаний и подсказка действия. Табуляция нормализуется; строки переносятся по реальной ширине шрифта. |
| «Мои заказы», обновление и лимит на последней странице | «Мои заказы» и «Лимит наград» закреплены под каталогом. Время обновления отображается строкой информации. Мои заказы используют исходный слот аддона; лимит открывает сведения без выполнения операции. |
| Большие полупустые кнопки и лишняя полоса прокрутки | Кнопки компактнее, подпись и иконка выровнены по центру строки. Стандартные категории помещаются в обычное окно. При очень малом GUI содержимое разбивается на страницы с постоянной навигацией. Старые стандартные сетки тоже уплотняются на клиенте. |
| Разный отступ заголовка и подзаголовка | Общая левая граница текста в городских и личных экранах. Убран фон под значком; поправлены отступы описаний внутри общих карточек. |
| Превью только у ратуши | Добавлено распознавание настоящей карточки проекта в старых DetailsHolder без метки превью. В комплект включён Builds 0.8.39, поддерживающий схемы всех стандартных зданий и чудес. |

Профиль уплотнён; обновление и история находятся в нижней панели. При большом GUI Scale поля профиля раскладываются в колонки и страницы. Справка разбита на информационные карточки. Проверены главный экран, городские категории, заработок, приключения, управление, безопасность, профиль, справка, нативные заказы/рынок/постройки и общие городские/личные вкладки.

Служебные действия доступны с клавиатуры через Tab и Enter. Page Up / Page Down и колёсико переключают локальные страницы. Переход назад использует прежний серверный токен. Правая кнопка, Shift, исходные предметы редкости и проверки аддонов сохранены. Длинные условия и большие списки используют прокрутку внутри своей области; навигационные сетки не создают лишнюю вертикальную полосу.

## Установка

1. Остановить Folia и закрыть игру. Сохранить папки настроек и данных.
2. Заменить `CraftoUI-Folia-26.2-0.8.17.jar` в `plugins/`.
3. Если Builds старее 0.8.39, заменить его на `NeverLandTownyBuilds-0.8.39.jar` из `release/addons/`. Если эта версия уже установлена, повторная замена не нужна. Не оставлять несколько версий одного плагина.
4. Заменить мод в `mods/` профиля GML на `CraftoUI-Fabric-26.2-0.8.17.jar`. Loader оставить 0.19.4.
5. Запустить сервер и игру. Проверить `/orders`, «Мои заказы», лимит, категории, профиль и превью внутри карточек нескольких зданий.

API JAR предназначен разработчикам; в `plugins/` его не устанавливать. Полная инструкция GML/Pterodactyl — [INSTALL.md](INSTALL.md).

Стандартные конфигурации обновляются с резервной копией. Сохраняется выбранная тема; произвольные пользовательские файлы не заменяются. Старые стандартные сетки с сохранёнными подписями и крупными ячейками уплотняются без изменения ID действий. Неизвестные API-макеты и явно выключенная адаптация не переписываются.

## Проверки этого выпуска

- Настоящие Fabric/Folia/API JAR собраны с оригинальными Minecraft 26.2, Fabric API и Paper API. JDK 25.0.2, Gradle 9.0.0, режим прямой компиляции `-PdirectMinecraft`; тестовые адаптеры не входят в JAR.
- **231 JUnit-тест**: 90 common и 141 server, без ошибок и пропусков. В том числе миграция профиля/справки, сохранение пользовательских файлов, уплотнение старого макета, локальные страницы, ограничения распознавания Board/DetailsHolder и неизменность произвольных API-экранов.
- **3848 проверок интерфейсов и ввода**: 1633 проверки городских/личных/командных/финансовых экранов, 1196 проверок конфигурационных и нативных меню, 914 новых проверок плотности/подсказок/служебных кнопок/выравнивания, 78 проверок меню зданий/превью, 27 проверок управления размещением.
- **579 PNG** из настоящего кода отрисовки с тестовыми данными. Две темы; основные логические размеры GUI: 829×563, 620×400, 520×340, 320×240, 320×180. Дополнительная проверка построек использует 900×600, 520×340 и 320×180.
- Проверено отсутствие вертикального хвоста у всех стандартных конфигурационных меню, сохранение текста и действий при перелистывании, постоянная доступность «Моих заказов»/лимита, исходный raw slot при клике и клавиатуре, отсутствие операции при чтении лимита, границы подсказок, цвет редкости и награды, совпадение отступов заголовка/подзаголовка.
- Настоящий Knot с Loader 0.19.4 выбрал CraftoUI 0.8.17 и MixinExtras 0.5.5. ContainerEventHandler преобразован успешно. Тестовый preLaunch завершает процесс до игрового окна. Upstream-регрессия MixinExtras отдельно воспроизведена на 0.5.4 и проходит на 0.5.5.
- SHA-256, метаданные, соответствие классов JAR результатам компиляции, отсутствие тестовых классов и целостность полного ZIP проверяются при упаковке. Результаты, XML и PNG — `validation/0.8.17/`.

Builds 0.8.39 не изменялся и не пересобирался: включён исходный бинарный файл из комплекта Placement Preview. SHA-256 совпадает с ранее проверенным на Folia файлом: `278f99a58bfe4ef1579f65d4c9f29d969a1a70e359c69a1fcb4dbeba221d08c5`. Исторические проверки этого аддона находятся в `validation/placement-preview-0.8.15/`; они отделены от проверок текущего выпуска.

## Ограничения

Полный графический Minecraft, сборка NLT/GML пользователя и живой Folia в этом прогоне не запускались. UI-проверки используют явные адаптеры платформы, инвентаря и транспорта; PNG не являются скриншотами игрового подключения. Платежи и все бизнес-ветви аддонов повторно не проходились.

Превью строится из настоящего плана Builds в окне подробностей здания. Для пользовательского объекта нужен существующий чертёж; фиктивная модель не подставляется. Длинная подсказка ограничивается окном, полное описание доступно через «Ещё». На очень малом GUI данные могут занимать несколько страниц. Мод остаётся опциональным; механизм подключения в этом выпуске не менялся.
