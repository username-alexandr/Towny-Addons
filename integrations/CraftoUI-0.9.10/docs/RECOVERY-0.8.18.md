# CraftoUI 0.8.18 — возврат, обновление и закрытие

Исправлен общий городской экран Civic: история города, казна, стройки, материалы, цели, приглашения и страницы подбора заказов. Заменить **оба JAR CraftoUI** — клиент и сервер — и полностью перезапустить игру и Folia. Fabric Loader **0.19.4** остаётся. Minecraft 26.2, Java 25, Fabric API 0.161.0+26.2 и вложенный MixinExtras 0.5.5 сохранены. Сторонние аддоны для этого исправления обновлять не требуется.

## Причина

При потере актуального токена кнопка «Обновить» отправляла обычное перелистывание с тем же устаревшим токеном. Сервер снова отказывал. «Назад» и Esc использовали один обработчик: в истории/казне он всегда пытался выполнить серверный переход, даже если страница была открыта напрямую и серверной истории переходов не было. Поэтому ошибка блокировала обычный выход. Дополнительно номера запросов начинались заново в каждом окне: задержанный ответ старого окна мог совпасть с номером нового.

## Изменения

- «Обновить» запрашивает новое состояние доверенного серверного маршрута. Для восстановления не нужен старый токен; маршрут, объект и команды из запроса клиента не принимаются. Сервер заново проверяет права, город и актуальные данные, выдаёт новый токен и таблицу действий.
- «Назад» проходит по сохранённой сервером истории. При прямом открытии корневой страницы возвращает в фактическое родительское меню. Если родителя нет, закрывает окно. Backspace выполняет то же действие.
- Esc и крестик в заголовке сразу закрывают окно до игрового мира, в том числе при ожидании ответа, ошибке токена, потере прав и тайм-ауте. Для выхода не требуется подтверждение сервера.
- При выходе отменяются ожидающие запросы и одноразовое подтверждение, освобождается сессия родительского меню. Явно закрытое окно не сохраняется для автоматического возврата из аддона.
- Возврат из меню аддона получает новое состояние. Номера запросов уникальны между экземплярами Civic; запоздавшие ответы не подменяют новое окно.
- Ошибка подтверждения освобождает «Обновить»; закрытие/возврат не выполняет подтверждаемую операцию.
- Серверные сообщения об отмене родительской сессии теперь доходят и до открытого Civic. При перезагрузке конфигурации скрытое родительское меню не остаётся рабочим на клиенте.

`act`, `confirm`, фильтры и серверные страницы по-прежнему требуют текущий токен. Действия проверяются сервером. Восстановление и возврат меняют только навигацию; они не принимают клиентские команды, суммы или ID объектов. Закрытие не отменяет операцию, которую сервер уже успел выполнить.

## Установка

1. Закрыть игру и штатно остановить Folia через Pterodactyl. Сохранить папки настроек и данных.
2. Заменить прежний CraftoUI в `plugins/` на `CraftoUI-Folia-26.2-0.8.18.jar`. Оставить один JAR этого плагина.
3. В GML/Crafto Launcher заменить мод профиля NLT на `CraftoUI-Fabric-26.2-0.8.18.jar`. Не оставлять старую копию. Loader оставить **0.19.4**.
4. Запустить сервер и игру. Старые пользовательские конфигурации и данные сохраняются; новых настроек для исправления не требуется. Bukkit `/reload` не использовать.
5. Проверить историю города: «Обновить», «Назад», Esc и крестик. Открыть подробности события и проверить возврат на прежнюю страницу. Проверить обновление после `/craftoui reload`.

API JAR из полного архива предназначен разработчикам; в `plugins/` не устанавливать. Builds 0.8.39 в `release/addons/` оставлен без изменения из предыдущего комплекта: для текущего исправления его повторно менять не нужно. Подробная инструкция GML/Pterodactyl — [INSTALL.md](INSTALL.md).

## Фактически выполненные проверки

- Настоящая сборка Fabric/Folia/API на JDK 25.0.2 и Gradle 9.0.0 с оригинальными зависимостями Minecraft 26.2, Fabric API и Paper API (`-PdirectMinecraft`). Тестовые адаптеры в JAR не входят.
- **239 JUnit-тестов**: 90 common и 149 server, без ошибок и пропусков. Восемь новых тестов используют тот же обработчик состояния и токенов, что сервер: восстановление, серверная история, сброс действий/подтверждений, инвалидирование асинхронных загрузок, запрет поддельного токена и повторения старых действий.
- **80 новых проверок Civic** через настоящий `CivicScreen` с явными адаптерами UI и сети. Размеры GUI: 960×500, 520×340, 320×240, 320×180. Проверены устаревший токен, обновление после ошибки, корневой и вложенный возврат, Esc во время ожидания, крестик, тайм-аут, просроченное подтверждение, Backspace, поздний ответ после закрытия и между окнами, возврат из аддона.
- Тот же тест запущен на исходном `CivicScreen` из выпущенного архива 0.8.17: он ожидаемо останавливается на неверном запросе обновления после ошибки токена. На 0.8.18 проходит. Это воспроизведение через тестовый транспорт, а не запись с сервера пользователя.
- Повторно пройдены **1633 существующие проверки** городских, личных, командных и финансовых экранов. Вместе с новыми — **1713 проверок** и **343 PNG** из рабочего кода отрисовки с тестовыми данными; обе темы. Старый тест Back обновлён для нажатия именно кнопки «Назад»: Esc теперь отдельно закрывает окно.
- Настоящий Knot выбрал Fabric Loader **0.19.4**, CraftoUI **0.8.18**, MixinExtras **0.5.5**, Minecraft **26.2**. `ContainerEventHandler` преобразован. Тестовый preLaunch завершает запуск до игрового окна.
- При упаковке проверены CRC, SHA-256, версии обоих JAR, зависимости клиента, вложенный MixinExtras, соответствие классов JAR результатам компиляции, исходники в полном ZIP и отсутствие тестовых/платформенных классов в CraftoUI JAR.

Логи, XML и изображения текущего прогона: `validation/0.8.18/`. Исторические проверки 0.8.17 и других выпусков сохранены отдельно и не считаются новым игровым прогоном.

## Ограничения

Полный графический Minecraft, пользовательская сборка NLT/GML и живой Folia в этом прогоне не запускались. UI/сеть проверены через явные адаптеры; бизнес-операции сторонних аддонов и платежи заново не прогонялись. Если сервер недоступен, получить новые данные нельзя, но Esc и крестик закрывают окно локально. Для новых запросов восстановления требуется сервер CraftoUI 0.8.18 вместе с клиентом 0.8.18. Мод остаётся опциональным; механизм входа игроков без мода не менялся.
