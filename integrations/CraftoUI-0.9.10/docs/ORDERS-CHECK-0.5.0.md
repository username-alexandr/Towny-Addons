# Принятие и отмена заказов — дополнительная проверка 0.5.0

Дата: **22 октября 2026 года, МСК**. Проверены те же выпускные JAR 0.5.0, без изменения кода или пересборки. Хеши и результаты — `validation/orders-check-0.5.0/results.json`.

На отдельном локальном стенде с настоящими Minecraft/Fabric и Folia выполнены семь сценариев. Тестовый игрок CraftoOrders050 принимал заказы через реальные карточки `/orders`, отменял через чат. Данные аддона вручную не менялись; выплаты не выполнялись.

| Проверка | Результат |
|---|---|
| Клик по «Овощи для столовой» | Создан один ACTIVE-заказ, на HUD «Морковь, 0 / 64» |
| Нажатие «Отменить» в чате | Подставлена команда, до Enter заказ остаётся ACTIVE |
| Отправка команды Enter | Состояние CANCELLED, сообщение «Отменён без штрафа», HUD исчез |
| Повторное принятие того же шаблона | Штатный отказ аддона до обновления доски; нового заказа нет |
| Принятие другого заказа после отказа | «Камень для сельских дорог» принят, HUD «Булыжник, 0 / 128» |
| Повторный клик по уже принятому заказу | Дубликат не создан, на сервере ровно одна запись этого заказа |
| Вторая отмена и повторное открытие /orders | Оба заказа отменены, меню снова открывается, клиент отвечает |

**Зависание в этом прогоне не воспроизвелось.** Оба процесса штатно остановлены после проверки. Подтверждения — снимки, клиентский/серверный журналы, снимки только тестовых записей и список выполненных действий в `validation/orders-check-0.5.0/`.

## Что может выглядеть как отсутствие реакции

- Исходный Contracts 0.3.21 после принятия оставляет доску открытой. Подтверждение отправляется в чат; HUD виден после закрытия меню.
- Ссылка «Отменить» подставляет `/orders cancel <UUID>`; для подтверждения нужно нажать **Enter**. Это штатное подтверждение исходного аддона.
- Отменённый заказ нельзя снова принять с той же ежедневной доски. Проверенный аддон сообщает о новой доске после **00:00 МСК**. Можно выбрать другой доступный заказ.
- При ручном выборе закреплённых заданий новый заказ не появляется на HUD автоматически: **K → Контракты → «+»** либо переключить «Показывать: все».

Это проверка локальной связки, а не диагностика рабочего сервера пользователя. Если зависает именно игра или сервер, для поиска причины нужны журналы соответствующего запуска. Старые 61 JUnit-тест и 38 протокольных сценариев не объявляются новым прогоном: в этом дополнении добавлены семь графических сценариев, JAR не менялись.
