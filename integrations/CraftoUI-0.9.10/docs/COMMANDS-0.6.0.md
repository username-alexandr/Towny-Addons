# Действия аддонов — 0.6.0

## Открытие и выполнение

- M → «Действия» — все разрешённые установленные аддоны.
- K → «Действия» — тот же каталог из быстрого доступа.
- В карточном меню аддона — кнопка «Действия». F7 работает также в режиме инвентаря.
- `/craftoui actions` — открыть каталог командой.

Выберите модуль, затем готовое действие. Заполните поля по порядку: варианты сервера можно нажимать, ник можно вводить вручную. Для выбора игрока показываются доступные онлайн-игроки и жители собственного города, включая офлайн-жителей. Введите начало ника, чтобы сузить список. Выберите «Проверить действие», сверяйте итоговую команду и подтвердите. Esc из подтверждения возвращает к редактированию без выполнения.

Входящие приглашения можно открыть действием «Мои приглашения»: выберите компанию по названию и подтвердите вступление в её настоящем меню. Форма «Принять приглашение» также поддерживает ввод ID компании.

49 готовых форм охватывают компании, министров, совет, армейские назначения и городские приглашения/должности. Для каждого зарегистрированного корня любого из 40 аддонов есть карточка `/команда · все команды`: можно ввести любую поддерживаемую подкоманду и её параметры, пользуясь настоящим TabCompleter аддона. Повторное нажатие варианта дописывает следующий аргумент. Если подсказок нет, используется ручной ввод внутри UI; синтаксис отображается внизу и полностью в подсказке при наведении.

Успех операции определяет исходный аддон. Его системные сообщения показываются в панели ответа и остаются в чате. При открытии настоящего инвентарного подтверждения компании CraftoUI преобразует его штатным мостом; его подтверждение также требуется. Важные действия исходных аддонов не подтверждаются автоматически.

«Назад»: подтверждение → форма → действия модуля → список модулей. «В меню» возвращает в экран, из которого открыты действия. Если открывали из инвентаря, заново открывается корневое меню аддона; старый редактор не восстанавливается из кэша.

## Серверная конфигурация

Файл `plugins/CraftoUI/command-ui.json` появляется при обновлении. `/craftoui reload` атомарно применяет изменения вместе с остальными конфигурациями; ошибочный файл оставляет предыдущую рабочую версию.

```json
{
  "modules": [{
    "plugin": "NeverLandTownyCouncil",
    "label": "Совет",
    "permission": "neverlandtownycouncil.use",
    "forms": [{
      "id": "appoint",
      "label": "Назначить министра",
      "root": "townycouncil",
      "prefix": "appoint",
      "fields": [
        {"id":"role", "label":"Должность", "type":"choice", "required":true,
         "choices":["economy","defense","construction","foreign"]},
        {"id":"player", "label":"Игрок", "type":"player", "required":true}
      ]
    }]
  }]
}
```

`plugin` — точное имя владельца команды из plugin.yml. `root` — каноническое имя команды, а не её алиас. Необязательный массив `roots` ограничивает перечень корней модуля; без него включаются все его зарегистрированные PluginCommand. `permission` у модуля и формы — дополнительные проверки; штатное право команды и бизнес-проверки аддона сохраняются. Пустой массив `forms` оставляет общий редактор всех команд плагина. Новый экран/форма не требует нового клиентского класса.

Типы полей: `player` (ник/UUID), `token` (один аргумент), `number` (десятичное число), `choice` (фиксированный список), `text` (текст с пробелами), `arguments` (произвольная последовательность аргументов). `text` и `arguments` допускаются только последними. Необязательные поля должны идти после обязательных. Корень и фиксированный префикс выбираются сервером; поля не могут заменить их. Для отсутствующего/отключённого модуля карточки не показываются.

Права: `craftoui.use` + `craftoui.commands`, оба по умолчанию доступны игрокам. LuckPerms работает через обычные Bukkit-проверки прав. Ранг, город, членство, состояние приглашения и транзакции проверяет исходный аддон при исполнении, даже если подсказка была получена раньше.

## Потоки, подтверждения и ограничения

Все запросы, подсказки и исполнение передаются в EntityScheduler игрока. Из UI нет консольного исполнения и прямого изменения баз аддонов. Фонового опроса команд каждый тик нет: подсказки запрашиваются после паузы ввода; действуют общий RateGate и отдельный предел подсказок.

Перед выполнением сервер проверяет владельца зарегистрированной команды, актуальный каталог, права, отсутствие предмета на курсоре и одноразовый 30-секундный билет. Билет хранит подготовленные аргументы только на сервере. Подмена аргументов в confirm игнорируется. Повторный confirm не выполняется. Отмена PlayerCommandPreprocessEvent соблюдается; переписанная другим плагином команда не исполняется без нового согласования.

Региональные действия и дополнительные подтверждения внутри обработчика остаются ответственностью аддона. Команды, разрешённые только консоли, не получают обход этого ограничения. Платежи требуют настроенной экономики. Полный перечень ограничений — в LIMITATIONS.md.
