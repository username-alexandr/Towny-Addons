# Проверки CraftoUI 0.5.2

Проверки выполнены 22 октября 2026 года. Исходники и результаты находятся в комплекте; журналы и снимки — `validation/ui-0.5.2/`.

## Сборка и автоматические проверки

- Java 25.0.2, Gradle 9.5.1; сборка `release` успешно завершилась. Клиент компилировался против настоящего Minecraft 26.2 через предусмотренный проектом `directMinecraft`, без заглушек.
- Fabric Loader 0.19.4, Fabric API 0.161.0+26.2, Paper API 26.2.build.121-stable.
- 74 JUnit-теста: common — 32, server — 42; 0 ошибок, пропусков и падений. XML-отчёты приложены.
- Новые проверки: геометрия 1–4 столбцов на ширине 288–720 GUI-единиц; кнопки и избранное внутри области, вместимость 49 разделов на широком экране; миграция economy.json, резервная копия и повторный запуск; сохранность пользовательского меню; соответствие кнопки orders серверной команде и праву; защита зарезервированных идентификаторов quick:.
- Проверены CRC JAR, наличие скомпилированных классов, версии мода/плагина, требование Loader >=0.19.4. В обеих локализациях конечного JAR присутствует `key.category.craftoui.menu = CraftoUI`.
- После исправления локализации повторно выполнен `release`; компиляция и тесты остались up-to-date, ресурсы клиента и JAR пересозданы. Журналы обеих успешных сборок приложены.
- В комплекте настоящий Gradle Wrapper 9.5.1 с закреплённой SHA-256 дистрибутива. Сборка в этой среде запускалась установленным дистрибутивом той же версии.

## Проверено в настоящем клиенте Minecraft 26.2

- Конечный Fabric JAR `bb8845190e6d68055022308750b3530310057e3fff7d186460c8394578d41db9` загрузился с Fabric Loader 0.19.4 и подключился к Folia с конечным серверным JAR.
- Путь `/menu open hub` → «Заработок» → «Личные заказы» открыл настоящий каталог `/orders` из NeverLandTownyContracts. Backspace вернул в «Заработок». Заказы и описания получены из аддона, не из макета.
- Сетка поиска после изменения размера игрового окна: 1600×1000 — четыре столбца; 1280×1000 — три; 1000×760 — два; 640×480 — один. Minecraft GUI Scale = 2. В минимальном окне проверены видимость нижней навигации и разбиение на страницы. Снимки всего виртуального экрана включают чёрную область за уменьшенным окном игры.
- Избранное: добавление, фильтр и сохранение закреплённого пункта после перезапуска клиента. Проверены на первой сборке 0.5.2 и сохранённый пункт повторно виден в конечной; между ними изменены только два JSON-файла локализации.
- В стандартном экране Minecraft «Назначение клавиш» фактически показано **CraftoUI**, четыре назначения M/K/H/J сохранены. Снимок `keybindings-category.png`.
- На запуске со стандартным economy.json из 0.5.1 автоматически добавлена кнопка; сохранённая резервная копия побайтно совпадает с исходным файлом.

## Границы проверки

Проверка выполнялась на изолированном localhost-сервере, без доступа к рабочему серверу пользователя. Использованы Folia 26.2 (26.2-DEV-14b7fee), Towny 0.103.2.0, NeverLandTownyBuilds 0.8.28 и NeverLandTownyContracts 0.3.21. bStats отключён до запуска. Клиент использует Xvfb и программный OpenGL.

Денежные операции, принятие/отмена/сдача заказов, все 38 аддонов и комбинации без мода/без серверного плагина заново не проверялись в 0.5.2. Эти обработчики и протокол не менялись; отчёты предыдущих выпусков обозначены собственными номерами версий. Неизменённый стандартный economy.json обновляется автоматически; авторские меню требуют ручного добавления кнопки по инструкции UI-0.5.2.md.

Один дополнительный запуск клиента завершён тестовым сценарием по тайм-ауту загрузки ресурсов, а не зарегистрированному крашу CraftoUI. Последующая проверка использовала больший Java heap. Журнал этого тайм-аута сохранён отдельно.
