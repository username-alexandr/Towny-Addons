# CraftoUI 0.9.8 — личные заказы и навигация

## Что изменилось

- Нажатие на предложение в подборе личных заказов сразу показывает предупреждение с названием, типом, редкостью, целью, инструкциями и наградой. Принятие происходит только после отдельного подтверждения; сервер повторно проверяет состояние заказа и права.
- Внутри «Моих заказов» кнопка «Назад» и Esc возвращают к предыдущему экрану, включая страницу списка. Если игрок пришёл из нативного меню `/orders`, выход из корня «Моих заказов» снова открывает это меню; если пришёл из подборки, возвращает в подборку. Серверный маркер входа не позволяет меню заказов подменить произвольной командой.
- Карточки каталога команд и параметров стали ниже; второстепенные описания уменьшены. Между стрелками страниц и разделителем появился зазор. Стандартные экраны используют общие размеры отступов и подписей.

## Установка

Замените клиентский `CraftoUI-Fabric-26.2-0.9.8.jar` и серверный `CraftoUI-Folia-26.2-0.9.8.jar`, удалив старые версии, и перезапустите клиент и сервер. Minecraft 26.2, Java 25, Fabric Loader **0.19.4**, Fabric API 0.161.0+26.2. Мод остаётся необязательным для подключения к серверу.

## Проверено

`./gradlew --offline release`: 328 JUnit-проверок, сборка обоих JAR и API. Контрольная загрузка через Fabric Knot 0.19.4 проверила MixinExtras 0.5.5 и трансформацию `ContainerEventHandler` до запуска окна. Полный запуск клиента с графикой и интеграционный игровой прогон с Folia и актуальным аддоном заказов в этом окружении не выполнялись; возврат в настоящий GUI `/orders` нужно дополнительно проверить на сервере.
