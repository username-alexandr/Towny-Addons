# Управление проекцией: Builds 0.8.33 + CraftoUI 0.8.1

Возьмите городской чертёж и нажмите ПКМ по земле, чтобы показать здание. Пока чертёж в основной руке и меню закрыто:

| Управление | Действие |
| --- | --- |
| ↑ / ↓ | Сдвинуть здание вперёд / назад относительно направления взгляда |
| ← / → | Сдвинуть здание влево / вправо |
| Колёсико вверх / вниз | Поднять / опустить здание |
| Shift + ПКМ | Повернуть здание |
| `/nltplace` | Открыть подтверждение места или отложить размещение |

Каждый шаг — один блок. Стрелки можно удерживать и переназначить в настройках управления Minecraft, раздел CraftoUI. В углу экрана появляются координаты и подсказка. Во время размещения колёсико меняет высоту; для смены предмета используйте клавиши 1–9. Без активного чертежа колёсико переключает предметы как обычно. Чат, инвентарь и другие открытые окна приостанавливают управление проекцией.

Место проверяется при каждом сдвиге. Стройка и списание денег начинаются только после отдельной кнопки «Подтвердить место и начать стройку». Уже начатые здания и улучшения существующих площадок этим способом не переносятся. Старое меню сдвига и поворота остаётся доступным без клиентского мода.

## Установка

Остановите сервер и игру. В `plugins/` замените старые Builds и CraftoUI на `NeverLandTownyBuilds-0.8.33.jar` и `CraftoUI-Folia-26.2-0.8.1.jar`. В клиентском `mods/` замените CraftoUI на `CraftoUI-Fabric-26.2-0.8.1.jar`. Удалите предыдущие JAR этих же плагинов/мода, чтобы не оставлять дубликаты. Запустите сервер и игру заново. Формат сохранений не менялся; конфигурации и данные сохраняйте.

Новые права не нужны: сохраняются `craftoui.use`, `neverlandtownybuilds.use` и прежние городские полномочия для подтверждения. В Builds добавлен необязательный параметр `settings.construction.placement.moves-per-tick: 512`; без изменения старого config.yml применяется тот же предел. Сдвиг переиспользует дисплеи, обновляя их частями.

## Проверки и ограничения

- Builds: 40 исполняемых smoke-проверок, 6 API-контрактов, 13 проверок сборочных скриптов.
- CraftoUI: 153 JUnit-проверки (65 common + 88 server), ошибок нет.
- Folia 26.2 build 7 / 14b7fee, Towny 0.103.2.0, Java 25.0.2: 85 утверждений за два запуска, включая сохранение после рестарта. Проверены направление взгляда, вертикальный сдвиг, повторные пакеты, ограничение частоты, повторное использование настоящих BlockDisplay, запрет управления без чертежа/прав и в открытом меню, согласование возможностей клиента и сервера.
- Игроки в серверной проверке имитируются; мир, сущности, регионы, Towny и сохранения настоящие. Ручное нажатие клавиш, прокрутка и внешний вид в запущенном Minecraft-клиенте не проверялись. Оплаченная стройка с реальным сторонним провайдером экономики и нагрузка населённого сервера остаются плейтестом.

Сценарий серверной проверки: `scripts/placement-runtime-probe/`. Отчёты, JUnit XML и журналы обоих запусков включены в каталог `validation/` пакета обновления.
