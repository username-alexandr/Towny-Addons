# CraftoUI 0.9.7 — расположение карточек и подсказки

В «Все действия» карточки начинаются после строки поиска с достаточным зазором. Надпись под названием стала меньше и располагается ближе к нему; она больше не выглядит отдельной пустой строкой. Стрелки страниц находятся над разделителем и не пересекают строку кнопок «Назад» и «Обновить».

В меню «Где найти нужное» однострочный заголовок выровнен по высоте с кнопкой «Назад». Наведение на информационные карточки показывает расширенное объяснение. Это работает и для установленного ранее файла справки без новых подсказок: в качестве объяснения используется текст карточки. Неизменённый `menus/help.yml` версии 0.9.6 и старый пример `config/menus/help.yml` обновляются с резервными копиями в `backups/`; пользовательский файл сохраняется.

Во всех экранах `NeverLandTownyControl` → «Панель администратора» содержательные пункты показывают название и мелкую строку из описания вместо предметной иконки. Служебные пункты из нижнего ряда исходного меню, включая «Как читать журнал», «Проверка операций», «Страница 1» и «Проверить журналы», вынесены в нижнюю полосу под разделителем. Наведение показывает полное описание из аддона. На узком окне видимые карточки ограничены двумя рядами, остаток доступен через «Ещё». Нажатие передаёт исходный слот аддону; права и результат действия остаются на его стороне.

Замените клиентский и серверный JAR CraftoUI версии 0.9.6 на 0.9.7 и перезапустите клиент и сервер. Старые копии JAR уберите. Для оформления административных меню нужны оба обновления. Совместимость: Minecraft/Folia 26.2, Java 25, Fabric Loader 0.19.4, Fabric API 0.161.0+26.2. Клиентский мод необязателен для входа на сервер.

Проверки: `./gradlew release`, модульные тесты, загрузка Fabric Knot до окна игры. Полный визуальный рендер и нажатия в работающем Folia-сервере в этой среде не проверялись.
