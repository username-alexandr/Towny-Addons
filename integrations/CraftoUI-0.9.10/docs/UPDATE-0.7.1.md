# CraftoUI 0.7.1 — история города и совместимость Builds

В экране города появилась отдельная кнопка **История города**. Она читает существующую летопись NeverLandTownyChronicles через публичный API `TownyChroniclesApi.entries(UUID)`; история казны остаётся отдельным разделом.

Список показывает события от новых к старым, дату и время UTC, категорию и участника. Нажатие открывает подробности и источник записи. Длинный текст переносится и разбивается на страницы; «Назад» возвращает на прежнюю страницу списка. «Обновить» сохраняет текущий раздел.

Доступны только записи текущего города игрока при наличии `craftoui.use`, `craftoui.city` и `townychronicles.use`. Сервер повторно проверяет город и права после загрузки данных. UUID события берётся из серверного списка действий. Отсутствие аддона/API или ошибка чтения показываются отдельно от действительно пустой истории. Файлы Chronicles не изменяются.

## Сообщение со скриншота

В 0.7.0 текст «Обновите Builds до 0.8.29 для перехода к конкретной стройке» появлялся при отсутствии публичного метода `uiOpenDetails(Player, String)` в фактически загруженном Builds. Это обычно означает старый JAR, но по одному скриншоту нельзя установить точную версию: другой вариант — сторонняя сборка без этого API.

0.7.1 проверяет метод заранее. У недоступного перехода показана фактическая версия Builds, а рядом доступна кнопка **Все постройки**, запускающая штатный `/town builds`. Поддержка определяется по методу, а не сравнению номеров версий. Вызов повторно проверяется на сервере.

Всплывающий дубль нижней строки был отдельной ошибкой CraftoUI: область наведения занимала всю ширину нижней полосы. Теперь подсказка появляется только над обрезанным текстом, переносится по ширине и ограничена высотой окна. Короткие подписи обычных кнопок не повторяются в подсказке.

## Установка

1. Полностью остановить сервер. В `plugins/` заменить CraftoUI на `release/CraftoUI-Folia-26.2-0.7.1.jar`. Удалить только прежний JAR CraftoUI; сохранить его папку данных.
2. Для переходов к отдельным стройкам заменить старый JAR NeverLandTownyBuilds на `release/addons/NeverLandTownyBuilds-0.8.29.jar`. Оставить один JAR этого плагина и сохранить папку данных. Если уже установлена более новая совместимая версия, откатывать её не требуется. Проверить загруженную версию командой `/version NeverLandTownyBuilds` после запуска.
3. Для истории города должен быть включён NeverLandTownyChronicles с API v1 и возможностью `entries` (исходники интеграции сверены с 0.1.18). Новый JAR Chronicles для этого изменения не требуется и в комплект не добавлялся. Проверить `/version NeverLandTownyChronicles` и права игрока. CraftoUI не восстанавливает события, которые Chronicles никогда не записывал.
4. В клиенте/GML заменить мод в `mods/` на `release/CraftoUI-Fabric-26.2-0.7.1.jar`. Minecraft 26.2, Java 25, Fabric Loader 0.19.4+ и Fabric API 0.161.0+26.2. Оба CraftoUI обновляются вместе для правильного вывода подробностей. Запустить сервер и клиент заново; горячая перезагрузка плагинов не нужна.

В Pterodactyl эти замены выполняются при остановленном сервере через файловый менеджер. API JAR предназначен разработчикам, его не нужно класть в `mods/` или `plugins/`.

Комплект сохраняет Builds 0.8.29, Contracts 0.3.23 и Companies 0.1.15 из 0.7.0 без изменения их байтов. История источников этих аддонов: https://github.com/username-alexandr/Towny-Addons/tree/codex/craftoui-0.7.0-integrations .

## Ограничения

- Источник истории — события, сохранённые Chronicles. Это не полный журнал всех команд сервера и не банковская история.
- Отображаются до 10 000 последних записей города. При превышении лимита интерфейс сообщает об этом.
- Для защиты лимита сетевого пакета очень длинная запись сокращается с явной пометкой; исходная запись в Chronicles сохраняется. Время явно отмечено как UTC.
- Проверки 0.7.1 перечислены в `TESTS-0.7.1.md`. Исправления этой версии ещё не проверены запуском игрового клиента/сервера; материалы реальных игровых тестов 0.7.0 являются историческими.
