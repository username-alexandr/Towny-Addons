# CraftoUI 0.8.19

Подсказка размещения здания слева сверху показывает, как открыть существующее меню: **Shift + ПКМ чертежом** или **`/nltplace`**. В меню остаются перемещение, поворот, осмотр и отдельное подтверждение установки.

Стрелки больше не регистрируются как управление чертежом. Колесо не перехватывается: обычное переключение ячеек и прокрутка окон сохраняются. Клиент не отправляет старые команды перемещения. Сервер CraftoUI также игнорирует эти сообщения, а Builds 0.9.1 запрещает старый публичный путь перемещения. Поэтому обновление только клиента не считается серверной защитой.

Установите клиентский и серверный CraftoUI **0.8.19**, Builds **0.9.1**, Contracts **0.5.1**, SiegesPlus **0.6.1**. Остановите сервер перед заменой JAR; конфиги и данные сохраните. Старые клиенты с новым сервером не получают прежний режим стрелок/колеса; для новой подсказки нужен новый клиент. Мод остаётся необязательным — штатное меню доступно командой `/nltplace`.

Версия основана на полных исходниках CraftoUI 0.8.18. Прочие экраны и исправления загрузчика сохранены. `CraftoUI-API` предназначен разработчикам, не для `plugins`.

Проверка: клиент, сервер и API собраны JDK 25.0.5 на настоящих библиотеках Minecraft/Fabric/Folia. Пройдены **90** общих и **149** серверных JUnit-тестов, **18** проверок производственного класса подсказки с явно выделенными адаптерами Minecraft/ввода/транспорта. Полный графический клиент не запускался. Adapters не включены в JAR. Серверные игровые операции и сохранение отдельно проверены на настоящем Folia 26.2 в комплекте NeverLandTowny 0.51.0.

Клиент сохраняет вложенную MixinExtras 0.5.5 и требования Fabric Loader >= 0.19.4, Fabric API >= 0.161.0+26.2. Анимации и прочие функции не менялись.
