# CraftoUI 0.9.9 — отчёт проверки

- `./gradlew --offline cleanTest release` на Java 25: успешно. JUnit: 95 тестов common и 238 server, 0 ошибок.
- Каталог Builds из NeverLandTownySuite 0.52.6: 90 зданий; 89 имеют требования, единственный исходный узел — ратуша. Тест проверил ссылки, уровни и отсутствие циклов. Полностью открытый город вместе с семью исследовательскими узлами укладывается в лимит сообщения протокола.
- `NeverLandTownyBuilds-0.11.4-CraftoTree.jar` получен заменой **только** встроенного `projects.yml` исходного Builds 0.11.4; остальные записи JAR сравнивались побайтно, ZIP проверен.
- Тестовый запуск Knot загрузил Fabric Loader 0.19.4, CraftoUI 0.9.9, MixinExtras 0.5.5 и преобразовал `ContainerEventHandler` до открытия игрового окна.
- Код аддона Builds 0.11.4 проверяет `requires` при начале строительства; старый установленный `projects.yml` наследует отсутствующие требования из встроенного каталога, а явно указанные условия сохраняют приоритет. Клиентское дерево применяет тот же порядок источников.

Не выполнены: запуск полного клиента в мире, подключение к живому Folia 26.2, реальные перемещения предметов на складе, полный цикл стройки/исследования, проверка цен и прав Towny на конкретном сервере. Графика склада использует родные слоты и транзакции инвентаря; фактическую работу нужно проверить с установленным аддоном. Открытие рынка и других возможностей прямыми командами регулируют соответствующие серверные аддоны; два узла рынка в дереве пока отражают зависимости UI, а не новую глобальную систему запрета команд.
