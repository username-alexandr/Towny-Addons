# CraftoUI 0.8.20: рабочая серверная правка

Карточки личных рыболовных заказов выводят правила водоёма и общего запаса из `uiSnapshot` Contracts 0.6.0. Поле необязательное: прежние задания и совместимость со старым Contracts сохраняются. Сервер 0.8.20 работает с клиентом 0.8.19; сетевой протокол прежний.

Патч применяется в корне исходников CraftoUI 0.8.19. Полные исходники и собранный сервер сохранены отдельно вместе с прежним клиентом. Компиляция против настоящих Folia/Minecraft 26.2 зависимостей и 239 JUnit-тестов пройдены. Графический клиент не запускался. Это часть рабочей ветки, не полный релиз городских систем.
