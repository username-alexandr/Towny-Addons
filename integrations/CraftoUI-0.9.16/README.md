# Карта расширения: CraftoUI Folia 0.9.16

Патч `claim-chain.patch` применяется к исходникам **CraftoUI Fabric 0.9.17 / Folia 0.9.15**. Он не заменяет изменения интерфейса клиента 0.9.17: обновляется только серверный модуль до 0.9.16.

При выборе свободного участка в карте CraftoUI мэр или заместитель с правом расширения должен находиться на земле своего города. Кнопка открывает карту планов NeverLandTownyStick 0.2.5 с фокусом на выбранном участке. Для удалённого участка игрок выбирает цепочку свободных участков от границы города; одиночный удалённый участок не оплачивается и не захватывается.

`ClaimService` повторно проверяет роль, права Towny согласно `claim.respect-towny-claim-permissions`, смежность всей цепочки, лимит, экономику и стоимость при создании и исполнении плана. CraftoUI не дублирует на своей кнопке настройку права Towny: это проверяет Stick по действующей конфигурации сервера.

Применение в корне распакованного архива CraftoUI:

```bash
patch -p1 < claim-chain.patch
```

Проверено: Gradle `:server:test :server:jar :api:jar` на Java 25; 249 серверных JUnit-тестов, ошибок нет. Живой Folia/Towny/Vault следует проверить перед выкладкой игрокам.
