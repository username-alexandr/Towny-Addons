# Отчёт проверки NeverLand Towny Suite 0.6.0

- Все 14 модулей проверяются GitHub Actions на Java 25; итог фиксируется перед публикацией релиза.
- NeverLandTownyBuilds компилируется вместе с отдельными smoke-тестами моделей, геометрии, локализации и муниципального расширения.
- Проверяются 78 обычных проектов, 5 Чудес Света, 7 категорий и 16 новых пятистадийных физических моделей.
- Конфигурационный тест дополнен разбором 59 YAML-файлов.
- Проверяется уникальность Bukkit-команд и алиасов между модулями.
- Для каждого JAR проверены `plugin.yml`, версия, главный класс и целостность архива.
- В JAR не упакованы классы Paper, Towny, Adventure или PlaceholderAPI.
- В байткоде новых JAR нет ссылок на несовместимый `LegacyComponentSerializer`.
- В пользовательской справке не осталось старых `/mint...`, `/nlt...` и `/townstick`; они присутствуют только как алиасы совместимости и в истории изменений.

Дополнительно исходники проходят релизную матрицу: версии модулей, число YAML-файлов, состав JAR/ZIP и отсутствие циклических зависимостей в `plugin.yml`.
