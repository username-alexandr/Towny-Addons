# Отчёт проверки NeverLand Towny Suite 0.7.0

- Все 14 модулей собираются GitHub Actions на Java 25 с целевым bytecode Java 17.
- NeverLandTownyBuilds проходит 14 исполняемых smoke-тестов моделей, геометрии, локализации, ресурсов, совместимости и муниципального расширения.
- Подтверждены 78 обычных проектов, 11 Чудес Света, 7 категорий и 89 физических проектов.
- Все 11 Чудес проверяются на уникальную геометрию, фундамент, лестницы, проходимые двери, ручные несущие блоки и автоматическую отделку.
- Повторно проверяются 37 импортированных моделей: 185 стадий и 25 497 блоков.
- Archaeology содержит 28 артефактов, 10 коллекций и требования для всех 11 Чудес.
- Конфигурационный тест разбирает 59 YAML-файлов и сверяет версии 14 модулей.
- Проверяются уникальность Bukkit-команд, целостность JAR, `plugin.yml`, главный класс и отсутствие циклов загрузки.
- В JAR не упаковываются классы Paper, Towny, Adventure или PlaceholderAPI.

Публикация релиза выполняется только после успешного прогона Verify для PR, повторной проверки основной ветки и отдельной сборки релизной ветки.
