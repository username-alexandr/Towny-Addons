## Suite 0.7.8 — 9 сентября 2026

Локально успешно собраны Builds 0.7.6, Events 0.2.0 и Expeditions 0.1.9 на Java 25 / Gradle 9.0.0 с Paper API 26.2.build.121-stable. Пройдены все smoke-задачи этих модулей. Пакет из 14 JAR проверен scripts/verify_release.py: имена, версии, целостность, зависимости и совпадение русских словарей с исходниками.

Каталог: 79 зданий и 11 чудес, 406 уровней. Проверены стадии, ресурсы и сохранение прежних архитектур. Для 26 импортированных моделей добавлено 1937 опорных/стеновых блоков; исходные 25 497 координат сохранены. Итоговый объём 37 импортированных моделей — 27 434 блока. Дополнительно закрыты стеклянные фронтоны и изменён порядок строительства фронтонов обычных домов. Контрольные срезы мельницы, собора, теплицы и Хрустального дворца сопоставлены с прежней геометрией; обнаруженный дефект отдельных фронтонов включён в исправление.

Регрессии: различимые иконки и миграция старого конфига; права экспедиций и их отзыв; сохранение, расходование и граница срока возврата; 18 лет включительно, неизвестный/неверный возраст, права офицера, принадлежность к городу, наличие штаба, повторная мобилизация и лимит мест. Модель состояния рейда проверена на 10 усиливающихся волнах и 100 смертях: повторные смерти, поставки до завершения, перезапуск на пятой волне, запрет 11-й волны и замена старого префикса.

Границы: тесты не запускали мир пользователя, не рендерили модели ModelEngine/ItemsAdder в Minecraft и не проверяли конкретный плагин паспорта. Эти интеграции используют публичные API и собственные ID/placeholder администратора; см. [инструкцию обновления](UPDATE_0.7.8_RU.md).

# Отчёт проверки NeverLand Towny Suite 0.7.2

- Все 14 модулей собираются GitHub Actions на Java 25 с целевым bytecode Java 17.
- NeverLandTownyBuilds проходит 15 исполняемых smoke-тестов моделей, геометрии, локализации, ресурсов, совместимости, миграции требований и муниципального расширения.
- Тесты ресурсов отдельно проверяют одинаковый результат подсчёта, списания и фонда для ванильного материала со служебными компонентами, а также изоляцию ItemsAdder/NBT-предметов.
- Подтверждены 78 обычных проектов, 11 Чудес Света, 7 категорий и 89 физических проектов.
- Все 11 Чудес проверяются на уникальную геометрию, фундамент, лестницы, проходимые двери, ручные несущие блоки и автоматическую отделку.
- Для всех 11 Чудес проверяются точные наборы из трёх существующих городских зданий и требуемые уровни — всего 33 инфраструктурных условия.
- Повторно проверяются 37 импортированных моделей: 185 стадий и 25 497 блоков.
- Archaeology содержит 28 артефактов, 10 коллекций и требования для всех 11 Чудес.
- Конфигурационный тест разбирает 59 YAML-файлов и сверяет версии 14 модулей.
- Проверяются уникальность Bukkit-команд, целостность JAR, `plugin.yml`, главный класс и отсутствие циклов загрузки.
- В JAR не упаковываются классы Paper, Towny, Adventure или PlaceholderAPI.

Публикация релиза выполняется только после успешного прогона Verify для PR, повторной проверки основной ветки и отдельной сборки релизной ветки. Отдельно проверяются миграция отсутствующих `requires` и единое распознавание `DEEPSLATE_TILES` в фонде строительства.
