# Отчёт проверки NeverLand Towny Suite 0.6.0

- Все 14 модулей успешно собраны GitHub Actions на Java 25 в прогоне Verify №21.
- NeverLandTownyBuilds прошёл 14 исполняемых smoke-тестов моделей, геометрии, локализации, ресурсов, совместимости и муниципального расширения.
- Подтверждены 78 обычных проектов, 5 Чудес Света, 7 категорий, 16 новых физических моделей и 80 их стадий.
- Повторно проверены 37 импортированных моделей: 185 стадий, 25 497 блоков и 46 полных дверей.
- Словарь покрывает все 145 материалов, используемых физическими чертежами.
- Конфигурационный тест дополнен разбором 59 YAML-файлов.
- Проверена уникальность Bukkit-команд и алиасов между модулями.
- Для каждого JAR проверены `plugin.yml`, версия, главный класс и целостность архива.
- В JAR не упакованы классы Paper, Towny, Adventure или PlaceholderAPI.
- В байткоде новых JAR нет ссылок на несовместимый `LegacyComponentSerializer`.
- В пользовательской справке не осталось старых `/mint...`, `/nlt...` и `/townstick`; они присутствуют только как алиасы совместимости и в истории изменений.

Релизная матрица также успешно проверила версии 14 модулей, 59 YAML-файлов, состав JAR/ZIP и отсутствие циклических зависимостей в `plugin.yml`.
