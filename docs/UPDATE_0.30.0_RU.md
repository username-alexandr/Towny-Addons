# 0.30.0 — городской суд и розыск

Добавлен отдельный NeverLandTownyJustice 0.1.0. Комплект содержит 33 аддона; Council обновлён до 0.1.5. Платформа: Paper/Purpur 26.2, Towny 0.103.2.0, Java 25. Объединять плагины или переносить существующие данные не требуется.

## Установка

Остановите сервер, сохраните резервную копию `plugins`, добавьте Justice и замените Council 0.1.4 на 0.1.5. Удалите старый JAR Council. Остальные версии не изменились. Можно установить полный комплект из релиза. Перезапустите сервер без `/reload`.

В существующем `NeverLandTownyCouncil/config.yml` добавьте `neverlandtownycouncil.action.justice` в `roles.defense.permissions`, если министр обороны должен управлять судом. Пользовательские назначения прав автоматически не изменяются. Новые установки Council уже содержат этот узел. Мэру назначение министра не требуется.

## Возможности и команды

Вход: `/t justice` или `/justice`. Меню разделяет личные штрафы, публичный розыск и дела города. Светлые заголовки, разные иконки, короткие описания, страницы и возврат в предыдущее меню используют общий MenuStyle.

| Команда | Действие |
|---|---|
| `/justice fines` | Свои неоплаченные штрафы |
| `/justice wanted` | Действующий обеспеченный розыск |
| `/justice case <ID>` | Состояние дела и платежей |
| `/justice pay <ID>` | Подтверждённая игроком оплата своего штрафа |
| `/justice capture <ID>` | Задержание рядом с целью в городе, объявившем розыск |
| `/justice cases` | Все дела своего города для мэра или суда |
| `/justice fine <игрок> <сумма> <причина>` | Назначить штраф зарегистрированному игроку Towny |
| `/justice warrant <игрок> <награда> <часы> <причина>` | Объявить розыск с заранее оплаченной наградой; 0 разрешает розыск без награды |
| `/justice cancel <ID>` | Отменить неоплаченный штраф или действующий розыск |
| `/justice release <ID>` | Освободить заключённого по делу, включая незавершённую доставку |
| `/justice prison create <имя>` | Создать тюрьму на обычном муниципальном участке под собой |
| `/justice prison bind <имя>` | Подключить существующую тюрьму Towny |
| `/justice prison unbind <имя>` | Убрать тюрьму из Justice после освобождения заключённых; участок Towny остаётся |

ID можно сократить до однозначных первых восьми символов. Причина обязательна: 5–160 символов. По умолчанию штраф — до 10 000, награда — до 100 000, заключение — до 24 часов. Срок действия розыска — 7 дней, защита от новой награды за ту же цель в том же городе — 24 часа после поимки. Все пределы настраиваются.

Штраф — отдельное требование к игроку, а не автоматическое списание или автоматическое заключение за просрочку. Сумма поступает в свободный бюджет города только после подтверждения банковских операций. Штрафы видны должнику и суду города; розыск публичен. Мэр может назначить штраф зарегистрированному игроку, в том числе иностранцу.

## Поимка и тюрьма

Оба игрока должны быть в игре, живы, вне транспорта, в survival/adventure, в пределах города-инициатора и не дальше 4 блоков друг от друга. Самозадержание и новая поимка уже заключённого запрещены. Проверки повторяются после cancellable `JusticeCaptureEvent`, поэтому сторонний плагин может запретить задержание.

На тюремном участке не должно быть частного владельца. Точка камеры требует безопасного твёрдого пола и свободного места для игрока. Justice сохраняет UUID и намерение создания до регистрации тюрьмы Towny. Повторная обработка использует тот же UUID.

Заключение выполняет публичный `JailUtil` Towny. Залог, побеги, окончание срока и штатные ограничения перемещений остаются правилами Towny. Награда назначается только после подтверждения нативной тюрьмы, завершения очереди телепортации, физического появления игрока в камере и сохранения Resident. Сам флаг `isJailed` либо выход игрока этого не подтверждают. Неудачная доставка без заключения возвращает дело в розыск; сомнительное заключение ожидает подтверждения или освобождения судом.

## Деньги и восстановление

Награда заранее списывается из военного бюджета `army` через Treasury+. При отсутствии Treasury+ используется счёт Towny. Установленный, но недоступный Treasury+ блокирует финансовую операцию. Резерв — сохраняемое обязательство Justice, а не дополнительный банковский счёт. При отмене или истечении розыска резерв возвращается городу; после подтверждённой поимки он направляется зафиксированному охотнику. Выход охотника не теряет выплату.

Дело и намерение платежа сохраняются одним атомарным снимком. Перед каждым банковским вызовом сохраняется pending. Потерянный ответ разрешается наблюдаемой квитанцией Towny; если результат неизвестен, повторного списания или зачисления нет. Подтверждённый отказ зачисления повторяется с заданной задержкой. Повреждение YAML или ошибка записи приостанавливает изменения; исходный файл не перезаписывается пустой базой.

Администратор с `neverlandtownyjustice.admin` получает `/justice payments`, `/justice reload` и `/justice resolve <UUID платежа> <решение>`. Перед resolve необходимо сверить реальное движение счёта по метке `[justice:UUID]`. Решения: `debit-applied`, `debit-not-applied`, `credit-applied`, `credit-not-applied`. Выбирайте только подтверждённый результат; ошибочное ручное решение может создать лишнюю выплату. Reload обновляет настройки, но не разблокирует повреждённую базу — исправьте её при остановленном сервере и перезапустите.

Все суммы фиксируются в целых сотых. Предел журнала приостанавливает новые дела; старые записи автоматически не удаляются, чтобы сохранить финансовые доказательства. Синхронная запись всего снимка ограничивает масштаб; нагрузочный TPS-прогон в этот выпуск не входит.

## API и permissions

`TownyJusticeApi` v1: `healthy`, `caseFile`, `cases`, `wanted`, `fines`, `prisons`. Неизменяемые JDK-снимки, запросы только из серверного потока. API предназначено доверенным серверным плагинам и не фильтрует дела по игроку; UI и команды выполняют собственную проверку прав. Monetary API не принимает неаутентифицированные команды.

`neverlandtownyjustice.use` и `capture` по умолчанию доступны игрокам. `manage` дополнительно требует статуса мэра либо действующего назначения Council в том же городе. Один глобальный узел Council не заменяет назначение. `admin` по умолчанию только OP.

PlaceholderAPI: `%townyjustice_fines%`, `%townyjustice_fine_total%`, `%townyjustice_wanted%`. Для асинхронного запроса или недоступной базы возвращается `—`.

## Проверки

Три исполняемых smoke-набора покрывают четыре денежных потока, ошибки на каждой границе сохранения, потерянные ответы, задержку повторов, повреждение хранилища, согласованность резерва и матрицу условий поимки. Общий CI автоматически обнаруживает и запускает эти проверки вместе с прежними; API v1 внесён в baseline.

Воспроизводимый серверный сценарий: `scripts/justice-runtime-probe`. Он проверяет реальные Towny/Treasury/Council API, счета, штрафы, резерв и возврат награды, сохранение тюрьмы, незавершённое заключение и спорный платёж через настоящий перезапуск JVM. Подтверждённая поимка для банковского сценария задаётся как явно отмеченная тестовая запись. Подключённого Minecraft-клиента, визуальной проверки конкретного ресурспака и полного живого телепорта игрока в камеру в этом прогоне нет. Точные результаты сохранены в `docs/validation/0.30.0`.
