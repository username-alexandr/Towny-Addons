# NeverLandTownySuite 0.41.0 — Folia

Восстановленная сборка 40 аддонов для Paper/Purpur/Folia 26.2, Java 25 и Towny 0.103.2.0. Байткод аддонов остаётся Java 17; серверу 26.2 нужна Java 25.

## Что изменилось

- Вместо BukkitScheduler используются глобальный, региональный, асинхронный и сущностный планировщики Paper/Folia. Телепортации сущностей используют `teleportAsync`.
- Операции с игроком, его инвентарём, эффектами и правами направляются в его поток. Физические постройки, археология, огонь, лагеря, караваны и экспедиции проверяют владение регионом.
- Внутренние реестры аддонов защищены общим монитором между копиями общего ядра. Этот монитор не даёт права обращаться к чужому региону. Банковские наблюдатели и файловый аудит используют отдельную синхронизацию, чтобы не создавать взаимную блокировку со счетами Towny.
- При административном отключении группа зависимых аддонов сначала замораживается. Открытые хранилища закрываются в потоках игроков, затем модули завершают работу. Время отключения не засчитывается как провал; разрешённое включение применяется после перезапуска.
- Команды наград за события и здания сохраняются в `command-outbox.yml`. Перед внешним вызовом ставится `REVIEW`; при успешном возврате команды — `DONE`. После прерывания команда не повторяется автоматически.
- В `/nltadmin` добавлена отдельная кнопка «Команды наград». Администратор сверяет результат и выбирает закрытие записи или повтор. Доступна также `/nltoutbox <модуль> [UUID done|retry]` с административным правом или OP.

## Установка

1. Остановите сервер и сохраните резервную копию миров и каталога `plugins`.
2. Удалите предыдущие JAR этих 40 аддонов; установите новые из `dist/plugins`. Конфигурации и игровые данные оставьте на месте.
3. Используйте версии зависимостей с поддержкой Folia. Само наличие Vault или PlaceholderAPI не подтверждает совместимость подключённых к ним провайдеров и расширений.
4. Выполните полный запуск сервера. Проверьте `/nltmodules list`, `/nltadmin` и консоль.

## Особенности

- Постройка или сворачивание лагеря требует загруженного участка, которым владеет текущий регион. Если участок ещё не готов, действие отклоняется до списания; подойдите к месту и повторите его.
- В Ideologies режим валюты `COMMAND` на Folia отклоняет списание из регионального потока. Используйте `TOWN_BANK`, `PLAYER_VAULT` с совместимым провайдером или `ITEM`. Команда списания не запускается, успешная покупка не имитируется.
- `retry` для команды награды может повторить внешний эффект. Выбирайте его только после проверки у провайдера награды. `DONE` означает успешный возврат обработчика команды, а не независимое подтверждение результата стороннего плагина.
- Общий монитор обеспечивает последовательность внутренних операций; он ограничивает их параллелизм. Полная нагрузочная проверка на реальном населённом сервере не входит в автоматические проверки сборки.

Сводка фактически выполненных проверок поставляется в `docs/FOLIA_VALIDATION.md`. Сборочные и серверные проверки находятся в `scripts/build_suite.py` и `scripts/folia`.
