# Проверка 0.38.0

Перед публикацией выполнены проверки исходников, API и безопасных зависимостей: **38 аддонов**, **39 API-контрактов v1**, **37 управляемых игровых модулей** плюс Control. Девять Python-тестов средств сборки прошли.

Выборочная сборка Control, Policies и Quests прошла **6 исполняемых Java-тестов**. `QuestSmoke` включает **44 проверки**: порядок этапов, уникальные районы, связность и владение территорией, непрерывное снабжение, пауза, отмена, повторный запуск, отсутствие повторного завершения, повреждённая база, ошибка атомарной записи и сохранение снимка определения. После доработки учёта долей секунды Quests проверен повторно. В Policies проверяется переход старого конфига с шестью категориями на семь, блокировка незаработанной реформы, привязка открытия к городу и одновременное отключение бонуса и стоимости при недоступном Quests.

На отдельном **Purpur 26.2 build 2632 / Towny 0.103.2.0 / Java 25** прошли **29 проверок в первом JVM и 5 после рестарта**. Реальные Bukkit-инвентари, Towny-город и его территории использованы с настоящими сервисами Quests, Policies и Control. Проверены завершение водного этапа по серверным наблюдениям, открытие реформы, её +5 счастья и ×1,1 содержания, нейтральная отмена, отсутствие повторной награды и восстановление сохранённых проектов после остановки группы модулей и штатной команды включения.

Тестовые ответы публичных API Builds, Districts и Resources управляли доступностью зданий, свежестью расчёта, дефицитом воды и набором районов. Это проверка интеграции потребителей, а не строительства объектов или экономического баланса. В этой нативной проверке использованы кандидаты новых Control/Policies/Quests и опубликованные зависимости набора 0.37.0; точные версии и SHA-256 приведены в [перечне JAR](validation/0.38.0/quests-native-plugins.json). [Полная проверка Verify](https://github.com/username-alexandr/Towny-Addons/actions/runs/35475686259) прошла: 38 модулей, 124 исполняемых Java-теста, 9 Python-тестов и 39 API-контрактов. Исходники проверены на коммите `f4924ad70f3f46c8c9b35040273930333b136502`; последующая правка уточняет только этот отчёт и описание Policies в README. Publish release повторяет полную сборку и поставляет `suite-tests.json` в релизе.

Доказательства: [список нативных проверок](validation/0.38.0/quests-native-checks.txt), [первый запуск](validation/0.38.0/quests-native-first-passed.txt), [рестарт](validation/0.38.0/quests-native-restart-passed.txt), [выборочная сборка](validation/0.38.0/selected-suite-tests.json). Воспроизводимый сценарий находится в `scripts/quests-runtime-probe`.

Проверки не заменяют визуальную проверку клиентом Minecraft и нагрузочный тест с реальными игроками. Развёртывание на игровом сервере в эту работу не входило.
