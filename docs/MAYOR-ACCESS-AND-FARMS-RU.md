# Права жителей и работа ферм — обновление 24.10.2026

## Исправление Governance

В архив включён **NeverLandTownyGovernance 0.1.24**. В нём объединены новые проверки прав и меню назначения/снятия с должностей из отдельной приложенной сборки. Путь: **Политики города → Законы и совет → Городской совет**, либо `/governance council`. Выбор должности → «Назначить жителя» → житель → подтверждение. Для снятия выберите уже назначенного жителя.

Если предыдущий архив уже установлен, достаточно заменить только Governance. Удалите старый JAR этого плагина и перезапустите сервер; данные и конфиги оставьте. Если архив ещё не установлен, используйте инструкции полного обновления ниже.

## Для мэра

Откройте `/council`. Внизу появились кнопки **«Доступ жителей»** и **«Доступ должностей»**.

- **Доступ жителей:** выберите жителя, раздел и действие. Работает и для жителей, которые сейчас не в сети.
- **Доступ должностей:** выберите министра экономики, обороны, строительства или иностранных дел, затем действие.
- Левой кнопкой переключайте **«По умолчанию» → «Разрешено» → «Запрещено»**. Правая кнопка возвращает «По умолчанию».
- Личное правило жителя важнее правила должности. «По умолчанию» сохраняет обычные правила соответствующей городской службы.

Менять эти настройки может только действующий мэр своего города. Статус OP, административное право или доступ к консоли сами по себе не открывают редактор. Обычные административные команды служб остаются доступными администраторам.

Доступ проверяется при действии, в том числе при вводе команд. Открытое старое меню не позволяет бывшему мэру менять права. При выходе жителя его личные настройки удаляются; при смене мэра назначения и настройки прошлого состава сбрасываются. После обычного перезапуска настройки сохраняются.

Команды:

```text
/council access
/council access roles
/council access player ИМЯ
/council access role construction
/council access player ИМЯ storage_withdraw allow
/council access player ИМЯ build_cancel deny
/council access role construction build_resources allow
/council access player ИМЯ build_cancel default
/council history
```

### Настраиваемые действия

| Раздел | Действия |
| --- | --- |
| Строительство | Покупка и улучшение зданий; отмена; передача ресурсов склада стройке; установка блоков по чертежу; пополнение складов; получение со складов; управление районами; защита участков от мобов |
| Экономика | Бюджет; налоги; выгрузка финансовых отчётов; городская торговля; городские контракты; рынок; рабочие места |
| Безопасность | Армия; разведка; правосудие |
| Политика | Соглашения; санкции; предложения налоговых, строительных, идеологических и гражданских законов; политики города |
| Развитие | Специализация; городские проекты; награды достижений; содержание зданий |

Это 29 действий городских аддонов. Права на обычную установку и разрушение блоков, приём жителей и захват территории остаются в Towny. Законы по-прежнему требуют голосования. Требования гражданства, базовый доступ к командам служб и правила наказаний сохраняются. Доступ к управлению стройкой не означает бесплатную отмену: для жителей сохраняется установленная комиссия.

Покупка, отмена и передача ресурсов — отдельные настройки. Изначальные полномочия министра строительства сохранены; если требуется запретить ему все три действия, переключите все три.

## Зелья и раздатчики на фермах

Исправлена проверка Towny, из-за которой запрет PvP блокировал зелья и стрелы раздатчика против враждебных мобов.

Исключение работает, когда **раздатчик и моб находятся на участках одного города, где мобы разрешены**. Оба участка могут быть разными. Защищённый соседний участок и другой город не получают это исключение. Запреты PvP, огня и взрывов не переключаются; игроки, мирные мобы и NPC не подпадают под новое исключение. Запрет другой защиты, обработанный после этого исключения, продолжает действовать.

Используйте `/t farm allow` на участке фермы и подтвердите изменение. Если раздатчик стоит в соседнем участке, разрешите мобов и там. Посмотреть зоны можно через `/t farm list` и `/t farm show`.

Именно **раздатчик** бросает зелье. Обычный **выбрасыватель** выпускает предмет, поэтому лежащая бутылка не накладывает эффект. Обычные правила Minecraft сохраняются: яд не действует на нежить, мгновенный урон её лечит, а мгновенное лечение наносит ей урон. Для проверки на зомби удобно использовать взрывное зелье слабости.

В `NeverLandTownyDistricts/config.yml`:

```yaml
mob-farms:
  enabled: true
  dispenser-effects: true
```

Новый параметр включён по умолчанию, в том числе при использовании старого конфига. `false` возвращает прежние проверки раздатчиков. При выключенном модуле Districts или `mob-farms.enabled: false` новое исключение не действует; сохранённые настройки участков не удаляются.

## Установка

1. Остановите сервер и сохраните резервную копию `plugins` и данных Towny.
2. Замените JAR тех 17 модулей, которые есть в архиве. Удалите их предыдущие версии: в `plugins` должен остаться один JAR каждого имени.
3. Другие плагины оставьте установленными. Этот архив — обновление изменённых модулей, а не полный комплект сервера.
4. Каталоги с данными не удаляйте. Запустите сервер обычным перезапуском.
5. Проверьте `/council access` от мэра и раздатчик со взрывным зельем слабости на разрешённом участке.

Новый файл `NeverLandTownyCouncil/access.yml` хранит права и последние 500 изменений. Старый `council.yml` с назначениями не меняет формат. Ошибка записи останавливает выдачу делегированных прав до устранения причины и перезапуска; прежнее состояние не заменяется пустым.

Для LuckPerms достаточно существующего `neverlandtownycouncil.use` (по умолчанию доступно всем) для открытия совета. Право на редактирование определяется действующим мэром, отдельного узла для выдачи редактора постороннему нет. `neverlandtownycouncil.action.*` не следует вручную выдавать в качестве замены городским настройкам.

## Для интеграций

В API Council v1 добавлены `decision(town,resident,action)` → `ALLOW/DENY/DEFAULT`, `actions()`, `roleActions(town,role)` и `residentActions(town,resident)`. Старые методы сохранены. При проверке `DEFAULT` служба использует свои прежние правила. Вызовы выполняются под общей блокировкой SuiteState; работа с игроком и инвентарём — через его планировщик Folia.

Нативное меню Minecraft готово. Отдельный клиентский интерфейс CraftoUI этим обновлением не изменяется. Существующие точки интеграции CraftoUI для Builds и публичных заказов Contracts сохранены.

Результаты проверок находятся в `verification/`. Исходники пробных плагинов предназначены только для отдельного тестового сервера и не включаются в папку `plugins` релизного архива.
