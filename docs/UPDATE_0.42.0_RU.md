# NeverLand Towny Suite 0.42.0

Полный пакет из 40 аддонов для Folia/Paper/Purpur 26.2, Java 25 и Towny 0.103.2.0. Точная матрица — `versions.yml`. Экономический провайдер и остальные сторонние плагины должны поддерживать Folia.

## Изменения после 0.41.0

- **Contracts 0.3.22:** `/orders` для всех игроков, включая игроков без города; награды на личный счёт; до трёх активных заказов. В каталоге 80 заданий, ежедневно выбираются 18. Обновление в 00:00 МСК; пять редкостей с разными требованиями, сроками, наградами и иконками. По умолчанию лимит — 3 000 монет за скользящие 24 часа. Оплаченный заказ скрывается у выполнившего его игрока. Исправлена дистанционная охота; разрешены все обычные инструменты и оружие, включая копья и руку.
- **Jobs 0.1.17:** оплата подтверждённых действий семи профессий во время рабочей смены. По умолчанию 350 монет за скользящие 24 часа, множители уровня 1.00–1.20. Исправление дистанционной охоты применяется и к зарплате стражника; условия смены и защита от AFK сохраняются.
- **Taxes 0.1.20 / Control 0.4.8:** проверки готовности экономики до обращения к счетам, диагностика, журнал операций и сверка незавершённых выплат. Установленный Vault сам по себе не означает, что провайдер валюты подключён к Towny.
- **Control 0.4.8 / Builds 0.8.28:** предупреждение и подтверждение удаления города простыми словами, административное удаление с сохранением обычных баз. Проверка полного плана, ограничения вертикального сноса, защита контейнеров и сохранение незавершённых операций.
- Включены остальные актуальные аддоны, в том числе **NeverLandTownyEvents**, Quests, Achievements и Environment. Цены зданий и требования к ресурсам не меняются. Контракты городов финансируются казной; функциональность компаний сохраняется.

## Установка и миграция

1. Полностью остановите сервер. Сохраните резервные копии миров и `plugins`, включая данные Towny и всех NeverLand-аддонов.
2. Скачайте `NeverLandTownySuite-0.42.0-plugins.zip`. В `dist/plugins` лежат 40 JAR; перенесите используемые модули в серверный каталог `plugins`, заменив прежние версии. Не оставляйте два JAR одного плагина. Не удаляйте данные и настройки.
3. Запустите сервер обычным способом. Не применяйте `/reload` и горячую замену JAR.
4. Проверьте `/orders`, `/orders admin status`, `/jobpay admin status`, `/nltadmin` и загрузку модулей. Удаление сначала проверяйте на отдельном тестовом городе.

**Изменение поведения Towny:** Control отключает штатные откат, удаление блоков и сущностей при снятии привата. Обычное снятие участков и автоматическое удаление города сохраняют территорию. Откат выполняется отдельным подтверждённым планом. Исходные настройки сохраняются в `NeverLandTownyControl/town-removal/worlds-before-protection.yml`; отключение Control не включает их обратно. Подробности: [инструкция удаления](TOWN_DELETION_20261022_RU.md).

Каталог заказов обновляется с резервной копией `orders.pre-catalog-v3.yml`. Сохраняются пользовательские цены, условия, удалённые старые шаблоны и нестандартные лимиты. Прежние стандартные значения 12 предложений и 1 500 монет повышаются до 18 и 3 000. Принятые заказы сохраняют условия; новая подборка появляется при следующем ежедневном обновлении. Выплаченные и ожидающие выплаты продолжают учитываться в лимитах.

## Права и проверка игроками

```text
/lp group default permission set neverland.orders.use true
/lp group default permission set neverlandtownyjobs.use true
/lp group default permission set neverlandtownyjobs.work true
/lp group default permission set neverlandtownyjobs.earn true
/lp group admin permission set neverlandtownycontrol.admin true
```

Игрок без города проверяет заказ через `/orders`. Житель с профессией и рабочим местом проверяет свою смену и `/jobpay`, затем может внести заработанное через `/town deposit <сумма>`. Административное меню доступно OP либо с правом `neverlandtownycontrol.admin`. Сверка выплат: `neverland.orders.admin` и `neverlandtownyjobs.payments` либо OP.

## Файлы и проверки

- `plugins.zip`: 40 JAR, краткая инструкция, контрольные суммы и отчёт сборки.
- `sources.zip`: исходники, встроенные конфигурации, инструкции, тесты и скрипты.
- `full.zip`: исходники, модели и готовые JAR.
- Отдельные JAR, `SHA256SUMS.txt`, `suite-tests.json`, `api-source-inventory.json`, `VALIDATION.txt` и `resource-balance.csv` приложены к релизу.

Публикация требует сборки всех 40 модулей, исполнения Java-тестов, проверок API, отказов хранилища, Python-тестов и соответствия JAR матрице. Архивы проверяются на целостность; список, размеры и SHA-256 загруженных файлов сверяются до открытия релиза.

Полный игровой прогон всех 40 новых JAR с игроками и нагрузочное тестирование не выполнялись. Прежние выборочные серверные проверки описаны в `ECONOMY_REVIEW_20261020_RU.md` и `TOWN_DELETION_VALIDATION_20261022_RU.md`; они не являются проверкой всего нового пакета. Текущее исправление охоты: [HUNTING_0.3.22_RU.md](HUNTING_0.3.22_RU.md).
