# Армейские рейды и компактная подсказка строительства — 0.46.0

Обновляются **NeverLandTownySiegesPlus 0.2.0** и **NeverLandTownyBuilds 0.8.40**. Армия, контракты, цены зданий и прочие модули сохраняют свои версии. Обновление устанавливается поверх совместимого комплекта 0.45.3; прежние исправления меню, превью и сдвига зданий входят в Builds 0.8.40. Клиент и сервер CraftoUI менять для этого обновления не требуется.

## Для игроков

Мобилизованный мэр или генерал объявляет нападение командой **`/sieges raid <город>`**. Для боевого TNT нужна действующая мобилизация в Army. Обычный участник армии не может объявить рейд. По умолчанию подготовка занимает **2 минуты**, бой — **20 минут**, а повторное нападение на защищавшийся город возможно через **24 часа после окончания** предыдущего рейда. В защищаемом городе должен находиться в сети хотя бы один житель; при выходе последнего защитника дальнейший урон приостанавливается. Таймер боя при этом продолжает идти.

Союз, принадлежность к одной нации, мирный/нейтральный статус, запрет нападения по договору и щит новичка запрещают рейд. Щит проверяется для обоих городов. Если установлен SiegeWar, объявление и стороны боя определяет он: боевой TNT работает для атакующей стороны в активной боевой сессии, а отдельные армейские рейды не создаются.

У дверей и блоков появляется прочность. Взрыв рядом наносит максимальный урон; с увеличением расстояния урон уменьшается. Расстояние считается до ближайшей грани блока, а обе половины двери считаются одной целью.

| Расстояние до грани блока | Урон при настройках по умолчанию |
| --- | ---: |
| До 1 блока включительно | 100 HP |
| 2 блока | 64 HP |
| 3,5 блока | 25 HP |
| 5 блоков | 4 HP |
| От 6 блоков | 0 HP |

| Блок | Прочность | Попаданий вплотную для разрушения |
| --- | ---: | ---: |
| Деревянная дверь, люк, калитка | 120 HP | 2 |
| Железная дверь или люк | 400 HP | 4 |
| Стекло | 60 HP | 1 |
| Доски, брёвна и деревянные стволы | 200 HP | 2 |
| Обычный твёрдый блок | 400 HP | 4 |
| Обсидиан и плачущий обсидиан | 1 200 HP | 12 |

Посмотреть прочность блока под прицелом: **`/sieges hp`**. Список рейдов: **`/sieges raid status`**. Обзор обороны: **`/sieges`** или **`/t sieges`**. Ворота Builds пропускают участника разрешённого рейда после физического разрушения двери; невидимая преграда не закрывает пробитый проход. Остальные действующие укрепления сохраняют свои эффекты.

Целый повреждённый блок восстанавливает HP после **30 минут без попаданий**. Уничтоженные блоки остаются уничтоженными; предметы из них не выпадают. Сундуки, бочки и другие блоки с состоянием/содержимым, бедрок, порталы и служебные блоки защищены. Права Towny на контейнеры и PvP продолжают определяться настройками сервера. Урон рассчитывается по расстоянию, в том числе через стены; отдельного расчёта укрытий нет.

TNT должен иметь установленного владельца: игрок, его снаряд, ранее поставленный игроком блок TNT или цепочка от такого взрыва. Поставленный TNT сохраняет владельца после рестарта, включая поджиг редстоуном. Перемещение TNT поршнем сбрасывает эту привязку. TNT без известного владельца, в частности выстрел из раздатчика без источника-игрока, не получает боевой урон по прочности города. Для рейда используйте TNT с владельцем; существующие запреты Towny на установку и поджиг блоков сохраняются.

## Для администрации

| Команда | Действие |
| --- | --- |
| `/sieges raid status` | Готовность армии/хранилища и текущие рейды |
| `/sieges raid cancel <город>` | Нейтрально остановить собственный армейский рейд |
| `/sieges raid history <город>` | Последние 10 записей объявления, отмены и урона |
| `/sieges status` | Состояние интеграции SiegeWar |
| `/sieges reload` | Проверить и применить настройки |

Отмена не объявляет город проигравшим, не списывает деньги и не выдаёт награды. Восстановление уничтоженных блоков не выполняется. Срок отдыха защищаемого города после отмены сохраняется. Осады SiegeWar отменяются его средствами.

Просмотр: `neverlandtownysiegesplus.use` (по умолчанию всем). Рейды: `neverlandtownysiegesplus.raid.use` (по умолчанию всем, дополнительно проверяются город, мобилизация и командование). Настройки, отмена и журнал: `neverlandtownysiegesplus.admin` (по умолчанию OP). Все узлы поддерживают LuckPerms.

```text
/lp group default permission set neverlandtownysiegesplus.use true
/lp group default permission set neverlandtownysiegesplus.raid.use true
/lp group admin permission set neverlandtownysiegesplus.admin true
```

## Настройки и установка

1. Остановите сервер и сделайте резервную копию мира и папок Towny/аддонов.
2. Удалите старые JAR **только Builds и SiegesPlus**, установите Builds 0.8.40 и SiegesPlus 0.2.0. В папке `plugins` должна остаться одна версия каждого плагина.
3. Сохраните существующие папки данных и конфигурации. Новые значения подхватываются из встроенных настроек, даже если их нет в старом YAML. Примеры конфигураций в архиве предназначены для сверки; заменять ими свой файл целиком не требуется.
4. Для армейских рейдов нужны работающие Towny, Builds и Army из совместимого комплекта. Для режима SiegeWar необходим его установленный провайдер. После запуска проверьте `/sieges raid status`.
5. Выполните плейтест на копии мира с двумя городами и действующими военнослужащими. Новые города защищены щитом новичка; для теста используйте города с истёкшим щитом.

В `plugins/NeverLandTownySiegesPlus/config.yml` новая секция `tnt` задаёт радиус, урон, спад, прочность, сроки и число защитников. Значения по умолчанию приведены в конфигурации, вложенной в JAR и архив обновления. Для отдельного материала можно задать, например:

```yaml
tnt:
  hitpoints:
    materials:
      STONE_BRICKS: 600.0
      COPPER_DOOR: 300.0
```

Этот фрагмент **добавляется к своей секции `tnt`**, а не заменяет весь файл. Радиус ограничен 8 блоками, чтобы ограничить работу на региональном потоке. Числа проверяются до применения; ошибочный reload оставляет прежние настройки. `tnt.enabled: false` отключает боевой урон и новые рейды. Пауза модуля сохраняет записи; время рейдов считается по часам сервера, без компенсации времени выключения. Новая механика не включает взрывы или PvP флагами Towny.

В Builds: `settings.construction.guide-label-scale: 0.45` и `guide-label-width: 200`. Подсказка остаётся личной и временной; масштаб применяется к уже отображаемой плашке при её обновлении. Допустимый масштаб автоматически ограничивается 0.2–0.8; неверное числовое значение заменяется 0.45.

## Хранение и проверки

`plugins/NeverLandTownySiegesPlus/raids.db` хранит объявления, HP, владельцев TNT, обработанные попадания и журнал. SQLite работает на отдельном потоке с ограниченной очередью. Региональные потоки не ожидают диск. Ошибка базы или переполнение очереди приостанавливает разрушение; для восстановления после устранения причины требуется перезапуск. Делайте копию `raids.db` при остановленном сервере; не удаляйте её для обычного обновления.

Один взрыв не может дважды повредить один блок. Физическое разрушение проверяет актуальную территорию, право на рейд и замену блока. Прерванное разрушение после рестарта не повторяется автоматически: у оставшегося блока устанавливается 1 HP, для разрушения нужен новый взрыв.

Результаты проверки и точные ограничения покрытия: [validation/tnt-raids-0.46.0](validation/tnt-raids-0.46.0/README.md). Проверены реальные Folia 26.2 build 7, Towny 0.103.2.0, SQLite, TNT и TextDisplay в отдельном мире. Проверка мира использует явную тестовую замену допуска к рейду; вход реальных игроков и полноценная боевая сессия Army/SiegeWar требуют плейтеста на сервере.
