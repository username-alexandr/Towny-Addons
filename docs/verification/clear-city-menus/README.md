# Проверка понятных меню города

Сборки: Governance 0.1.25, Council 0.1.15. Стенд: Folia 26.2 build 7 (14b7fee), Towny 0.103.2.0, Java 25.

- Сборка: 7 исполняемых Java smoke-тестов и 13 Python-проверок прошли. API Council v1 (30 сигнатур/возможностей) и Governance v1 (27) совместимы. Проверка отказов записи Governance прошла; тесты Council проверяют сохранение, ограничения и ошибки записи.
- Первый запуск: 74 проверки. Открытие общего списка, городские назначения, офлайн-жители, страницы, отмена, повторный клик, личные запреты, изменившиеся состав и права, закрытые окна, снятие министра, явные кнопки прав, просмотр закона без отправки, предложение закона и ответы в голосовании.
- Полный перезапуск: 7 проверок загрузки, городских назначений, министров, их истории и личного запрета. Оба запуска завершились штатной остановкой.
- Перед упаковкой сверены SHA-256 JAR со списками реально загруженных плагинов каждого запуска.

Источники результатов: `suite-tests.json`, `checks.txt`, `first-passed.txt`, `restart-passed.txt`, консольные логи и перечни SHA-256.

Игроки, InventoryView и EntityScheduler в проверке имитируются; обратные вызовы направлены в глобальный планировщик для работы с тестовыми данными. Настоящие Towny, инвентари, события, сервисы плагинов и сохранение используются на Folia. Это не проверка региональной принадлежности подключённого игрока и не визуальный тест CraftoUI. Citizens/Elections на стенде отсутствуют. Внешний запрос ключей Mojang может завершаться ошибкой из-за изоляции стенда.

Форматы сохранения не менялись. Предыдущие отчёты в соседних каталогах относятся к своим прежним сборкам. Остальные JAR полного пака не изменены.
