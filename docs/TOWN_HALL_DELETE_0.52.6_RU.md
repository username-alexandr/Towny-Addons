# Исправление удаления ратуши — 0.52.6

В Control 0.6.7 пустая кафедра и колокол ратуши входят в план изменения территории после удаления города. Это работает при обычном удалении мэром и при административном удалении только зарегистрированных зданий. Перед изменением каждого блока плагин повторно сверяет его состояние; если блок изменился или участок уже занял новый город, изменение не выполняется.

Кафедра с книгой остаётся, как и сундуки и другие блоки с содержимым. Сначала заберите книгу, если хотите убрать кафедру. Администратор может увидеть количество пропущенных блоков через `/nltdelete status`.

Оставшиеся после **предыдущего** удаления кафедра и колокол автоматически не удаляются: старый план не содержит их координат, а рядом могут уже появиться чужие постройки. Администратору нужно проверить участок и убрать эти два блока вручную, если они действительно остались от ратуши.

Установка: остановите сервер, сохраните копию данных, замените прежний `NeverLandTownyControl` одним JAR версии 0.6.7 и запустите сервер. Для полного комплекта используйте согласованный набор 0.52.6. Команда `/reload` для этого обновления не подходит.
