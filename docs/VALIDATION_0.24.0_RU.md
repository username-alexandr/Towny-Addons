# Проверка обновления 0.24.0

Основа: опубликованный `main` 0.23.0, коммит `51a46481827236dd5a9194d9e15ab367c392d806`.

Проверены раздельные Gradle-сборки Citizens, Builds, Governance и Taxes. Единый `build_suite.py` выполнил 39 тестовых классов, проверку контрактов API и проверки отказов хранилищ Governance/Taxes. Дополнительный тест Citizens проверяет сохранение, точную границу срока, повреждённую запись, отказ записи и отсутствие повторной попытки после ошибки.

Локальная сборка использовала Java 25.0.4.1, Gradle 9.0.0 и зависимости подготовленного Purpur 26.2-2632, Towny 0.103.2.0 и PlaceholderAPI 2.12.3. Недоступные в этом окружении Maven-репозитории заменены локальным classpath через временный Gradle init-script. Исходные определения сборки и закреплённые версии зависимостей сохранены. Это локальная проверка, а не выполненный GitHub Actions.

Passport 0.4.0 подготовлен из сохранённого NeverLandPassport 0.3.0: изменённые Java-классы скомпилированы с `--release 25`, неизменённые классы и встроенный SQLite перенесены из исходного JAR. Новый адаптер использует публичный Citizens API, не меняет схему SQLite и не переписывает прежние паспортные данные.

Серверная проверка выполнена на изолированном Purpur 26.2-2632 с 28 аддонами, Passport 0.4.0, Towny 0.103.2.0, Vault 1.7.3, EssentialsX 2.22.0 и PlaceholderAPI 2.12.3. Скрипт требует маркер одноразового окружения и привязку к 127.0.0.1. Проверяются:

- Загрузка всех плагинов, регистрация API, команда Towny и карточка.
- Исходное гражданство, запрет самостоятельного повышения и сохранение гражданства мэра.
- Права временного жителя, почётного жителя и почётного гостя.
- Ограничение электората и управленческих действий Governance.
- Реальное списание налога через Towny: 10 при базе 20 для почётного статуса и 25 для временного, по одному списанию.
- Запрет сноса блока и доступа после смены статуса при уже открытом складе.
- Паспортный адаптер и PlaceholderAPI, сохранность прежнего значения паспортного поля.
- Сохранение почётного статуса и автора изменения, истечение временного проживания после перезапуска.

Оба запуска прошли: 32 + 10 = **42 серверные проверки**. Точные результаты и SHA256 проверенных JAR находятся в `docs/validation/0.24.0/`. Все неизменённые аддоны взяты из опубликованного архива 0.23.0. Minecraft-клиент заменён прокси открытого окна и сообщений; визуальная проверка ресурс-пака и нагрузочное тестирование в этот прогон не входят.

Публикация на GitHub не выполнена: подключение GitHub возвращало `Internal error`, а пробная отправка через git завершилась отсутствием учётных данных. Пакет и исходники подготовлены для передачи и последующей публикации.
