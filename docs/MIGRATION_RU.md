# Переход на единые команды

## Что изменилось

- Игровые городские команды собраны под `/t`.
- Административные команды приведены к формату `/towny...`.
- Внутриигровая справка, `plugin.yml`, README и сообщения используют новые имена.
- Старые команды не удалены: они зарегистрированы как алиасы и не ломают существующие NPC, меню и скрипты.
- Добавлен `NeverLandTownyTaxes 0.1.0`; `NeverLandTownyTrade` обновлён до `0.1.3` для применения санкций и торговых льгот.
- В NeverLandTownyBuilds 0.6.0 добавлены 16 проектов и семь категорий меню. Старые идентификаторы проектов, прогресс строительства и купленные Чудеса не меняются.
- В NeverLandTownyBuilds 0.7.0 добавлены шесть Чудес. Новый каталог, требования зданий и музейные реликвии дописываются автоматически; данные 0.6.0 сохраняются.
- В NeverLandTownyBuilds 0.7.1 первоначальные пять Чудес получили требования к зданиям. Если в старом `projects.yml` поле `requires` отсутствует, оно наследуется из встроенного каталога; явно настроенные администратором требования сохраняются.
- `town-data.yml` автоматически дополняется секциями муниципальных участков, маршрутов, складов, страхового резерва и лавки. Ручная миграция не требуется.

## Безопасное обновление

1. Сделайте резервную копию каталога `plugins`.
2. Остановите сервер.
3. Удалите только старые JAR модулей. Не удаляйте каталоги данных.
4. Установите новые JAR из папки `plugins` этого релиза.
5. Полностью запустите сервер.
6. Проверьте `/t builds`, `/t civic status`, `/t taxes`, `/n taxes`, `/t trade` и `/townytaxes bank`, затем остальные команды пака.
7. Настройте места лавок на спавне через `/townybuilds stall set <id>`. Без настроенных мест торговые города продолжают работать, но занять лавку на спавне не смогут.

Одновременное хранение старого и нового JAR одного модуля запрещено: Bukkit увидит дублирующиеся имена плагинов и команд.
