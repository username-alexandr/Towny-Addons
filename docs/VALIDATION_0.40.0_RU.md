# Проверка 0.40.0 — экология города

## Локальные проверки

- Успешно собраны Environment, Resources, Population и Control на Java 25, bytecode основных классов Java 17.
- Выполнены 9 Python-тестов инструментария и 7 обнаруженных исполняемых Java-тестов этих модулей; список — `validation/0.40.0/selected-tests.json`.
- EnvironmentSmoke: 34 проверки загрязнения, очистки, порогов штрафов, пауз, атомарного сохранения, ошибок диска, повреждённых данных и изоляции UUID.
- ResourcesSmoke дополнен проверками уменьшения только нового выпуска еды, неизменности запасов/затрат/вместимости, сочетания с сезонами и отказа при нечисловом коэффициенте.
- Проверены публичные API выбранных модулей; новый TownyEnvironmentApi внесён в baseline. Состав исходников: 40 модулей, 90 стандартных зданий и 11 чудес.

## Нативный запуск

Purpur 26.2 build 2632, Java 25.0.4.1+1, Towny 0.103.2.0. Одноразовый сервер слушал 127.0.0.1. Environment 0.1.0, Resources 0.1.21, Population 0.1.20 и Control 0.4.3 проверены вместе с остальными 36 аддонами из опубликованного 0.39.0. Полные SHA-256 JAR — `validation/0.40.0/plugins.json`.

**33 проверки первого запуска + 9 проверок второго JVM = 42 успешные проверки.**

Проверены совместная регистрация сервисов, принадлежность площадки городу, завершённые уровни, промышленные выбросы, парки, ручная остановка производства, неработающий парк, реальные расчёты Resources и Population, отсутствие конфискации ресурсов, таймер без накопления простоя, недоступный поставщик, возобновление, меню, защита предметов, отказ обычному мэру в админских действиях, наследование общего права администратора, отдельная категория журнала, нейтральные мосты отключённого аддона, неизменность файла после отключения и перезапуска.

Это проверка интеграции на реальном сервере с управляемыми ответами публичных сервисов зданий/содержания/питания/специализации. Загрязнение 70 задаётся через реальное хранилище в защищённом тестовом плагине; серверные циклы вызываются явно для детерминированной проверки интервала. Это не игровой клиент, не нагрузочный тест и не полное строительство промышленного города вручную. PlaceholderAPI не участвовал в запуске; Environment его не требует.

В журналах допускаются предупреждения о ключах внешней авторизации в изолированной среде, а также сообщения об искусственно недоступном поставщике и безопасном отключении зависимостей. Все проверки завершаются подтверждениями в `first-passed.txt` и `restart-passed.txt`.

## Воспроизводимость и выпуск

Сценарий: `scripts/environment-runtime-probe/README.md`. Журналы, проверки, снимок данных и хеши тестируемых исходников сохранены в `docs/validation/0.40.0/`.

Обязательный Verify CI собирает все 40 модулей, исполняет обнаруженные тесты и проверяет совместимость API. Публикация повторяет полную сборку независимо, сверяет JAR с матрицей, упаковывает исходники и SHA256SUMS. Окончательный отчёт всех модулей прикладывается к релизу как `suite-tests.json`; локальный отчёт выбранных модулей его не заменяет.
