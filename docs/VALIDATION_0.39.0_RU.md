# Проверка NeverLand Towny Suite 0.39.0

## Локальная проверка

- Сборка и выполнение тестов Achievements, Control, Events, Population: **15 исполняемых Java-тестов**, включая 33 утверждения `AchievementsSmoke` и 9 утверждений `RaidVictoriesSmoke`.
- Общие проверки Python: **9 тестов**.
- Проверены API v1 затронутых поставщиков и неизменность ранее опубликованных сигнатур. Новый API Achievements и дополнительный метод Events `raidVictories` добавлены в эталон совместимости.
- Проверка исходников и метаданных: **39 модулей**, 90 зданий и 11 чудес; карта безопасного отключения актуальна.
- Полная матрица всех аддонов запускается workflow Verify и повторяется в Publish release перед публикацией JAR.

## Нативный тест

Отдельный сервер **Purpur 26.2 build 2632**, **Towny 0.103.2.0**, **Java 25.0.4.1+1**. Новый Achievements 0.1.0 и кандидаты Control 0.4.2, Events 0.4.5, Population 0.1.19; остальные зависимости из опубликованного комплекта 0.38.0. Контрольные суммы всех установленных JAR сохранены рядом с результатами.

**27 утверждений в первом процессе и 7 после повторного запуска**, всего 34. Настоящие города Towny, инвентари и события Bukkit; действующие сервисы Achievements, Population и Control. Наблюдения публичных API Builds, Population и Events управляются тестом, чтобы проверять точные пороги.

Проверено: отсутствие наград ниже порога, пауза источника населения, пауза администратора, 89/90 и 90/90 зданий, первое чудо, фактический бонус довольства в Population, права мэра и жителя, недоступность наград после выхода из города, защита инвентаря от извлечения, оформление одного знамени из одного чистого предмета, отдельная категория аудита, доступ через корневое разрешение администратора, сохранение открытых наград при падении показателей, повторной проверке и перезапуске. Недоступный установленный поставщик бонуса блокирует зависимый расчёт. Баланс проверен на недоступной экономике; точный денежный порог покрыт модельным тестом. Нативный тест не имитирует полный бой, строительство всех объектов, рендер клиента или промышленную нагрузку.

В журнале bootstrap есть недоступность внешнего сервиса ключей Mojang на локальном offline-сервере и предупреждение настройки плоского мира. Оба запуска завершились штатно, маркеров ошибки теста нет.

Результаты: `docs/validation/0.39.0/`. Воспроизводимый стенд: `scripts/achievements-runtime-probe/`; запуск разрешён только при явном маркере одноразового сервера и привязке к loopback.
