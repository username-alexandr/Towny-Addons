## Когда вступят в силу изменения

После установки и запуска действует новый личный лимит. Уже выплаченные за последние 24 часа суммы продолжают учитываться, незавершённые начисления сохраняют резервирование. Например, при полученных ранее 1 200 монетах остаток нового стандартного лимита составляет 1 800, а не 3 000. Повторной выплаты старых наград не происходит.

Сохранённая доска текущего дня остаётся прежней. Новые шаблоны участвуют в следующей случайной подборке после 00:00 МСК. Новая стандартная доска содержит 18 заказов; на сервере с пользовательским размером применяется его настройка. При первом запуске без сохранённой доски новый каталог используется сразу. Принятые задания сохраняют прежние цель, количество, сумму, срок, редкость и прогресс.

Лимит остаётся скользящим: полночь обновляет доску, но не обнуляет историю дохода. Общий бюджет публичных заказов — прежние 100 000 монет за 24 часа, если не настроен иначе. Фактическая доступная выплата ограничена и личным, и оставшимся общим бюджетом. Профессии сохраняют прежний отдельный лимит 350 монет. Городские и корпоративные контракты, казна и цены зданий этим обновлением не меняются.

## Установка

1. Остановить сервер и сохранить резервную копию `plugins/NeverLandTownyContracts`.
2. Заменить старый JAR Contracts на `NeverLandTownyContracts-0.3.20.jar`; оставить один JAR этого плагина.
3. Запустить сервер. Конфигурация обновится автоматически. Проверить `/orders`, `/orders mine`, `/orders admin status`.

При миграции сохраняется исходный `orders.yml` в `orders.pre-catalog-v3.yml`; прежняя копия `orders.pre-daily-v2.yml`, если есть, не затрагивается. Версия каталога становится `catalog-version: 3`.

Стандартный прежний `board-size: 12` повышается до 18, `limits.player-24h: 1500` — до 3000. Иные пользовательские значения сохраняются. Если общий серверный бюджет настроен ниже 3000, новый личный предел ограничивается этим общим бюджетом без его повышения. При обновлении из старой почасовой версии стандартный размер 4 сразу превращается в 18.

Добавляются только новые шаблоны этой версии. Удалённые ранее старые задания не восстанавливаются. Существующий шаблон с совпавшим ID не перезаписывается. Изменённые награды, веса редкости и отключённые шаблоны сохраняются. После завершения миграции вручную уменьшенный лимит не будет вновь повышаться при каждом запуске.

Чтобы установить другой личный предел, изменить `limits.player-24h` в `plugins/NeverLandTownyContracts/orders.yml` и перезапустить сервер. Новый предел должен быть не выше `limits.server-24h`. Не удалять `orders-board.yml`, `public-orders.yml` и `order-payments`: они хранят подборку, прогресс и историю выплат. Для отката на 0.3.19 требуется исходная конфигурация из резервной копии, поскольку старая версия не понимает каталог v3; журналы выплат при этом очищать нельзя.

## Проверка

Сборка Java 25.0.2 / Gradle 9.0.0 против Paper API 26.2.build.121-stable и Towny 0.103.2.0 прошла. Пройдены 5 существующих исполняемых программ Contracts и проверка совместимости публичного API. В `DailyOrdersSmoke` теперь 61 проверка, включая миграцию v1/v2→v3, сохранение удалённых/изменённых шаблонов, пользовательские лимиты и рост лимита без сброса уже оплаченных и ожидающих начислений. `RewardLedgerSmoke` прошёл 38 проверок. Все 80 целей каталога проверены парсером и русским словарём.

Результаты: `docs/validation/expanded-orders-0.3.20/`. Новый серверный запуск Folia, игровой клиент и проверка фактической сложности всех целей для этой версии не выполнялись. Набор серверных проверок обновлён для расширенного каталога, но его результаты от предыдущих версий не выдаются за новый запуск.
