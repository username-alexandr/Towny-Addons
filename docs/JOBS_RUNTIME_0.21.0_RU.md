# Проверка Jobs 0.1.0 / комплекта 0.21.0

Дата: 11 сентября 2026 года. Локально собраны Builds 0.8.10, Jobs 0.1.0, Resources 0.1.7 и Research 0.1.2; выполнены их `smokeTest`. Остальные 23 JAR взяты из проверенного релиза 0.20.0. CI релиза заново собирает все 27 модулей.

## Автоматические проверки

JobsSmoke: **78 проверок** — семь профессий, пять уровней, отдельное сохранение опыта, подходящее рабочее здание, места после снижения уровня, подготовка смены, истечение активности, недопустимые координаты, режим, права и отсутствие игрока, пределы бонусов, перезапуск, повреждённая база и ошибка атомарной записи. Отказ записи не меняет опубликованное состояние и блокирует дальнейшие изменения.

Существующие проверки Builds, Resources и Research завершились успешно. Стоимость строительства сверяется с предыдущим релизом: 90 зданий, 11 чудес, 461 стадия и 1118 строк ресурсов без изменений.

## Границы проверки

Проверка использует настоящий сервер, данные Towny, сервисы аддонов, файлы и реестры предметов. Контролируемый тестовый источник задаёт присутствие, разрешённый режим и время; команда выбора проверяется с тестовым объектом Player. Подключённого клиента Minecraft нет: визуальный вид меню, игровые клики, патруль и анимации вручную не проверялись. Создание строительных площадок в тесте проверяет публичные координаты и завершённые уровни, а не ручную постройку моделей.

На стенде присутствует известное предупреждение EssentialsX 2.22.0 о версии сервера и предупреждение завершения его фоновой задачи. Это не подтверждение полной совместимости EssentialsX с 26.2. Запросы обновлений и проверки профилей через внешние службы могли завершаться сетевыми предупреждениями; тестовые жители созданы локально.

Исходник проверки находится в `scripts/jobs-runtime-probe/`. Его можно запускать только на одноразовом стенде: нужны файл `ALLOW_DISPOSABLE_JOBS_PROBE`, `server-ip=127.0.0.1` и параметр JVM `-Dneverland.runtimeProbe=true`. Тест изменяет свои города, данные, резерв знаний и состояние плагинов, затем останавливает сервер. Проверочный JAR не входит в комплект аддонов.
