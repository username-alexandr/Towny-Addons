# Понятные сообщения и переводы — 0.52.5

У каждого аддона теперь есть собственный файл `plugins/NeverLandTowny<Название>/messages.yml`. Администратор может менять предложенные тексты, не редактируя JAR. Существующие файлы не перезаписываются: если файл уже есть, используются его настройки и новые встроенные значения по умолчанию.

В Builds и Events прежний формат ключей (`not-enough-money`, `no-event` и др.) сохранён. В Market новые сообщения и подписи покупки перечислены обычными ключами. Изменения Market доступны после `/townymarket reload`, изменения Builds и Events — после их команд перезагрузки.

В остальных аддонах есть список `overrides`:

```yaml
overrides:
  - source: '&cНет доступа к энергосети этого города.'
    text: '&cУ вас нет доступа к энергосети этого города.'
message-prefix-Ui: '&8[&aNeverLand &8• &fЭнергия&8] &r'
```

Меняйте **только `text`**; `source` нужен для поиска исходной фразы. Префикс редактируется, если он есть в файле. Цветовые коды и команды в подсказках сохраняйте. Для этих файлов изменения вступают в силу после перезапуска сервера. Вынесены короткие сообщения и справка, которые выдаются напрямую; динамические строки, названия предметов, системные идентификаторы и названия команд по-прежнему берутся из кода или их профильных конфигов.

Что исправлено в интерфейсе:

- Builds различает нехватку денег, ожидание платежа и недоступную проверку экономики. Ошибка провайдера не называется отсутствием средств в казне.
- Market предлагает «Забрать» только для завершённой личной покупки. Пока оплата или доставка продолжается, показывается состояние; городские покупки отправляются на склад. История показывает московское время.
- Events не открывает пустой список восстановления, если после пожара нет повреждённых мест. В истории время указано по Москве.

При установке остановите сервер, замените старые JAR **каждого** обновлённого аддона новой версией и оставьте по одному JAR на имя плагина. Старые `messages.yml` и данные городов оставьте на месте. Перед стартом сохраните копию папки `plugins/`; при откате верните согласованный набор JAR и данные из этой копии.
