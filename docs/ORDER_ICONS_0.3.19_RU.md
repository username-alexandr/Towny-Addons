# Contracts 0.3.19 — иконки редкости

Карточки `/orders` различаются предметом и цветом уже при открытии доски.

| Редкость | Охота | Добыча | Доставка | Рыбалка |
|---|---|---|---|---|
| Обычная | Деревянный меч | Деревянная кирка | Белый шалкеровый ящик | Треска |
| Необычная | Каменный меч | Каменная кирка | Лаймовый шалкеровый ящик | Лосось |
| Редкая | Железный меч | Железная кирка | Голубой шалкеровый ящик | Иглобрюх |
| Эпическая | Алмазный меч | Алмазная кирка | Фиолетовый шалкеровый ящик | Тропическая рыба |
| Легендарная | Незеритовый меч | Незеритовая кирка | Оранжевый шалкеровый ящик | Сердце моря |

Эпические и легендарные иконки блестят. Это визуальный эффект без добавления зачарований. Урон и скорость атаки инструментов по-прежнему скрыты. В подсказке остаются русские название цели, редкость, сложность, награда и срок.

Предмет иконки обозначает вид и редкость задания. Требуемый ресурс или моб указан в строке «Цель»; например, сердце моря у легендарной рыбалки не меняет задание на добычу сердца моря. Требования, выплаты, дневная подборка, прогресс и настройки этой версией не меняются. Иконки обновятся и у текущей сохранённой доски при следующем открытии меню после установки.

Установка: остановить сервер, заменить прежний JAR Contracts на `NeverLandTownyContracts-0.3.19.jar`, запустить сервер. Папку плагина и конфигурацию удалять не нужно. Ресурспак не требуется. Источник соответствия: метод `iconMaterial` в `PublicOrders.java`.

Сборка: Java 25.0.2, Gradle 9.0.0, Paper API 26.2.build.121-stable. Существующие автоматические проверки и проверка совместимости API прошли; результаты записаны в `docs/validation/order-icons-0.3.19/`. Новый запуск Folia и клиентская визуальная проверка для этого изменения не выполнялись.
