# Экология районов

В `/t environment` добавлена кнопка «Экология районов», прямая команда — `/t environment districts`. Доступ к своему городу требует `neverlandtownyenvironment.use`. По нажатию на район открывается полный список его работающих источников с обычной пагинацией.

Раздел показывает вклад района в прежние общие выбросы и очистку города за цикл. Парки, лесничество и другие здания с очисткой выделены как зелёные источники. Природное восстановление показано отдельно в общегородской группе, вместе с постройками вне назначенных районов. Это не отдельное загрязнение каждого участка: новые штрафы, бонусы и списания не вводятся, прежняя формула города и сохранённое загрязнение остаются без изменений.

Места источников берутся из согласованного `assessment` формата 2 Districts 0.2.1. Без установленного Districts все источники общегородские. Недоступный, старый или повреждённый поставщик районов даёт понятное сообщение; неизвестные данные не подменяются нулями. Время источников показывается по Москве.

`districts.enabled: false` в Environment/config.yml отключает только новый раздел. `/townyenvironment reload` применяет настройку. Старые сохранения `environment-data.yml` не меняют формат. Раздел не меняет его при открытии, не делает шаг симуляции и не перераспределяет реальные ресурсы.

Снимок использует прежние наблюдаемые уровни и коэффициенты. Десятичное распределение сохраняет точные итоговые значения старого движка; исправляется лишь ничтожная погрешность накопления double, без изменения фактического давления. Необъяснимое расхождение источников отклоняется. API `districts(UUID)` читает неизменяемый опубликованный кеш, регистрирует интерес и может вернуть `pending`. Расчёт отдельный, один поток, очередь 16, максимум 128 городов, интерес истекает через 120 секунд. Чтение API не ждёт SuiteState, не читает мир и не обращается к Towny.

Просмотр разрешён только в своём городе. Ожидание обновляет тот же инвентарь ограниченное число раз; смена окна или потеря прав прекращает обновление. Выключение отдельно завершает производные расчёты. Существующее сохранение и административное управление Environment остаются синхронными: эта доработка не закрывает общий пункт миграции всех хранилищ на фоновое подтверждённое сохранение.

Проверки: DistrictEnvironmentSmoke содержит точное сложение районов и источников, 10000 случайных распределений, порядок источников, строгую границу Districts, устаревание, ограничение интереса, чтение API при занятой общей блокировке и остановку. Сборка Environment 0.2.1 прошла три тестовые программы, в том числе 21 проверку DistrictEnvironmentSmoke и 10000 распределений. Настоящая Folia: 26 проверок первого запуска и 13 после полного перезапуска. Точные артефакты и границы проверки — `validation/city-systems-052/environment-districts/`.
