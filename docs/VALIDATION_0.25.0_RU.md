# Проверка 0.25.0

Локально собраны Elections 0.1.0, Governance 0.1.10 и Ideologies 0.1.8. Выполнены шесть исполняемых тестовых классов, проверки трёх публичных API и файловых отказов Governance/Ideologies. Elections дополнительно проверяет повреждённые бюллетени, отказ атомарной записи, сохранение прежней памяти и запрет повторных записей после ошибки. Отчёт: `validation/0.25.0/suite-tests.json`.

Общий валидатор: 29 модулей, 29 JAR, 124 YAML; 90 зданий и 11 чудес света. Упаковщик сверяет полный список JAR с `versions.yml`, без фиксированного числа аддонов.

На отдельном Purpur 26.2-2632 с Towny 0.103.2.0, Java 25, Vault, EssentialsX 2.22.0, PlaceholderAPI 2.12.3 и Passport 0.4.0 прошли 48 проверок: 34 при первом запуске и 14 после перезапуска. Загружены все 29 аддонов. Исходник воспроизводимого сценария: `scripts/elections-runtime-probe/`.

- Проверены реальная смена мэра Towny и сохранение его после перезапуска.
- Установлены два депутата через публичный API Governance; совет получил полномочия голосовать по законам. Мэр не смог снять депутата обычным назначением.
- Временный житель не смог выдвинуться и проголосовать; почётный гражданин смог стать кандидатом. Иностранец исключён из результата после изменения статуса.
- Повторный голос не увеличил явку. Не разыгранная должность сохранила прежнего держателя.
- Монархия отменила открытую кампанию и запретила новый старт. Ошибочная форма правления вызвала отказ API.
- Проверены регистрация `/t elections`, создание меню, запрет извлечения предметов и отображение сохранённого выбора для нескольких мест.
- Проверены квитанция результата, бюллетени, история и повторное применение. Для восстановления намеренно сохранён APPLYING с уже применёнными эффектами, затем выполнен штатный перезапуск: кампании потребовался REVIEW и точный ID для resume.

Доказательства: `validation/0.25.0/checks.txt`, `first-passed.txt`, `restart-passed.txt`, SHA-256 локально проверенных JAR в `tested-jars.sha256`. Эти контрольные суммы относятся к локальной сборке; JAR выпуска отдельно пересобираются GitHub Actions с закреплёнными зависимостями.

Это проверка на настоящем сервере с прокси Player/InventoryView, без сетевого Minecraft-клиента. Внешний вид пользовательского ресурспака, нагрузка от большого числа городов и аварийное завершение ОС в произвольный момент этим сценарием не измерялись. Восстановление проверено через сохранённую контрольную точку операции. Общей атомарной транзакции с хранилищем Towny нет; при неопределённом результате применяется REVIEW, описанный в инструкции Elections.

Предыдущая проверка Citizens: 39 исполняемых классов изменённых модулей и 42 проверки на сервере — `VALIDATION_0.24.0_RU.md`. CI всего комплекта запускается при публикации и прикладывает собственный `suite-tests.json` к выпуску.
