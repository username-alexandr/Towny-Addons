# NeverLand Towny Suite 0.8.0 — городские районы

Новый NeverLandTownyDistricts 0.1.0 позволяет делить землю города на семь типов районов. Builds 0.7.8 передаёт реальные границы строительных площадок и применяет бонусы; Population 0.1.1 учитывает их в показателях населения. Всего в релизе 16 модулей.

## Установка

Остановите сервер, замените NeverLandTownyBuilds на 0.7.8 и NeverLandTownyPopulation на 0.1.1, добавьте NeverLandTownyDistricts 0.1.0 и запустите сервер. Старые JAR этих модулей уберите, каталоги данных сохраните. Совместимость: Paper/Purpur 26.2, Towny 0.103.2.0, Java 25.

Districts требует Towny и Builds 0.7.8 или новее. Population необязателен для районов, но нужен для бонусов населения. Без Districts Builds и Population сохраняют обычные коэффициенты. Три новых файла создаются в каталоге Districts: `config.yml`, `projects.yml`, а после первого изменения — `districts-data.yml`. Данные населения, здания и чертежи не сбрасываются.

## Создание района

1. Встаньте в первом углу участка своего города и выполните `/t district pos1`.
2. Перейдите в противоположный угол и выполните `/t district pos2`.
3. Выполните `/t district create zavod industrial`.
4. Задайте название: `/t district rename zavod Заводской район`.
5. Проверьте `/t district info zavod` и `/t district map`.

Без выделения создаётся район из текущего участка Towny. После успешного создания или добавления территории выделение сбрасывается. Чтобы расширить район, выделите соседний прямоугольник и выполните `/t district claim zavod`. Можно также добавлять по одному текущему участку. Для сброса незавершённого выделения есть `/t district clear`.

Район состоит из участков Towny: используется настроенный размер сетки, обычно 16 × 16 блоков. Все участки должны принадлежать своему городу, находиться в одном мире и соединяться сторонами. Пересечения районов запрещены. Можно создать несколько районов одного типа. Это дополнительная разметка: типы участков Towny, права строительства и владение землёй не меняются.

## Команды и права

| Команда | Действие |
|---|---|
| `/t district` | Меню районов своего города и создание района кнопкой выбранного типа |
| `/t district list` | Список районов с постраничной навигацией |
| `/t district info <id>` | Здания, условия размещения и действующие бонусы |
| `/t district pos1` / `pos2` | Два угла выделения по текущему положению игрока |
| `/t district clear` | Сброс выделения |
| `/t district create <id> <тип>` | Создание района; ID — до 32 латинских букв, цифр, `_` и `-` |
| `/t district claim <id>` | Добавление текущего участка или выделенного прямоугольника |
| `/t district unclaim <id>` | Исключение текущего участка; оставшаяся территория должна быть связной |
| `/t district rename <id> <название>` | Название до 48 символов; форматирующие коды запрещены |
| `/t district delete <id>` | Удаление разметки района; земля и здания остаются у города |
| `/t district map` | Цветные границы на 30 секунд, радиус 64 блока |
| `/townydistricts reload` | Перезагрузка настроек и профилей |

Прямые команды `/townydistricts`, `/districts`, `/nltdistricts` поддерживают те же аргументы. Если `/t district` занят другим плагином, используйте `/townydistricts`; предупреждение появится в консоли.

| Право | По умолчанию | Назначение |
|---|---|---|
| `neverlandtownydistricts.use` | Все игроки | Просмотр своего города, меню, границы |
| `neverlandtownydistricts.manage` | Выключено | Управление районами своего города для назначенного жителя |
| `neverlandtownydistricts.admin` | Операторы | Перезагрузка конфигурации |

Мэр и житель с городским рангом `assistant` могут управлять районами без отдельного `manage`. Право управления не даёт доступа к чужому городу. Права и гражданство проверяются повторно при каждом действии меню. Выделение очищается при выходе игрока.

## Условия и величина бонуса

Завершённое обычное здание V этапа или чудо I этапа получает **+15%**, если вся его горизонтальная площадка находится в одном районе подходящего типа. Учитывается полный прямоугольник чертежа, включая выступы крыши, крыльцо и двор, с правильным поворотом. Одна точка установки внутри района недостаточна. Для незавершённой постройки, неподходящего района или площадки на границе коэффициент остаётся ×1.

**Кузница + Литейная + Городской склад в одном промышленном районе** добавляют ещё **20 процентных пунктов**: суммарно ×1.35. Связка усиливает подходящие завершённые промышленные здания этого района. Участники в разных промышленных районах не объединяются. Названия участников берутся из `projects.yml`; стандартные ID — `forge`, `foundry`, `warehouse`.

Показатели обновляются каждые 5 секунд и при управлении районами. Изменение владения землёй вызывает дополнительный пересчёт. После утраты участка он исключается из района; пустой район удаляется. Если разрыв территории разделил район на части, бонусы всего района приостанавливаются до соединения участков. Выгруженный мир не удаляет сохранённую разметку; его бонусы не действуют до загрузки.

## Что реально усиливается

| Система | Действие бонуса |
|---|---|
| Население | Вклад соответствующего здания в жильё, рабочие места, еду, воду и положительное довольство. Базовые показатели города и отрицательное довольство не умножаются |
| Муниципальные службы | Вклад здания в опубликованные Builds-показатели торговли, таможни, укреплений, воды, страхования и другие CivicBenefit; существующий предел показателя сохраняется |
| Армия | Вместимость завершённого штаба армии; требования гражданства и возраста от 18 лет сохраняются |
| Лесничество | Лимит посадки за цикл |
| Ирригация | Лимит увлажняемых участков за цикл |
| Переработка | Количество выходного материала за прежнее количество входного |
| Промышленный район | Дополнительный результат обычной плавки в печах на его территории; требуется хотя бы одно подходящее завершённое промышленное здание |
| Сельскохозяйственный район | Шанс ещё одной стадии роста возрастных культур при событии естественного роста; требуется подходящее завершённое сельскохозяйственное здание |

Пример: жилой квартал даёт 120 мест; в жилом районе — 138. С базовыми 20 местами города общий лимит получается 158. Завершённый штаб с исходными 50 местами получает 57 мест. Целочисленные вместимости округляются вниз.

Для единичного результата плавки +15% означает 15% шанс получить дополнительный предмет; со связкой — 35%. Дробный выпуск округляется вероятностно, место в выходном слоте учитывается. Предметы с дополнительными метаданными исключены из бонуса плавки. При росте культур добавляется максимум одна стадия за событие. Отменённые другими плагинами события не меняются.

Бонус не создаёт пассивный выпуск ресурсов из каждого здания: применяются перечисленные действующие механики. Еда и вода Population остаются мощностью снабжения, без списания предметов.

## Настройки и сохранение

`config.yml`:

```yaml
limits:
  districts-per-town: 32
  cells-per-district: 256
  selection-cells: 128
bonuses:
  matching-building: 0.15
  industrial-combination: 0.20
  maximum-multiplier: 2.0
  industrial-requires: [forge, foundry, warehouse]
production:
  industrial-furnaces: true
  agricultural-crops: true
```

Настройки проверяются перед применением; при ошибке перезагрузка сохраняет прежние значения. Участники промышленной связки должны быть существующими промышленными проектами. `projects.yml` содержит русские названия, иконки и тип района всех 91 проектов. Изменения применяются через `/townydistricts reload`.

База сохраняется заменой временного файла до публикации изменения в памяти. Ошибка записи не подтверждает изменение. Повреждённый YAML, пересекающиеся записи или изменение размера сетки Towny останавливают загрузку районов без сброса базы. Размер сетки нельзя менять для существующей базы без отдельного переноса координат.

Публичный API `TownyDistrictsApi` зарегистрирован в Bukkit ServicesManager: `multiplier(UUID, String)`, `districts(UUID)`, `districtAt(UUID, int, int)`. Он возвращает неизменяемые снимки. Builds предоставляет `TownyBuildsApi.buildingFootprints(UUID)`; получение границ не загружает чанки. Циклических зависимостей плагинов нет.

## Проверка

Автоматически проверены все профили, соединение и владение участками, пересечения, недострой, промышленная связка, 364 повёрнутые площадки, расчёт вместимости, дробный выпуск и сохранение после перезапуска. Проверка меню, частиц и печей на запущенном игровом сервере в этой среде не выполнялась.
