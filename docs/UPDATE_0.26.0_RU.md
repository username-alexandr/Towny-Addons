# Обновление 0.26.0 — министры городского совета

В комплекте 30 отдельных аддонов. Новый NeverLandTownyCouncil 0.1.0 позволяет мэру назначать министров, выдаёт им отдельные Bukkit permissions и подключает полномочия к службам своего города.

## Должности по умолчанию

| Команда должности | Направление | Доступ |
|---|---|---|
| `economy` | Экономика | Бюджеты Treasury+, городские налоги Taxes, экспорт CSV, предложение налоговых законов Governance |
| `defense` | Оборона | Управление мобилизацией Builds и операциями Espionage |
| `construction` | Строительство | Улучшение городских проектов Builds, передача ресурсов склада в фонд проекта, предложение строительных законов |
| `foreign` | Внешняя политика | Городские соглашения и санкции Taxes, управление Trade и регулярными поставками |

Мэр остаётся фактическим мэром Towny. Council проверяет назначение, принадлежность к городу, действующего мэра, гражданство и permission при каждом вызове интеграции. Обычные условия действия продолжают действовать: стоимость, доступность здания, возраст для мобилизации, права команды, лимиты и подтверждения платежей.

Назначение министра не даёт права назначать других министров, менять гражданство, управлять национальными налогами или обходить защиту территории Towny.

## Команды

Основная команда — `/council`, также работают `/townycouncil`, `/ministers`, `/nltcouncil` и `/t ministers`.

```text
/council
/council menu [город]
/council appoint economy <игрок> [город]
/council appoint defense <игрок> [город]
/council appoint construction <игрок> [город]
/council appoint foreign <игрок> [город]
/council dismiss <должность> [город]
/council permissions <должность>
/council history [город]
/council help
/council reload
```

Назначает и снимает мэр своего города. Администратор с `neverlandtownycouncil.admin` может управлять любым городом, указав его имя. Для консоли город обязателен. На должность можно назначить зарегистрированного в Towny жителя, в том числе находящегося офлайн.

На каждое направление выделено одно место; совмещать министерства нельзя. Занятую должность сначала освобождают через `dismiss`. Назначить самого мэра министром нельзя.

## Citizens и смена власти

При установленном Citizens требуется право `HOLD_OFFICE`. По стандартным настройкам оно есть у гражданина и почётного гражданина, состоящих в этом городе. Временный житель и иностранец назначаться не могут. Неустановленный Citizens оставляет базовую проверку членства Towny; установленный, но неисправный Citizens приостанавливает полномочия.

Потеря `HOLD_OFFICE` приостанавливает назначение: оно видно в меню, но действия закрыты. Если право возвращается, министр продолжает работу. Выход из города окончательно снимает назначение. Повторное вступление его не восстанавливает.

При смене мэра весь министерский состав снимается. Новый мэр формирует его заново. Это действует и при победе нового мэра в Elections, и при административной смене правителя. Возвращение прежнего мэра не восстанавливает старые назначения.

Выборный совет и должности Governance/Elections сохраняются отдельно. `/t council` продолжает открывать совет Governance; в нём добавлена кнопка «Министры города». Назначенные министры не получают автоматически места в выборном совете и не меняют его электорат.

## Permissions

| Permission | По умолчанию | Назначение |
|---|---|---|
| `neverlandtownycouncil.use` | Все | Просмотр состава, справки и настроенных прав |
| `neverlandtownycouncil.manage` | Все; дополнительно проверяется реальное мэрство | Назначение и снятие министров своего города, журнал |
| `neverlandtownycouncil.admin` | OP | Управление любым городом и `reload` |
| `neverlandtownycouncil.minister.<должность>` | false | Маркер текущей активной должности |
| `neverlandtownycouncil.action.<действие>` | false | Отдельное полномочие министерства |

Стандартные действия:

- economy: `budget`, `tax`, `export`, `law_tax`;
- defense: `army`, `espionage`;
- construction: `build`, `law_construction`;
- foreign: `agreements`, `sanctions`, `trade`.

Списки хранятся в `plugins/NeverLandTownyCouncil/config.yml`, в `roles.<должность>.permissions`. Permission маркера должности добавляется автоматически. Для изменения роли можно убрать отдельное действие или добавить конкретное право другого плагина. Wildcard-узлы и выдача Council admin/manage через министерство отклоняются. Для применения: `/council reload`; ошибочный конфиг не заменяет действующие настройки.

Bukkit permissions сторонних плагинов могут действовать глобально. Ограничение своим городом обеспечено для перечисленных интеграций через публичный API Council; самостоятельно добавленные permissions требуют проверки правил соответствующего плагина. Права, выданные независимо через Towny, OP или менеджер permissions, сохраняют своё обычное действие.

Council использует собственные временные PermissionAttachment. При снятии, выходе, отключении и перезагрузке настроек удаляется только его attachment. Права других плагинов сохраняются. При входе восстанавливаются сохранённые полномочия. Дополнительная сверка раз в секунду обновляет attachments после изменения гражданства; городские действия проверяют актуальный статус сразу, до этой сверки.

CSV доступен по прежнему `neverlandtownytreasury.export` либо действующему полномочию economy `neverlandtownycouncil.action.export`. Видимость кнопки, справка, автодополнение и исполнение используют один шлюз доступа. Доступ к самому городу по-прежнему проверяет Treasury+.

## Сохранение и API

`plugins/NeverLandTownyCouncil/council.yml` содержит назначения и последние 500 событий назначения/снятия с городом, временем и инициатором. Сначала сохраняется полный новый снимок через AtomicFiles, затем меняется память и выдаются права. Сбой записи блокирует новые записи и отзывает права Council. Повреждённые записи не пропускаются при загрузке. После восстановления файла нужен перезапуск; `reload` меняет только настройки.

Публичный `ru.neverland.townycouncil.api.TownyCouncilApi`, версия 1, зарегистрирован в ServicesManager. Методы: `healthy`, `holders`, `role`, `permissions`, `allows`. Обращения выполняются в основном потоке сервера. Контракт использует только типы JDK; `allows` проверяет назначение, а вызывающий плагин также проверяет эффективное `Player.hasPermission`. Готовый адаптер: `ru.neverland.core.CouncilAccess`.

## Установка

1. Остановите сервер и сохраните резервную копию `plugins` и данных Towny.
2. Замените JAR комплекта по `versions.yml`, удалив старые версии тех же плагинов. Добавьте Council 0.1.0.
3. Запустите сервер. Council создаст конфиг; существующие выборные должности и назначения Governance не мигрируют в министерства.
4. Откройте `/council` и назначьте министров.

Изменены Builds 0.8.15, Governance 0.1.11, Taxes 0.1.7, TreasuryPlus 0.1.5, Trade 0.2.5 и Espionage 0.1.8. Остальные версии сохранены. Citizens 0.1.0, Elections 0.1.0 и Passport 0.4.0 продолжают использоваться.

Существующий `Builds/messages.yml` автоматически не перезаписывается. При желании обновите `only-mayor-upgrade` и `only-mayor-storage-contribute`, добавив в текст министра строительства.

Платформа: Paper/Purpur 26.2, Towny 0.103.2.0, Java 25; bytecode аддонов Java 17. Результаты серверной проверки: [validation/0.26.0](validation/0.26.0/README.md).
