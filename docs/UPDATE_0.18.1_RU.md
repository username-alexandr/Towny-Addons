# Обновление 0.18.1: запуск казны и серверная проверка рынка

## Исправление

На Purpur 26.2 с Vault и EssentialsX воспроизведён сбой TreasuryPlus 0.1.0 при наличии сохранённых городов: `Essentials API is called before Essentials is loaded`. Vault уже предоставлял экономический интерфейс, но Essentials ещё не завершил включение. Первый опрос счетов внутри `onEnable` приводил к отключению казны. При установленной, но отключённой казне рынок правильно запрещал бюджетные покупки.

В TreasuryPlus 0.1.1 первый опрос перенесён на первый серверный тик после включения плагинов. Бюджетные операции закрыты до успешной инициализации; повреждённая база по-прежнему блокирует работу. Добавлены мягкие зависимости от Vault, Reserve и Essentials. Смена структуры данных не требуется.

С 0.18.0 достаточно остановить сервер, заменить `NeverLandTownyTreasuryPlus-0.1.0.jar` на `NeverLandTownyTreasuryPlus-0.1.1.jar` и запустить сервер. Сохраните существующие папки плагинов. Market 0.1.0, Builds 0.8.8 и Trade 0.2.1 сохраняют версии. Полный релиз содержит все 25 аддонов.

## Границы проверки

Проверены серверные операции и сохранение после штатной остановки между этапами сделки. Это не имитация внезапного отключения питания. Исключения банка и файловой записи дополнительно покрываются существующими smoke-тестами.

Окна подтверждения и права с подключённым игроком, выдача через настоящий PlayerInventory, ItemsAdder, внешний серверный баланс и визуальная геометрия зданий в этом запуске не проверялись. Для тестовых зданий созданы записи и территории; постройка блоков в мире не выполнялась. Исследования при создании городов сообщали об ожидании первого расчёта Resources.

На стенде использован offline-mode с привязкой к 127.0.0.1. Проверка авторизации Mojang недоступна из этого окружения. EssentialsX 2.22.0 выводил сообщение о неподдерживаемой версии сервера и предупреждение об асинхронной задаче при остановке; его экономический интерфейс прошёл перечисленные проверки. Это не подтверждение полной совместимости всех функций EssentialsX с 26.2.

## Повторение

Исходник теста находится в `scripts/market-runtime-probe`. Он создаёт тестовые города, меняет их ресурсы и деньги, затем останавливает сервер. Используйте отдельный пустой стенд, без игроков и рабочих данных.

1. Подготовьте Purpur 26.2, Java 25, все 25 аддонов, Towny, Vault и EssentialsX. Один раз запустите и остановите стенд для загрузки серверных библиотек.
2. В `server.properties` задайте `server-ip=127.0.0.1`, отдельный `server-port`, `online-mode=false`.
3. Создайте в корне стенда файл `ALLOW_DISPOSABLE_MARKET_PROBE`.
4. Соберите пробник:

```sh
python3 scripts/market-runtime-probe/build.py --server-dir /absolute/path/to/disposable-server --java-home /absolute/path/to/jdk-25
```

5. Дважды запустите сервер из его каталога с JVM-параметром `-Dneverland.runtimeProbe=true`. Каждый запуск остановится автоматически. Первый создаёт сделки, второй проверяет их восстановление. Успех подтверждают оба маркера и файлы `first-passed.txt`, `restart-passed.txt` в папке пробника. При ошибке появляется `failed.txt`; одного кода выхода Java 0 недостаточно.
6. Для повторения с начала создайте новый пустой стенд. Не запускайте пробник на рабочем сервере и не включайте его JAR в пользовательский комплект.
