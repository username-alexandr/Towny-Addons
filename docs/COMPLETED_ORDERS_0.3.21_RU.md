# Contracts 0.3.21 — скрытие выполненных заказов

После подтверждённого зачисления награды карточка заказа исчезает из `/orders` у выполнившего его игрока и из подсказок `/orders accept`. У остальных игроков этот заказ остаётся на доске.

В уже открытой доске карточка убирается при следующей проверке, через 20 тиков регионального планировщика игрока. Остальные карточки сохраняют свои места, чтобы нажатие не попало на другой заказ. При повторном открытии оставшиеся предложения располагаются подряд. Если оплачены все предложения, меню показывает сообщение о выполнении всей подборки.

Выполненное задание без полученной награды остаётся доступным. Ожидающие зачисления, проверки ресурсов или административной сверки выплаты тоже не скрывают карточку. Забрать награду и посмотреть последние завершённые заказы можно через `/orders mine`.

Скрытие учитывает игрока, шаблон и дату доски, с которой был принят заказ. Если тот же шаблон появится в новой подборке после 00:00 МСК, старое выполнение его не скроет. Это действует и когда награда за вчерашнее задание получена сегодня. Принятые задания и журнал выплат сохраняются; повторное принятие того же предложения за текущий день по-прежнему запрещено.

Установка: остановить сервер, заменить предыдущий JAR Contracts на `NeverLandTownyContracts-0.3.21.jar`, запустить сервер. Папку плагина, данные и настройки сохранять. Изменять `orders.yml` не требуется.

Проверка: сборка Java 25 / Gradle 9 с Paper API 26.2; существующие проверки городских и компанийных контрактов, расчётов, журнала выплат и ежедневной доски, а также совместимости публичного API. Результаты — в `docs/validation/completed-orders-0.3.21/`. Запуск сервера Folia и визуальная проверка игровым клиентом для этой версии не проводились.

Код: `PublicOrders.java`, методы `paidTemplates`, `visibleTemplates`, `menu`, `refreshMenu` и `onTabComplete`. Механизм начисления денег и сохранения данных не изменён.
