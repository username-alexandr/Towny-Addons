# Изоляция Quests в полном наборе из 40 аддонов

Folia 26.2 build 7 / Towny 0.103.2.0, Java 25, три последовательные JVM на свежем tmpfs-стенде. Перед запуском проверены версии, хеши всех входных файлов каждого JAR и отсутствие пропущенных исходников. Установочный preflight прошёл для 40 аддонов и Towny. Изменённые общим аудитом и отсутствовавшие JAR пересобраны: 15 модулей, см. cold-refresh.log.txt.

- Первый запуск: 126 проверок, настоящий PluginDisableEvent Quests и сохранение всех 39 соседей включёнными и незамороженными.
- Ошибка конфигурации: 84 проверки, настоящий BROKEN_KIND в старом quests.yml, прогресс не переписан, чужие модули не поставлены на паузу.
- Восстановление: 83 проверки после адресного enable Quests и исправления файла. Завершённый проект и принятая политика сохраняются без повторного вознаграждения.

Точные JAR зафиксированы в artifacts.json и native-results.json; все три JVM завершились с кодом 0. Полные логи отличаются от оригиналов только удалением пробелов в концах строк. В них сохранены ожидаемая ошибка Quests, сообщения о временно неготовых API при порядке запуска и внешние ошибки DNS/системной телеметрии стенда.

Ограничения: Towny economy выключена; завершённый проект задан явно, мэр — офлайн Player substitute. Проверка подтверждает изоляцию и совместный запуск/остановку, а не все финансовые действия, сетевой клиент, продолжительный онлайн или готовность полного релиза.
