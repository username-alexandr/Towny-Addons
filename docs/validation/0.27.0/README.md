# Проверка 0.27.0

2026-09-13: отдельный сервер Purpur 26.2-2632, Towny 0.103.2.0, Java 25.0.4.1, Vault 1.7.3, EssentialsX 2.22.0, PlaceholderAPI 2.12.3, Passport 0.4.0 и все 31 аддон. Изменённые JAR собраны локально; остальные из опубликованного 0.26.0. SHA-256 — `jars.json`.

- Первый запуск: 40 успешных проверок.
- Последующий перезапуск: 16 успешных проверок.
- После остановок на диске подтверждены девять договоров и один оборонный инцидент.
- Проверены Towny, реальные Bukkit permissions, потеря гражданских прав, смена мэра, отзыв министерства при подтверждении в меню, типы/стороны договоров, Trade/Market/Taxes/Espionage, урон, стрелы, вредоносное облако, API outage, отказ диска и отключение плагина.
- Два тестовых класса Diplomacy дополнительно выполняют 60 проверок чистых правил, сроков, вассального графа, санкций, тарифов, строгого YAML и атомарной записи. Market проверяет завершение оплаченной покупки и остановку неизвестного списания после эмбарго.

`checks.txt` содержит все серверные утверждения. Проба использует настоящие Towny и CraftPlayer для урона; меню и полномочия проверяются через тестовые Player/InventoryView с настоящим PermissibleBase. Обработчики боевых событий вызываются на нативных объектах событий. Нагрузочное тестирование, реальные сетевые клиенты и визуальная проверка конкретного ресурспака не проводились. Рабочий сервер пользователя не изменялся.

Воспроизведение: `scripts/diplomacy-runtime-probe/README.md`. Полная Gradle/Maven-сборка всех модулей и API-контрактов выполняется единым `build_suite.py` в CI и при публикации. Приложенные SHA относятся к стенду до публикации; опубликованный комплект проверяется отдельно по SHA-256 GitHub assets.
