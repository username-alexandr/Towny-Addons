# Проверка Suite 0.43.2 / Contracts 0.3.27 — 27.10.2026

## Изменённый модуль

Contracts собран заново. Пройдены все 7 его исполняемых тестовых программ, 13 Python-тестов сборочных инструментов и контракт API Contracts (27 сигнатур/возможностей). Новая `MountedOrdersSmoke` содержит 76 проверок, существующая `HuntingSmoke` — 135, журнал выплат — 38, ежедневная доска — 61. Результаты: `contracts-tests.json`, `automated-checks.txt`.

Новый тест вызывает реальные обработчики PublicOrders с настоящими объектами PlayerFishEvent / EntityDeathEvent. Строгие двойники игроков запрещают доступ к их состоянию из чужого региона. Проверяются отложенный зачёт, пассажир лодки/плота/гаста/наземного транспорта, личные меч/копьё/булава/рука, лук/арбалет/трезубец, смена предмета после выстрела, поздняя отмена события, отсутствие природной метки моба, раздатчик/косвенный урон, режимы игры, полёт/элитры, права, пауза модуля и потеря владения регионом. Улов продвигает один заказ; реальная запись прогресса загружается заново без потери и повторного зачёта. Зарплатный фильтр и ограничение добычи в транспорте сохранены.

На настоящем прежнем Contracts 0.3.26 этот же тест падает на зачёте улова в лодке. Ожидаемый сбой и SHA-256 старого JAR записаны в `baseline-regression.txt`. Это подтверждает воспроизведение исходной причины, а не только выполнение нового кода.

Остальные 39 JAR не пересобирались: они побайтово совпадают с проверенным комплектом 0.43.1. Сравнение записано в `artifact-provenance.json`. `suite-tests.json` содержит накопленный отчёт 145 программ для 40 текущих бинарников: новый результат Contracts и прежние результаты неизменённых модулей. Это не заявление о повторной сборке всех модулей в данном исправлении.

`verify_release.py` подтвердил 40 JAR, 262 YAML, 90 зданий / 11 чудес и согласованность имён, версий, ресурсов и зависимостей.

## Границы

Клиент к стенду не подключался. Сценарии пассажира проверяют свойство Player.isInsideVehicle и реальный путь зачёта со строгими двойниками; это не физическая посадка живого игрока на каждый вид транспорта. Серверные прогоны проверяют загрузку комплекта и регрессии планировщиков/сохранения, а не ручную рыбалку с клиента. Инструкция для такого плейтеста есть в `docs/MOUNTED-ORDERS-0.43.2-RU.md`.

Нагрузочный тест с игроками, реальный экономический провайдер, клиентский CraftoUI и платные интеграции не проверялись. Экономика Towny намеренно выключена; сетевое предупреждение о ключе Mojang, предупреждения недоступной экономики и диагностика намеренно удерживаемой блокировки ожидаемы для этого изолированного стенда.
