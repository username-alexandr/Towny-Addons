# Проверка 0.45.0

- Builds 0.8.37: 40 исполняемых Java-программ и 6 опубликованных контрактов API; Contracts 0.4.1: 9 программ и 2 контракта. DailyOrdersSmoke: 665 утверждений, включая 670 шаблонов, цвета, древесину, малые партии, миграции и лимиты. 13 Python-проверок сборки.
- Остальные 38 JAR не пересобирались: SHA-256 сверены с 0.44.0. Накопленный отчёт для полного состава — 147 Java-программ, 42 контракта API, 7 проверок отказа хранилища. Это не повторный прогон всех 147 программ в этом изменении.
- Два полных запуска/остановки настоящего Folia 26.2 build 7 (14b7fee), Java 25.0.5, Towny 0.103.2.0. В каждом: 109 общих проверок, 20 блокировки/хранилища, 18 рейда/остановки, 11 SQLite/API склада и 22 меню/взносов. Уникальные run_id и SHA-256 40 JAR; CraftoUI server 0.8.14 также записан по SHA-256. Watchdog и ошибок жизненного цикла нет.
- Новый native BuildMenuProbe сначала воспроизводит исходное исключение serializeAsBytes на 272, затем проверяет образец NBT, количество/метаданные, настоящий previewContribution, реальную страницу MenuManager, Bukkit-клики, инвентарь/склад, недействительный старый список, двойной клик и обновления CraftoUI в том же контейнере.
- CraftoUI: 210 JUnit-тестов без ошибок; клиент скомпилирован против оригинального Minecraft 26.2 и Fabric API. 60 утверждений и 18 изображений настоящего AddonScreen через явные AWT/инвентарные/текстурные адаптеры. Рендерер проверен в двух темах и трёх разрешениях. Это не графический Minecraft-клиент; иконки и изображение схемы в этом стенде заменены тестовыми областями.
- Loader: отдельная регрессия на официальных Fabric/MixinExtras проверяет исправление старого ClassCastException. Knot 0.19.4 запускает тестовый preLaunch с текущим клиентским JAR и выбирает встроенный MixinExtras 0.5.5; окно игры не запускается. Подробные журналы и источники клиентских проверок — в комплекте CraftoUI.

Игроки и сетевой транспорт имитируются. Реальная банковская выплата, платное строительство, ручная сдача каждого нового материала, полный NLT-модпак и нагрузка с игроками не проверялись. Экономика Towny в disposable-стенде выключена. Для сохранения старого тестового рейда перед запуском продлён только срок синтетического рейда на остановленном стенде; это не изменение игрового плагина.
