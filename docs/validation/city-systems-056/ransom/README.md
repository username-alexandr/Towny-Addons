# Выкуп 0.6.7 / Control 0.6.5 — проверка 30 октября 2026

Выполнена холодная сборка по точной Folia 26.2 API, Towny 0.103.2.0 и Java 25. 17 исполняемых программ SiegesPlus, 15 Control, включая RansomStoreSmoke (26 SQL-проверок): точные ID и роли городов, дубли, остановка боёв, запрет поздних захватов, неизвестное списание/зачисление/возврат при рестарте, ручная сверка, атомарное завершение войны и нейтральный возврат. Полный выпускной набор проходит verify_release.py: 40 модулей, 40 проверенных JAR, 267 YAML, 90 зданий, 11 чудес.

Три последовательных запуска Folia 26.2 build 7 на одноразовом loopback сервере с Towny и ровно этими 40 JAR: 126 + 84 + 83 проверок. Все остальные аддоны пережили ожидаемое отключение/сбой Quests и его восстановление, ошибок загрузки или выключения остальных аддонов нет. SHA-256 каждого JAR — в jars.sha256.json; сокращённые результаты — в native-results.json. По сравнению с отдельным SQLite-тестом этот серверный тест проверяет загрузку/выключение набора, но **не проводит** реальную капитуляцию через Vault: Towny economy в нём намеренно отключена, мэр — офлайн фикстура без настоящего клиента.

Для реальной приёмки на сервере пользователя с его Vault, экономическим провайдером и двумя подключёнными игроками выполните сценарий в docs/RANSOM-0.6.7.md. Не считайте этот набор стабильным до получения такой квитанции. Старые блокирующие операции других аддонов также остаются отдельной задачей.
