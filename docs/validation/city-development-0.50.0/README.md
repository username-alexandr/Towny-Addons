## Нативные сценарии

- Загружены все 12 обновлённых модулей и зависимость Resources. Использованы настоящие Folia-регионы, BlockData, инвентари, файлы, Towny и SQLite.
- Мэр выбирает стиль один раз; старый сайт сохраняет исходную архитектуру. PreNewTownEvent отменяет создание до оплаты. Подтверждение возобновляет штатную команду Towny; затем настоящий NewTownEvent применяет сохранённый резерв выбора к тестовому городу.
- Все уникальные блоки/формы/направления максимальных уровней всех стандартных чертежей в трёх стилях приняты настоящим BlockData Folia. Отдельный Java-тест проверяет геометрию, роли, этапы и ориентации всех уровней и исторические варианты архитектуры.
- Современный завершённый чертёж доступен для ремонта; реальные материалы и исходный HP-профиль идут вместе. Нативный прогон обнаружил неразмещаемый предмет в декоре Великого канала; он исправлен до финального прогона.
- Рассчитан фактический дефицит материалов; образцы больших требований сериализуются с количеством 1. Изменение склада меняет отпечаток предложения. Динамический заказ резервирует деньги из настоящего Towny-счёта казны, дубль отклоняется.
- Прогноз экологии получен после штатного обновления ресурсов/наблюдений; пауза провайдера не выдаёт ложный готовый прогноз. Проект требует подтверждения ветви, отмена не открывает альтернативу.
- Суточное окно объявляется заранее и сохраняет предыдущее расписание до вступления в силу; повторная замена ожидающего изменения запрещена.
- Физический груз лагеря зачислен ровно один раз. Квитанция доступна для восстановления отправителя. Существующий API складов Logistics показывает лагерь. Коридор свободной земли ограничен окрестностью своего лагеря.
- Производственный CompanyBank выплачивает зарплату через настоящие Towny Account/AccountObserver при явно установленном тестовом провайдере. Повторный UUID не платит дважды. Подтверждённая работа сохранена в SQLite и обработана штатным процессором с множителем уровня.
- Благодарность мэра появляется в настоящей летописи. После полного выключения/старта сохранены стили, разные версии площадок, деньги/квитанции, расписание, запасы/доставка лагеря, отменённая ветвь и оплаченный динамический контракт. Зарплаты не повторились.

## Границы проверки

Нет подключённых Minecraft-клиентов. Для прав/инвентарей используются автономные CraftPlayer с настоящими сущностями в списке идентичности своего региона и перехваченными меню/командами. Сетевой протокол и фактический экран CraftoUI/наведение на 3D-превью этим тестом не сертифицированы. Завершение штатной команды создания заменено явной подготовкой тестового города и вызовом настоящего NewTownEvent; сами штатные проверки стоимости Towny сохранены в рабочем коде и изучены по исходникам 0.103.2.0.

Экономический адаптер тестовый, детерминированный и сохраняет свои балансы между двумя загрузками. Обёртка провайдера используется только для указания типа экономики Towny; внешний Vault/Essentials/Reserve этим прогоном не проверялся. Реальные личные и городские Towny-счета, их наблюдатели и производственный CompanyBank при этом задействованы.

Лагерь и завершённые площадки подготовлены как фикстуры. Полный сбор живой армии, движение курьеров по пользовательским дорогам, все реальные действия семи профессий, взрывы между авторизованными игроками и отдельно установленный SiegeWar требуют плейтеста на серверном наборе плагинов. Поведение прежних войн покрыто сохранёнными Java-тестами; нативный отчёт 0.49.0 остаётся отдельным историческим прогоном, а не выдаётся за новую проверку всех боёв.

В изолированном контейнере в консоли встречается недоступность сервисов Mojang и метрик ОС. В успешных прогонах нет ошибок включения/выключения плагинов, обработчиков событий и watchdog. Подробные консоли и утверждения находятся рядом.
