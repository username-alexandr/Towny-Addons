# Проверка компактного меню 0.45.1

Builds 0.8.38: повторно пройдены 40 исполняемых Java-программ, 6 контрактов API и 13 Python-проверок сборки. Остальные 39 JAR, включая Contracts 0.4.1, не пересобирались; их SHA-256 сверены с 0.45.0. Накопленный отчёт полного состава — 147 Java-программ и 42 контракта API; это не повторный запуск всех 147 программ в этом изменении.

Два полных запуска/остановки Folia 26.2 build 7 (14b7fee), Java 25.0.5, Towny 0.103.2.0, неизменённый CraftoUI server 0.8.14. В каждом: 109 общих проверок, 20 блокировки/сохранения, 18 рейда/остановки, 11 SQLite/API и 27 меню/сдачи. Нулевые ошибки, свежие run_id и хеши реальных JAR — native-results.json.

Нативная проверка использует настоящие CraftItemStack, Towny, BuildService, MenuManager, Bukkit-события и региональные/сущностные планировщики Folia. Проверены единственная кнопка на компактной странице, актуальные количество и цена, скрытие ненужных разделов, строительная зависимость, действительные имена/количества музейных артефактов, ЛКМ/Shift+ЛКМ, устаревший список и повторный клик. Тестовый инвентарь и сетевой игрок имитируются. Текст кнопки захвачен непосредственно из настоящего серверного ItemMeta.

Неизменённый AddonScreen из CraftoUI 0.8.14 с захваченным серверным описанием: 42 проверки, 6 PNG в двух темах и трёх размерах. AWT, инвентарь, сеть, предметные иконки и текстура схемы являются явными адаптерами. Реальный код рендерера скомпилирован заново из текущих исходников, а не переписан для картинки. Запуск: scripts/folia/build-menu/render.py с путями к CraftoUI, оригинальному Minecraft JAR, Gson, JDK25 и захваченному resource-tooltip.json.

Игровой клиент, живое подключение игрока, настоящий банковский провайдер и нагрузка с игроками не проверены. Экономика Towny в одноразовом стенде выключена. Перед запуском продлён только срок синтетического тестового рейда на остановленном стенде.
