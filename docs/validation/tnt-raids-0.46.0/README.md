# Проверка обновления 0.46.0

Проверены финальные JAR из `artifacts.json`: Builds 0.8.40 и SiegesPlus 0.2.0.

- Компиляция реальным JDK 25.0.5 с `--release 17`, genuine Folia 26.2 build 7 API и Towny 0.103.2.0. Все ресурсы и `plugin.yml` JAR побайтно совпадают с исходниками, тестовые классы в JAR отсутствуют.
- 40 исполняемых Java-проверок Builds и 4 SiegesPlus. Из новых правил: 137 проверок расстояния/конфигурации; 22 проверки настоящей SQLite, включая повторное попадание, прерванное разрушение, перезапуск, очередь, cooldown и журнал.
- Совместимость двух опубликованных API с v1 baseline: 58 и 16 сигнатур. Аудит исходников: 42 контракта, 111 точек вызова, 144 запроса; 13 Python-проверок прошли.
- Два последовательных запуска чистой Folia: 29 + 14 = **43 нативные проверки**, без watchdog и ошибок включения/отключения плагинов. Реальный TNT, двери, сундук, бедрок, граница чанка, отмена события, замена блока во время фонового сохранения, пауза, отмена во время паузы, сохранение HP и TextDisplay масштаба 0.45.
- Проверены реальные ограничения для своего/нейтрального/союзного города, щит новичка, отсутствие защитников и недоступная Army.

Проверка урона использует **явную тестовую замену `TntRaidEngine.Access`**. Настоящие игроки не входили; полноценная мобилизация Army и бои SiegeWar этим прогоном не сертифицированы. Нужен плейтест с игроками на копии сервера. Остальные 38 JAR не пересобирались и не запускались полным комплектом в этом прогоне.

В ранних пробных прогонах корректировалась тестовая фикстура: `newTownInternal` не задаёт дату регистрации, которую задаёт обычная команда создания города. Здесь сохранены результаты повторного прогона финального сценария. В консоли возможны внешние ошибки получения ключей Mojang в изолированной среде; они не относятся к плагинам и не влияют на локальный тест.

Воспроизведение нативных сценариев: `scripts/tnt-runtime-probe/README.md`. Все проверки выполнялись в отмеченном временном мире на 127.0.0.1.
