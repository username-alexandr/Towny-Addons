# Population 0.2.0 — подтверждённое сохранение

Настоящие Folia 26.2 build 7 (14b7fee), Towny 0.103.2.0 и Java 25.0.5. Два запуска одного изолированного сервера: 12 проверок первого запуска, 4 после полного перезапуска. Точные SHA-256 всех JAR находятся в native-results.json.

Проверены реальный PopulationService, физическая блокировка писателя population-data.yml, ошибка атомарной замены файла, сохранение подтверждённых значений при ошибке, остановка расчёта при отключённом поставщике Districts, отсутствие офлайн-убыли после восстановления. После намеренного отказа записи стенд восстанавливает именно последние подтверждённые байты файла перед перезапуском; автоматическое восстановление повреждённого диска не заявляется.

Банк и графический клиент не используются. Население назначено административным методом службы, не игровыми действиями. Город и участок созданы настоящим Towny API. Модель районных групп пока не подключена к меню — это проверка сохранения, а не завершение всего пункта Population.

Холодные проверки: PopulationPersistenceSmoke — 18; DistrictCohortsSmoke — 22 и 10000 распределений; прежний PopulationSmoke — 101 профиль, рост/убыль/снабжение/настройки/перезапуск. Сборка публикует JAR только после прохождения всех трёх программ.
