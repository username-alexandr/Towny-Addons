# Environment 0.2.1 — районные источники

Настоящие Folia 26.2 build 7 (14b7fee), Java 25.0.5, Towny 0.103.2.0, Districts 0.2.2, Builds и Environment 0.2.1. Два запуска: 26 проверок первого запуска + 13 после полного перезапуска. Точные SHA-256 всех плагинов стенда — native-results.json. Оба запуска завершились штатно без ошибок включения/отключения аддонов или watchdog.

Настоящие Towny участки, районные API и зарегистрированные площадки ратуши, парка и кузницы уровня V. Площадки и исходное загрязнение 55 с историей 7 циклов заданы как явные сохранённые тестовые данные; игровая покупка/строительство и естественное накопление загрязнения не заявляются. Офлайн Player/InventoryView/EntityScheduler явно подменены; серверные команды, инвентари и событие клика настоящие. Внешний клиент и сканирование реальных деревьев не проверялись.

Проверены точные суммы по районам и всем источникам, соответствие прежнему движку давления, физическое назначение парка и кузницы, отдельное природное восстановление, асинхронный API без ожидания SuiteState, кнопка главного меню, полный список источников района, права, неизменность файлов при просмотре, нейтральные false/повреждённая настройка нового раздела/отключение оценки Districts и восстановление тех же итогов и сохранённого загрязнения после перезапуска.

Resources и банк здесь не используются. Сохранение Environment осталось прежним синхронным; этот стенд не заявляет миграцию хранилища, проверку ошибки файловой системы или всей связки экологических эффектов с реальным выпуском склада. Старые коэффициенты счастья и сельского хозяйства проверены на неизменность при отказе только нового раздела.

Холодная сборка, выполненная root перед копированием JAR: 3 программы Environment, включая DistrictEnvironmentSmoke — 21 проверка + 10000 распределений, прежние EnvironmentSmoke и EnvironmentForecastSmoke. Точный результат нативного сценария применим к записанным SHA-256; общий релиз 0.52 остаётся незавершённым.
