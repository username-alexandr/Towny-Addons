# Population 0.2.1 — районные группы

Folia 26.2 build 7 (14b7fee), Java 25.0.5, Towny 0.103.2.0. 27 проверок первого запуска и 13 после полного перезапуска. Все точные JAR SHA-256 записаны в native-results.json.

Настоящие плагины Population, Districts и Builds, настоящий Towny API и региональный планировщик. Жилой/промышленный районы, площадки ратуши/таверны/кузницы уровня V сохранены через API как явные тестовые данные: покупка или строительство игроком не заявляются. Player, InventoryView, EntityScheduler — явные офлайн-подмены. Серверные инвентари, команды и событие клика настоящие; внешний вид в клиенте не проверялся.

Проверены физическое назначение площадок, все целочисленные итоги, точные десятичные доли еды/воды, асинхронное чтение, кнопка главного меню, обновление, отмена движения предметов, прекращение отложенного обновления после замены окна, права, нейтральное отключение раздела/оценки Districts, неизменность файлов при просмотре и восстановление одинаковых итогов после перезапуска.

Resources на этом стенде не установлен: проверка отсутствия второго расхода основана на чистой модели, точных суммах и read-only интеграции, а не на отдельной банковской или складской транзакции. Нативная проверка ошибки и задержки записи того же Population 0.2.1 фиксируется отдельно в population-persistence-021.

Холодные программы: CohortBoundarySmoke 21; DistrictCohortsSmoke 22 + 10000 распределений; PopulationPersistenceSmoke 18; прежний PopulationSmoke 101 профиль и прежние формулы. API audit: 49 контрактов, 137 мест вызова, 173 разрешённых запроса, 200 исполняемых тестовых программ (последнее — количество найденных программ, не заявление запуска всех 200).
