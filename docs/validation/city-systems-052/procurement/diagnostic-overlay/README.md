# Сохранённая диагностика overlay-стенда

В fixture7 первые два запуска прошли 21+4 проверок. Перед третьим запуском runner обнаружил прежние WAL/SHM, хотя после завершения первого JVM их отсутствие, успешный checkpoint и закрытие соединения были проверены. Третий JVM не запускался. Причина аномалии не установлена; эти фазы не считаются полной проверкой рестарта.

Финальный fixture8 на отдельном tmpfs прошёл все три запуска в одном runner, проверку физических копий и отсутствие незакрытых sidecar-файлов. Код хранения между этими двумя стендами не менялся. Это подтверждает конкретный финальный тест, но не устанавливает причину прежней аномалии и не заменяет проверку на диске сервера.
