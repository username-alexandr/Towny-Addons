# 0.37.0 — меню администрации

`/nltadmin` открывает инвентарное меню игроку с OP или правом `neverlandtownycontrol.admin`. Например, в LuckPerms: `/lp user Ник permission set neverlandtownycontrol.admin true`. Пермишен даёт полный административный доступ к аддонам, чтению журналов и CSV через дочерние права; выдавать дополнительные права каждого аддона не требуется. OP проходит проверку входа явно. Отрицательные права отдельных разделов учитываются для администраторов без OP.

Команда без аргументов из консоли сохраняет текстовый каталог. `/nltadmin list` выводит его и игроку, `/nltadmin logs` сразу открывает категории журналов. Старые команды `/nltmodules`, `/nltaudit`, `/nltadmin <аддон> native …` продолжают работать.

## Разделы меню

| Кнопка | Назначение |
|---|---|
| Журналы операций | Категории, фильтры, карточки записей, экспорт |
| Отмена без провала | Задачи с поддерживаемой нейтральной отменой |
| Перезапуск задач | Перезапуск таймера с сохранением прогресса |
| Пауза и время | Пауза, продолжение, продление и статус |
| Управление модулями | Состояние, отключение, разрешение запуска |
| Справочник аддонов | Все 36 игровых аддонов и их штатные команды |

Действия задач доступны у Events, Expeditions, Espionage, Contracts, Trade, Governance, Elections, Research, Builds и Logistics. Список формирует сам работающий аддон. Research поддерживает паузу, продолжение и безопасную отмену; Builds и Logistics — паузу и продолжение. Незавершённые финансовые расчёты не получают кнопок перезапуска или отмены. У остальных аддонов доступны состояние, управление модулем и справочник штатных команд.

Перед изменением задачи показываются её аддон, название, полный ID и последствия. Продление выбирается кнопками: 5, 15, 30, 60, 180 или 1440 минут; произвольное значение 1–10080 остаётся доступным командой. Перезапуск Events также снимает паузу, как и прежняя штатная команда; у остальных таймеров пауза сохраняется.

Отключение модуля сначала показывает список зависимых аддонов. Состояние сохраняется перед остановкой, простой не начисляет игрокам провалы. Разрешение запуска вступает в силу после полного перезапуска сервера. Горячее включение не выполняется.

## Журналы

Категории: все операции, денежные переводы, отдельные списания/зачисления, торговля и поставки, рынок и магазины, ресурсы и склады, компании, контракты, налоги, действия администрации, прочие операции. Новые неизвестные типы попадают в «Прочие», поэтому не теряются из интерфейса.

Карточка показывает время UTC, участников, инициатора, количество и материал, сумму или цену, результат. Подробности разделяют отправителя, получателя, инициатора и квитанцию с полными UUID. ID можно вывести в чат. Поддерживаются страницы по 36 записей, выбор города, межгородских операций, текущего дня/семи дней и точного результата. `COMPLETE`, `COMPLETED`, `DONE` и другие исходные статусы видны отдельно, поскольку относятся к разным этапам разных подсистем.

CSV сохраняет выбранную категорию и фильтры и включает все подходящие страницы, до 100000 строк. Путь выводится в чат; доступ — `neverlandtownycontrol.audit.export`. Точный поиск по игроку, UUID удалённого города, датам, модулю и тексту остаётся в `/nltaudit`. Новый фильтр: `category=ALL|BANKS|BANK_ENTRIES|TRADE|MARKETS|STORAGE|COMPANIES|CONTRACTS|TAXES|ADMIN|OTHER`.

Чтение выполняется вне серверного тика, одновременно не больше двух запросов на меню и команды вместе. Повреждение любого исходного журнала останавливает запрос целиком. Закрытое меню не открывается заново по завершении чтения. Кнопка проверки журналов проверяет контрольные суммы всех файлов.

Перевод, изменения банковских счетов и товарная сделка представляют разные свидетельства одной операции; их суммы не складываются. `OBSERVED` фиксирует команду и не доказывает оплату. Сохраняются [границы аудита 0.36.0](UPDATE_0.36.0_RU.md): сторонний `/pay`, прямые вызовы Vault другими плагинами и обычные сундуки требуют собственных интеграций.

## Контроль действий

Изменения через общий адаптер задач и `/nltmodules` записываются в категории «Действия администрации» с инициатором, целью и результатом. В неё входят те же действия через меню. Прочие штатные команды аддонов сохраняют существующее собственное логирование; меню не объявляет успешным действие только потому, что команда вернула `true`.

Права повторно проверяются на каждом клике и перед отложенным выполнением. Подтверждение одноразовое и действует 60 секунд. Закрытие окна, отзыв прав, исчезновение/замена цели или изменение её названия останавливают действие. Shift, двойной клик, цифровые клавиши, перетаскивание и клики по нижнему инвентарю не исполняют кнопки и не позволяют забрать предметы меню.

Адаптер `ActivityAdmin` предоставляет публичный протокол меню версии 1: `adminMenuVersion()`, `adminMenuTargets(CommandSender)` и `adminMenuAction(CommandSender, id, expectedName, action, minutes)`. Передаются только типы Bukkit/JDK. Control обращается к публичным методам текущего исполнителя команды; приватные репозитории других плагинов не читает. Сам владелец повторно проверяет права, точный ID и допустимое действие. Все прежние 38 публичных игровых API версии 1 сохранены.

Установка: обновить комплект из 37 JAR с полным перезапуском, удалив прежние JAR тех же аддонов. Control версии 0.4.0 использует новый адаптер, включённый в этот комплект.
