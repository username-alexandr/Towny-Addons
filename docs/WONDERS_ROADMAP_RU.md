# Следующая очередь Чудес Света

Предлагаемая очередь продолжает существующие пять Чудес, но не дублирует их постоянные эффекты. Каждое Чудо связывает несколько обычных зданий в отдельную городскую специализацию.

|---:|---|---|---|---|

| 2 | Мировое древо | полый проходимый ствол, корневая система и крона с площадками, 31×31×46 | Лесничество V, Ботанический сад IV, Ирригация III | расширяет лимит лесничества, ускоряет восстановление зелёных зон и смягчает засуху |

## Рекомендуемый порядок разработки

Начать с Колосса, Мирового древа и Небесного оррерия: они используют уже готовые API торговли, лесничества, воды, экспедиций и событий и не требуют новой боевой подсистемы. Затем добавить Хрустальный дворец. Терракотовую армию стоит выпускать вместе с формализованным API военных потерь, а Великий канал — после общего конструктора динамических линейных чертежей.

Каждое Чудо должно иметь проходимый вход, доступные внутренние уровни, завершённую крышу или намеренно открытую архитектуру, отдельную музейную коллекцию и одноразовую глобальную летописную запись. Постоянные бонусы следует выдавать через `TownyBuildsApi`, чтобы не возвращать циклические зависимости Paper.
