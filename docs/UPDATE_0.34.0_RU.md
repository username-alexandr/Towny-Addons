# Обновление 0.34.0: управление событиями и отключение аддонов

В комплекте 37 плагинов: 36 игровых аддонов и новый **NeverLandTownyControl 0.1.0**. Events обновлён до 0.4.0. Все остальные игровые аддоны получили общий протокол административной паузы; устанавливайте весь комплект с остановленным сервером и удаляйте прежние JAR-файлы заменяемых версий.

## События

Все команды доступны из консоли через `/townyevents`; игрок-администратор также может использовать `/t events`. Право — `mintevents.admin`, по умолчанию только у операторов. Названия городов с пробелами поддерживаются. Числовой аргумент у `extend` и `shield` указывается перед названием города.

| Команда | Действие |
| --- | --- |
| `start <событие> <город> [--force]` | Запуск; явный `--force` позволяет обойти щит новичка |
| `stop <город>` / `cancel <город>` | Нейтральная отмена без проваленного события, штрафных команд и квитанции поражения в репутации |
| `restart <город>` | Полный таймер события заново; вклады, цель и прогресс набега сохраняются |
| `pause <город>` / `resume <город>` | Заморозка и продолжение с оставшимся временем |
| `extend <минуты> <город>` | Продление на 1–10080 минут, в том числе на паузе |
| `shield <часы> <город>` | Выдать щит на 1–720 часов; `0` снимает щит |
| `success <город>` / `fail <город>` | Явно применить обычные последствия успеха или поражения |
| `status <город>` / `list` | Состояние, прогресс, оставшееся время и щит |
| `raidwave <город>` / `reload` | Волна активного набега / перезагрузка конфигурации |

Старые явные варианты `stop <город> success` и `stop <город> fail` продолжают работать. Обычный `stop` теперь всегда нейтрален. Отменённое событие получает обычный перерыв перед следующим случайным событием; запись о поражении не создаётся. Административное действие фиксируется в журнале сервера.

На паузе прекращаются эффекты события, появление врагов и повреждения от пожара. Взносы через меню и API закрыты; урожай и стратегическое производство получают нейтральный коэффициент. Для набегов сохраняется незавершённая часть волны, а прежние тела врагов становятся недействительными. `restart` продолжает то же событие с новым таймером, сохраняя уже внесённые предметы и убитых врагов в прогрессе.

Отмена и отключение не откатывают уже выполненные игровые действия: ранее внесённые предметы остаются израсходованными, завершённые платежи остаются в журнале, существующие повреждения пожара требуют обычного ремонта. Административная отмена не запускает новые штрафы, выплаты или автоматическую выдачу предметов.

## Щит нового города

Город получает **24 часа защиты от неблагоприятных событий Events** при создании в Towny. Это распространяется на набег, пожар, эпидемию, засуху и наводнение. Фестиваль доступен. Случайный выбор и обычный административный запуск учитывают щит.

Срок связан с созданием города и сохраняется по UUID; перезагрузка, переименование или смена мэра не выдают его заново. Для уже существующего города учитывается исходная дата регистрации, поэтому обновление не выдаёт всем городам новые сутки. Новое событие Towny также поддерживает создание городов сторонним кодом, ещё не записавшим дату регистрации. Повторное уведомление о создании не перезаписывает сохранённый щит. Это защита от городских событий данного аддона; правила PvP Towny и войн SiegeWar задаются соответствующими плагинами.

## Отключение модулей

Право — `neverlandtownycontrol.admin`, по умолчанию у операторов. Управление доступно из игры и консоли.

```text
/nltmodules list
/nltmodules status Events
/nltmodules plan Events
/nltmodules disable Events
/nltmodules enable Events
/nltmodules disable all
/nltmodules enable all
```

Можно использовать короткое имя (`Events`) или полное (`NeverLandTownyEvents`). `plan` показывает, какие зависимые аддоны тоже остановятся. Граф учитывает как зависимости загрузки, так и обращения через общие API-мосты. Связанные игровые системы могут образовать большую группу: например, остановка Events затрагивает производство и через него другие экономические системы. Независимые модули можно отключать отдельно.

`disable` действует сразу: сначала сохраняется запрос для всей группы, затем закрываются открытые инвентари игроков с действующими обработчиками сохранения и останавливаются плагины. Меню закрываются для всех игроков, чтобы не оставить доступных служебных предметов после снятия обработчиков. Состояние сохраняется между запусками. Внешнее отключение одного из управляемых плагинов также останавливает зависимых; обычное завершение работы сервера не создаёт административных пауз.

`enable` снимает запрос на отключение. **Плагин запускается при следующем полном перезапуске сервера.** Если другая отключённая зависимость ещё нужна этому плагину, он останется остановленным; список отображается в ответе команды. Горячая перезагрузка сторонними менеджерами не входит в этот протокол.

До загрузки репозиториев восстанавливаются оставшиеся сроки событий, контрактов, предложений, караванов, экспедиций, временного гражданства, выборов, обеспечения армии и других задач с абсолютными датами. Счётчики онлайн-времени, например содержание зданий и исследования, сами стоят на месте при отключении и не сдвигаются. Сроки наказаний, санкций и заключения не продлеваются. История, суммы, предметы и квитанции платежей сохраняются; неопределённый результат списания по-прежнему требует штатной сверки.

Самостоятельный календарь Seasons при административной паузе сохраняет фазу. Внешний RealisticSeasons и часы мира Minecraft продолжают жить по правилам своих владельцев. Control управляет плагинами этого комплекта; сторонние налоги Towny, экономика и SiegeWar продолжают работать по своим настройкам.

## Данные и восстановление

- `NeverLandTownyControl/modules.yml` — версия протокола, явно отключённые модули, зависимая группа и даты паузы.
- `module-resume.yml` в каталоге каждого возобновлённого аддона — журнал восстановления с исходными и целевыми снимками изменяемых файлов. Сбой между заменами файлов не приводит к повторному сдвигу сроков.
- Изменённый извне файл при незавершённом восстановлении вызывает остановку загрузки; снимок не записывается поверх неизвестных данных.
- `events-data.yml` дополнен `paused-at` и `shields`. Старые записи читаются с отсутствующей паузой. `fire-damage.yml` и платёжные журналы сохраняются.

Храните состояние Control и журналы восстановления вместе с резервной копией данных аддонов. Удаление JAR Control не снимает сохранённые запреты запуска: сами игровые аддоны читают протокол до инициализации.

## API и проверка

API Events остаётся версии 1. Добавлены совместимые методы `paused(UUID)` и `shieldRemainingMillis(UUID)` с реализациями по умолчанию. Форма `EventSnapshot` и прежние методы сохранены; `activeEvent` возвращает пустой результат для приостановленного события.

В наборе 120 исполняемых Java-тестов и 9 тестов инструментария. Дополнительная проверка `scripts/module_control.py` проверяет граф зависимостей и наличие ранней проверки состояния во всех 36 игровых аддонах. Серверный сценарий `scripts/safety-runtime-probe` выполняет три запуска JVM: первый запуск, работу с отключённой группой и возобновление. Кандидат прошёл 173 проверки: 93 + 33 + 47; проверены все 38 публичных API-контрактов, права, меню паузы, щит, отмена, перезапуск, зависимости, фактическое истечение исходного срока во время отключения, сохранность прогресса и денег.

Стенд: Purpur 26.2 build 2632, Towny 0.103.2.0, Java 25, SiegeWar 3.6.2, Vault и PlaceholderAPI. EssentialsX 2.22.0 на этом стенде сообщает о неподдерживаемой версии сервера; проверка балансa прошла, но это не подтверждает совместимость всех функций EssentialsX. Прогон не включает многопользовательскую нагрузку, клиентскую отрисовку ресурс-пака и полный сценарий активной войны стороннего SiegeWar.
