# Проверка 0.35.0

Локально собраны все 37 JAR на Java 25 с bytecode 17; проверена матрица версий и YAML. Выполнены 60 Java-тестов 11 затронутых модулей, включая сохранение паузы, ограничения команд, выборы и возврат резерва исследований. Полная проверка всех модулей и опубликованных API запускается обязательной CI-сборкой; её отчёт `suite-tests.json` прикладывается к релизу.

На отдельном Purpur 26.2 build 2632 с Towny 0.103.2.0 и SiegeWar 3.6.2 прошли три отдельных JVM: **135 + 33 + 62 = 230 проверок**. Проверены 37 загруженных аддонов и 38 API-контрактов, права команд, сохранение индивидуальных пауз, пропущенные реальные сроки во время отключения, отсутствие повторной оплаты, голоса и прогресс, груз и квитанции, нейтральная отмена, общий щит новичка и возобновление модулей. В логах зафиксированы ожидаемые ограничения внешних проверок сети и предупреждение Essentials о версии сервера; исследование в первом тике нового города ожидает начального расчёта ресурсов.

[Списки утверждений и SHA-256 тестировавшихся JAR](validation/0.35.0/). Проверка выполнялась без подключённых клиентов и нагрузки игроков; отображение ресурспака и производительность многопользовательского сервера этим прогоном не проверялись. Тестовый плагин предназначен только для отдельного сервера с защитным маркером и в комплект игровых JAR не входит.
