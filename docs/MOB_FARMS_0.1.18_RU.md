# Участки для ферм мобов

Обновление 23.10.2026: **NeverLandTownyDistricts 0.1.18**, **NeverLandTownyControl 0.4.10**. Все изменения предыдущей сборки строительства сохранены.

## Команды для игроков

| Команда | Что делает |
| --- | --- |
| `/t farm` | Открывает карту участков вокруг игрока |
| `/t farm allow` | Предлагает разрешить мобов на текущем участке; требуется подтверждение |
| `/t farm protect` | Предлагает снова включить защиту на текущем участке; требуется подтверждение |
| `/t farm list` | Показывает все участки города с разрешёнными мобами, включая другие миры |
| `/t farm show` | Показывает цветные границы рядом на 30 секунд |
| `/t farm status` | Показывает правило текущего участка |

Если `/t farm` занят другим плагином, используйте `/townyfarms` или `/nltfarms` с теми же аргументами. В меню `/t district` добавлена кнопка **«Фермы и защита от мобов»**.

**Оранжевый** — мобы разрешены. **Зелёный** — защита включена. **Серый** — чужая земля либо ограничение мира; описание карточки уточняет причину. Карта ориентирована на север, текущий участок подписан «Вы здесь». В карточке указаны мир, координаты участка, границы в блоках и его размер. При входе в зону с разрешёнными мобами появляется предупреждение над панелью предметов; при выходе показывается новое правило. Переключение соседних участков не требуется.

Настройка относится ко всей высоте участка. При обычном размере участка Towny 16 × 16 блоков это один чанк Minecraft. Если администратор изменил размер сетки Towny, меню честно показывает фактический размер: переключается целый участок Towny, а не произвольная его часть. Участки в группе Towny сначала нужно отделить от группы; массовое изменение группы из этого меню запрещено.

## Права

Смотреть карту и список могут жители с обычным правом `neverlandtownydistricts.use` (оно включено по умолчанию). Правило своего города меняют мэр, помощник с рангом Towny `assistant` или житель с правом:

```text
/lp user НИК permission set neverlandtownydistricts.farms.manage true
```

OP и `neverlandtownydistricts.admin` могут управлять чужим городом, находясь на его территории. Подтверждение повторно проверяет полномочия, владельца и настройки участка. Смена владельца или прав делает старое подтверждение недействительным.

## Что именно меняется

Изменяется только штатное разрешение мобов на выбранном участке Towny. Towny сохраняет его в своей базе; существующие настройки `/plot toggle mobs` тоже отображаются в карте и списке. Отдельной базы исключений нет. При снятии привата или удалении города у участка больше нет правил прежнего города; аддон не создаёт скрытых зон в дикой местности. Передача участка другому городу обрабатывается штатно Towny, а меню всегда показывает его текущие правила.

**PvP, огонь, взрывы, строительство, разрушение и использование предметов не переключаются.** Разрешённые мобы могут атаковать игроков; ферму нужно огородить. При включении защиты Towny снова может удалять мобов в этом участке и работа фермы может остановиться.

Запреты мира и отмена появления мобов другими плагинами остаются в силе. Настройка не создаёт мобов принудительно: нужны обычные условия появления, подходящая сложность и свободный лимит мобов. Отключённый `doMobSpawning`, мирная сложность и ограничения сторонних плагинов по-прежнему могут мешать ферме. Список видов, которые блокирует Towny, определяется конфигурацией Towny; при нестандартном списке он может включать не только враждебных мобов.

Пассивные бонусы защиты от урона от исследований/специализации сохраняются. Заработок `/orders` и профессий за AFK не включается: их существующие проверки честных действий остаются.

## Установка и настройки

Остановите сервер, сохраните резервную копию Towny и аддонов, замените JAR Districts и Control. Старые версии этих двух JAR уберите. Папки данных и конфигурации сохраните. Districts требует установленный Builds; сборка проверена с Builds 0.8.29 из предыдущего обновления.

Новые настройки работают со значениями по умолчанию. При необходимости добавьте в `plugins/NeverLandTownyDistricts/config.yml`:

```yaml
mob-farms:
  enabled: true
  entry-notifications: true
```

`enabled: false` отключает управление и подсказки. Штатные настройки участков сохраняются, фермы продолжают работать. `/townydistricts reload` перечитывает настройки. Если сами мобы должны снова блокироваться, включите защиту нужного участка через подтверждение; выключение аддона не выполняет массовую очистку ферм.

В журнале `/nltadmin` появился раздел **«Участки и фермы мобов»**: кто запросил изменение, участок, город и итог. Изменение не выполняется, если журнал недоступен. Включение мобов не требует изменения общегородского правила.

## Данные для будущего интерфейса и карты

В `TownyDistrictsApi` добавлены совместимые возможности `mobFarmPlots(UUID town)` и `mobProtectionAt(UUID world, int blockX, int blockZ)`. Первая возвращает список участков с локальным или принудительным разрешением мобов, вторая — состояние конкретной точки. Снимок `MobFarmPlot` содержит UUID города и мира, имя мира, координаты сетки, размер участка, локальное разрешение, фактический статус и русское описание. Для корректного рендера используйте размер и границы снимка; не считайте любую сетку Towny сеткой чанков.

Статусы: `PROTECTED`, `ALLOWED`, `FORCED_ALLOWED`, `WORLD_RESTRICTED`, `TOWNY_DISABLED`. При ограничениях мира локальный флаг может оставаться разрешённым, поэтому UI должен учитывать статус. API возвращает неизменяемые снимки без загрузки чанков. Будущие CraftoUI/JourneyMap-интеграции могут читать эти методы; клиентские моды этим обновлением не изменяются.

## Проверка

Пройдено 7 исполняемых тестовых программ и 28 проверок на Folia 26.2 build 7 за два запуска. Сборка: `python scripts/build_suite.py Districts Control`. Результаты и SHA-256 итоговых JAR находятся в `docs/verification/mob-farms-0.1.18`.

Тесты включают приоритет запретов мира, принудительные настройки, запрет изменения групп, отрицательные координаты и нестандартный размер сетки. Отдельный тест на Folia проверяет настоящие события появления/удаления мобов Towny, соседний защищённый участок, права и устаревшие подтверждения, API карты, содержимое меню и сохранение через перезапуск. Игровой клиент для визуальной оценки карты/частиц не подключался; реальная производительность AFK-фермы не измерялась.
