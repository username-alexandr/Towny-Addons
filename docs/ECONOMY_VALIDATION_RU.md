## Нативный стенд

- Предоставленный `server.jar`: NeverFolia **26.2-DEV-HEAD@14b7fee**, API `26.2.local-SNAPSHOT`.
- Java 25.0.2, два потока регионов Folia, два удалённых региона.
- Towny 0.103.2.0, VaultUnlocked 2.20.1.
- Реально загружены Builds, Contracts, Jobs, Companies, Taxes и Control.
- Одноразовый тестовый провайдер `EconomyFixture` зарегистрирован через обычный Vault Economy. Он не включён в устанавливаемые JAR и не предназначен для хранения рабочих денег.
- Сервер слушал только loopback; мир и города тестовые; телеметрия отключена.

**30 нативных проверок, 0 ошибок.** Полный протокол: `verification/folia-result.txt`; SHA-256 тестировавшихся JAR: `verification/folia-sha256.json`.

Проверены загрузка всех шести аддонов и инициализация команд `/orders` и `/jobpay`; реальное подключение адаптера Towny `VAULT`; зачисление 120 монет личному аккаунту жителя без города; отсутствие второй выдачи при повторном запросе и повторной загрузке журнала; перечисление 100 монет в казну с остатком 20 у жителя; списание существующих средств городской казны; остановка новых вызовов при выключенном провайдере, сохранение PENDING и единственная выплата после восстановления; владение двумя регионами и сущностями; долговечность записей происхождения блоков.

При запуске контейнера наблюдались внешние предупреждения OSHI о недоступной информации процесса и обращении Minecraft к сервису публичных ключей. Они не являются ошибками плагинов; стенд использовал локальный offline mode. Журналы приложены для самостоятельной проверки.

## Что этим не подтверждено

Нативная программа работала с Towny-аккаунтами, API, блоками и сущностями. Она **не заменяет полный проход настоящим игроком через GUI**, физическую покупку здания и все семь профессий с вашим экономическим провайдером. Доступный автоматический Minecraft-клиент не поддерживал протокол 26.2, поэтому такой прогон не объявляется выполненным.

Совместимость со сторонними защитами регионов, кастомными мобами/предметами, ботами, плагинами отката, конкретным провайдером сервера и нагрузка реального онлайна требуют игрового плейтеста. В первую очередь следует пройти `ECONOMY_ACCEPTANCE_RU.md`. До завершения этой приёмки пакет следует считать **MVP для плейтеста**, а не подтверждённым производственным релизом по всем критериям задания.

## Воспроизведение

```sh
python3 scripts/build_suite.py Contracts Jobs Control Builds Companies Taxes --stage dist/economy --report build/economy-tests.json
```

Для этого нужны Java 25 и Gradle 9 в PATH. Нативные исходники находятся в `scripts/folia/economy/`: собрать `build.py <одноразовый_сервер>` и запустить `run.py <одноразовый_сервер>`, задав JAVA_HOME и JAVA. В каталоге тестового сервера должны находиться нужные зависимости и шесть перечисленных аддонов. Перед запуском отключить телеметрию, ограничить адрес loopback, установить два потока регионов и включить экономику Towny. Скрипты создают тестовые аккаунты и города; никогда не запускать их на рабочем мире.
