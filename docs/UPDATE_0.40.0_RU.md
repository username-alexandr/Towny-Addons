# Обновление 0.40.0 — NeverLandTownyEnvironment

В комплекте 40 аддонов. Новый модуль связывает промышленность и зелёные зоны с довольством Population и выпуском сельскохозяйственной еды Resources.

## Правила

Каждый город начинает с загрязнением **0 из 100**. По умолчанию каждые **300 секунд работы сервера** к загрязнению прибавляется нагрузка действующих зданий, вычитается их очистка и **0,20** естественного восстановления. Значение ограничено диапазоном 0–100. Неоконченный цикл при перезапуске начинается заново, простои сервера не начисляются.

Учитываются завершённые уровни на территории города, разрешённая специализация, содержание и питание здания. Ручная остановка здания через Resources исключает его и из загрязнения, и из очистки. Это экологическая нагрузка действующей постройки: она сохраняется при заполненном складе или нехватке производственного сырья. Уровень I даёт одну долю нагрузки, V — пять. Простые деревья вне проекта лесничества не сканируются.

Выше **40** загрязнения штрафы линейно растут: при 70 — **−10 довольства и −20% аграрного выпуска еды**, при 100 — максимум **−20 довольства и −40% еды**. Еда, уже лежащая на складе, сохраняется. Производственные затраты, вместимость и прочие ресурсы не уменьшаются. Сезоны и экология перемножаются один раз.

Сельскохозяйственные здания: аграрный комплекс, пасека, ирригационная станция, селекционный центр, ботанический сад, Висячие Сады и Мировое древо. Меняется только их выпуск ресурса FOOD; влияние, знания и прочие продукты сохраняют прежние коэффициенты. На фермы Minecraft за пределами городской системы производства аддон не воздействует.

## Команды и меню

| Команда | Назначение |
|---|---|
| `/t environment` | Загрязнение, прогноз цикла, штрафы и кнопки разделов |
| `/t environment sources` | Промышленные источники и уровни |
| `/t environment cleaning` | Парки, лесничество и очистка |
| `/townyenvironment` | Прямая команда; алиасы `/nltenvironment`, `/cityenvironment` |
| `/townyenvironment reload` | Проверить и применить настройки, сохранив загрязнение и паузы |
| `/townyenvironment admin list` | Список городов для администратора |
| `/townyenvironment admin status <UUID>` | Состояние экологии города |
| `/townyenvironment admin pause <UUID>` | Заморозить загрязнение и снять экологические штрафы |
| `/townyenvironment admin resume <UUID>` | Возобновить расчёт с новым полным интервалом |
| `/townyenvironment admin restart <UUID>` | Перечитать здания и начать новый цикл без сброса загрязнения |

Жители используют `neverlandtownyenvironment.use` (по умолчанию доступно). Управление требует OP либо `neverlandtownyenvironment.admin`. Общее право `neverlandtownycontrol.admin` включает управление экологией. В `/nltadmin` доступны Environment в разделах задач и модулей и отдельная категория журналов **«Экология города»**. Переходы между нормальным, повышенным и критическим загрязнением записываются в эту категорию; административные действия — в журнал администрации. Каждый обычный цикл в журнал не дублируется.

## Безопасная остановка

Пауза отдельного города сохраняет показатель и убирает экологические штрафы; после возобновления действуют штрафы сохранённого уровня загрязнения. Никаких провалов, списаний ресурсов или накопления задолженности за паузу нет.

`/nltmodules plan Environment`, затем `/nltmodules disable Environment` используют общую систему безопасной остановки. Control включает зависимые аддоны в план, сохраняет их состояния и таймеры. Для временной остановки только экологических штрафов используйте паузу города. При фактически отключённом Environment его мосты возвращают нейтральные коэффициенты.

Если данные зданий недоступны, экологический цикл останавливается, показатель сохраняется, штрафы временно отключаются. После восстановления отсчёт начинается заново. Ошибка записи блокирует дальнейшие изменения и отключает штрафы до восстановления данных и перезапуска модуля. Повреждённый YAML не заменяется пустыми значениями.

## Настройки и баланс

`plugins/NeverLandTownyEnvironment/config.yml`: интервал 30–3600 секунд кратно 5, естественная очистка, порог штрафов, их пределы, аграрные здания, нагрузка и очистка каждого уровня. Допустимые максимумы настройки: −30 довольства и −80% выпуска еды. Изменение настроек действует на будущие циклы, накопленное загрязнение сохраняется.

## Установка

Остановите сервер, сохраните резервную копию, замените прежние версии JAR комплектом 0.40.0 и запустите сервер. Версии всех существующих аддонов повышены из-за обновления общего кода безопасного управления. Новые конфигурации Environment создаются автоматически; прежние файлы конфигурации других модулей не удаляйте.

Требуются Java 25, Paper/Purpur 26.2 и Towny 0.103.2.0. Для расчёта зданий нужен Builds; интеграции с Resources, Population, Upkeep, Power и Specialization подключаются при наличии. Циклические связи разрешаются через API после регистрации сервисов. API v1: `TownyEnvironmentApi.environment`, `happiness`, `agricultureMultiplier` (главный поток; неизменяемые снимки).
