# Обновление 0.24.0: гражданство

В комплект добавлен отдельный NeverLandTownyCitizens 0.1.0. Статусы: гражданин, временный житель, иностранец, почётный гражданин. `/t citizens` открывает карточку, `/t citizens help` — справку. Мэр назначает статус в своём городе, администратор — в любом.

| Файл обновления | Что меняется |
| --- | --- |
| NeverLandTownyCitizens-0.1.0.jar | Новый реестр статусов, сроки, права, меню и API |
| NeverLandTownyBuilds-0.8.14.jar | Проверки доступа к складам, лавкам, конюшням и страхованию |
| NeverLandTownyGovernance-0.1.9.jar | Электорат, должности и предложения зависят от статуса |
| NeverLandTownyTaxes-0.1.6.jar | Множитель муниципального налога зависит от статуса |
| NeverLandPassport-0.4.0.jar | Городской статус и его условия отображаются в существующем паспорте |

1. Остановите сервер и сохраните резервную копию папки `plugins` и данных Towny.
2. Удалите прежние JAR Builds, Governance, Taxes и Passport; положите пять файлов обновления. Остальные 24 аддона остаются на версиях комплекта 0.23.0. Папки данных сохраняются.
3. Запустите сервер. Проверьте `/t citizens`, паспорт и `/t citizens info <игрок> <город>`.
4. При необходимости настройте `NeverLandTownyCitizens/config.yml`, затем `/townycitizens reload`.

Существующие жители автоматически считаются гражданами своего города. Множители по умолчанию: гражданин ×1, временный ×1,25, иностранец ×1,5, почётный ×0,5. Множитель действует на муниципальные начисления NeverLandTownyTaxes в бюджет своего города; встроенные налоги Towny и глобальные/национальные сборы не перенастраиваются.

Пример: `/t citizens set Alex temporary 30`. По истечении 30 дней статус становится иностранным при проверке прав, без автоматического исключения игрока из Towny. Для почётного статуса: `/t citizens set Alex honorary 0`.

Выборы и голосования используют существующие правила Governance: `COUNCIL` или `ALL_RESIDENTS`. Citizens ограничивает право голоса и занятие должности; отдельной автоматической смены мэра в этом обновлении нет.

В Passport 0.4.0 меняются отображение гражданства и его паспортные placeholders. Сохраняются SQLite, прежнее текстовое значение, номер и статус документа, данные персонажа, скин и ресурс-пак. В присутствии Citizens редактирование гражданства производится через реестр города. Без Citizens работает прежнее текстовое поле.
