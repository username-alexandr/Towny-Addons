Java 25.0.2, Gradle 9.0.0; `scripts/build_suite.py` — **40 исполняемых тестовых программ успешно**: 35 для Builds и 5 для Control. После заключительной правки отмены подготовки при выходе инициатора Control пересобран и все 5 его программ повторно прошли. Отчёт содержит результаты окончательной сборки каждого модуля.

Проверены полнота и обрезание снимков, высота, отрицательные координаты, границы участка, повторяющиеся координаты, контрольная сумма, сохранность предыдущего файла при неудачной записи, повторное применение, новые изменения, контейнеры, занятые участки, системные блоки, запрет нижнего слоя и опасного вертикального сноса.

Изолированный сервер: предоставленное ядро **NeverFolia 26.2-DEV-HEAD@14b7fee**, API `26.2.local-SNAPSHOT`, Towny **0.103.2.0**, Java 25.0.2. Только Towny, два обновлённых аддона и тестовый DeletionProbe. bStats отключён. Использовались отдельные синтетические города и мир; производственные данные не изменялись. Экономика и руины выключены в тестовой конфигурации.

## Что этой проверкой не доказано

- Точная причина прежней полосы на рабочем сервере: для неё нужны реальные снимки и настройки Towny.
- Работа каждого стороннего плагина и административного обхода API на полном наборе серверных модификаций.
- Рендеринг меню человеческим клиентом, отложенный цикл руин и финансовые последствия удаления: тест использовал синтетических отправителей команд, а экономика и руины были выключены. Обработка казны не изменялась.
- Поддержка сетки Towny, отличной от 16×16, или автоматическое восстановление уже уничтоженной территории.
