# NeverLand Towny Suite 0.48.0

Обновление для Folia 26.2, Java 25 и Towny 0.103.2.0. Заменяются **Builds 0.8.42**, **SiegesPlus 0.4.0** и **Control 0.4.18**; остальные 37 JAR и CraftoUI сохраняют версии.

- Рейды через физический лагерь с костром и знаменем сохранены. Армия собирается у лагеря, командир начинает нападение через меню.
- Ремонт здания оплачивается из казны пропорционально утраченной общей прочности. Например, при 50% повреждений списывается 50% цены текущего завершённого уровня. Перед подтверждением показывается сумма; права, повреждения, деньги и бюджет проверяются повторно.
- Действующие укрепления и гарнизон уменьшают деньги и предметы, получаемые за кафедру ратуши. Проценты настраиваются, расчёт фиксируется в квитанции.
- В `/nltadmin` раздельно показаны рейды, урон TNT, отмены, защита и расчёт добычи, расходы на ремонт, результаты и записи для сверки.
- Прочность зданий сохраняется после рестарта. Неизвестный результат банковского вызова не повторяется автоматически. При штатной остановке завершается закрытие фонового хранилища.

Архив содержит три JAR, полные исходники, конфигурации, инструкцию и результаты проверки. Остановите сервер, уберите старые версии этих трёх плагинов, установите новые и сохраните папки данных. Восстановление выполняется только для зарегистрированных повреждений от боевого TNT; обычные базы и посторонние блоки не перезаписываются.

Проверка использует настоящие Folia/Towny/SQLite с явными тестовыми заменами допуска к бою и внешней экономики. Для основного сервера нужен плейтест с реальными бойцами и вашим Vault-провайдером.

[Установка, формула ремонта, защита добычи и сверка](docs/RAID-REPAIRS-0.48.0-RU.md).
