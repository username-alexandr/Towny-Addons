# NeverLand Towny Suite 0.37.0

Добавлено графическое меню администрации `/nltadmin`.

- Доступ для OP или по единому праву `neverlandtownycontrol.admin`; оно включает права аддонов и аудита.
- Отдельные кнопки журналов, нейтральной отмены, перезапуска, паузы/продления, модулей и справочника.
- Журналы разделены по типам операций; карточки сторон, инициатора, ресурсов, денег и квитанций, фильтры, страницы и CSV.
- Подтверждение изменений с указанием цели и зависимостей; повторная проверка прав и актуальной задачи, защита от двойных кликов и закрытых окон.
- Ивенты подключены к общему меню задач. Действия общего адаптера и управление модулями пишутся в отдельную категорию административного аудита.

Инструкция: [UPDATE_0.37.0_RU.md](https://github.com/username-alexandr/Towny-Addons/blob/v0.37.0/docs/UPDATE_0.37.0_RU.md).

Комплект: 37 JAR, архив плагинов, полные исходники, полный пакет и SHA256SUMS. Paper/Purpur 26.2, Towny 0.103.2.0, Java 25; bytecode Java 17. Обновление — полным перезапуском с заменой прежних JAR.
