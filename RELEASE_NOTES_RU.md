# NeverLand Towny Suite 0.38.0

Добавлен **NeverLandTownyQuests** — общие городские проекты с последовательными этапами.

- Акведук → вода в пяти районах 300 секунд → бани → санитарная реформа.
- Следующая цепочка: канализация → лечебница → устойчивое водоснабжение → общественное здравоохранение.
- `/t quests`: этапы, текущие условия, общий прогресс и результаты. Начинает мэр или уполномоченный своего города.
- Проверяются работающие здания, владение и связность территорий, полное снабжение водой и свежие расчёты ресурсов.
- Результаты открывают режимы в `/t policies`: +5 или +8 счастья с дополнительным содержанием санитарных зданий. Город принимает реформу отдельно.
- UUID города, условия начатой цепочки, этапы и открытия сохраняются. Нет повторных наград, провалов при административной отмене или потери прогресса при отключении аддона.
- Quests подключён к `/nltadmin`; добавлена категория журнала «Городские проекты». Общее административное право включает новый модуль.

Инструкция: [UPDATE_0.38.0_RU.md](https://github.com/username-alexandr/Towny-Addons/blob/v0.38.0/docs/UPDATE_0.38.0_RU.md). [Проверки и их границы](https://github.com/username-alexandr/Towny-Addons/blob/v0.38.0/docs/VALIDATION_0.38.0_RU.md).

Комплект: 38 JAR, архив плагинов, полные исходники, полный пакет, отчёты тестов и SHA256SUMS. Paper/Purpur 26.2, Towny 0.103.2.0, Java 25; bytecode Java 17. Обновление — полным перезапуском с заменой прежних JAR.
