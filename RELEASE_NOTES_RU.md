# NeverLand Towny Suite 0.22.0

Релиз надёжности и унификации всех 27 аддонов.

- Общие версионируемые API-контракты и понятная диагностика необязательных интеграций.
- Лавка городских зданий теперь восстанавливает незавершённую покупку после сбоя без двойного списания, зачисления или выдачи.
- Публичный API склада и каталога зданий заменил обращения к внутренним классам Builds.
- Единые правила атомарного сохранения и блокировки изменений после ошибки записи для критичных данных.
- `CivicService` разделён на меньшие сервисы без изменения каталога и стоимости строительства.
- CI запускает все 86 исполняемых smoke-проверок во всех 27 модулях, включая Maven-модули.

Полный комплект — **27 JAR**, архивы плагинов, исходников и полного проекта, модели, CSV стоимости строительства и SHA256SUMS. Все модули получили исправленную patch-версию; данные и конфигурации 0.21.0 совместимы.

Проверено на Purpur 26.2 build 2632, Towny 0.103.2.0 и Java 25: два запуска с перезапуском, загрузка и штатное отключение всех 27 аддонов. Ошибок аддонов не обнаружено.

Остановите сервер и замените все 27 JAR одновременно, не удаляя папки данных. [Подробности обновления и проверки](docs/UPDATE_0.22.0_RU.md).
