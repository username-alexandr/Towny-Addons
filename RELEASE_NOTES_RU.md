# NeverLand Towny Suite 0.47.0

Обновление к совместимому комплекту 0.46.0 для Folia 26.2, Java 25 и Towny 0.103.2.0. Заменяются Builds 0.8.41, SiegesPlus 0.3.0 и Control 0.4.17; остальные 37 модулей сохраняют версии.

Нападающие строят костёр и знамя на свободной земле рядом с чужим городом, регистрируют лагерь и собирают у него мобилизованную армию. Мэр или генерал начинает рейд через меню лагеря. После подготовки боевой TNT пробивает двери и стены по прежним правилам прочности. Потеря костра или знамени прекращает нападение.

Разрушение основной кафедры завершённой ратуши даёт атакующему городу одну добычу за рейд: по умолчанию 10% казны и 10% общего склада. Проценты настраиваются. Деньги переводятся между казнами, новая валюта не создаётся. Зарезервированные предметы сохраняются при полном складе и перезапуске; книга кафедры возвращается защищавшемуся городу. Захват не меняет мэра или владельцев участков.

В `/nltadmin` добавлен раздел «Рейды и добыча» с отдельными журналами денег, ресурсов и записей для сверки. Вызов банка с неизвестным результатом не повторяется автоматически. Завершённые здания по умолчанию больше не восстанавливают утраченные блоки при запуске сервера.

Архив обновления содержит три JAR, полные исходники, примеры конфигураций, инструкцию, результаты проверки и контрольные суммы. Остановите сервер, удалите старые JAR этих трёх плагинов, установите новые и сохраните папки данных. Не ставьте рядом две версии одного плагина.

Проверено: 54 Java-программы, 13 Python-проверок, совместимость восьми API, 47 + 30 = 77 нативных проверок в двух запусках Folia. Проверка использует явный допуск к рейду и детерминированный внешний экономический адаптер с настоящими Towny Account; реальная положительная мобилизация игроков и подключение Vault требуют плейтеста.
