# NeverLand Towny Suite 0.23.0

27 отдельных аддонов для Paper/Purpur 26.2, Towny 0.103.2.0 и Java 25.

- Все меню используют светлые заголовки, контрастные названия, переносы описаний и выделенные действия.
- Торговый центр получил значок колокола; справка логистики показывает команды по отдельности.
- Казна возвращает в предыдущее меню. CSV доступен только с `neverlandtownytreasury.export` (по умолчанию операторам).
- Пожары охватывают деревянные постройки и декор. Часть блоков остаётся целой, часть исчезает без дропа и требует ручного ремонта. Повреждения сохраняются после перезапуска.
- Меню `/t events repairs` показывает материалы, координаты и подсветку; `/t events repair` подтверждает установленные блоки.

[Настройка и обновление](https://github.com/username-alexandr/Towny-Addons/blob/v0.23.0/docs/UPDATE_0.23.0_RU.md). Результаты сборки — `suite-tests.json` среди файлов выпуска.

Вложения: 27 JAR, архив плагинов, исходники, полный архив, модели, баланс ресурсов и SHA256SUMS.
