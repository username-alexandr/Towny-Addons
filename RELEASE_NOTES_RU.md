# NeverLand Towny Suite 0.22.1

27 отдельных аддонов для Paper/Purpur 26.2, Towny 0.103.2.0 и Java 25.

- Журналы наград экспедиций и расчёта разовых караванов с остановкой неопределённых операций до сверки.
- Квитанции склада защищают резерв, разгрузку и возврат от повторного выполнения.
- Подтверждение фактического сохранения инвентаря с учётом структуры миров 26.2.
- Исправления публичных API, атомарного сохранения и диагностики ошибок.
- Единый запуск тестов; исходники без старых JAR и кэшей сборки.

**Перед обновлением сделайте резервную копию. Старые награды и караваны требуют сверки:** [инструкция](https://github.com/username-alexandr/Towny-Addons/blob/v0.22.1/docs/UPDATE_0.22.1_RU.md).

[Результаты серверной проверки](https://github.com/username-alexandr/Towny-Addons/blob/v0.22.1/docs/VALIDATION_0.22.1_RU.md). Отчёт запуска всех тестов при сборке релиза — `suite-tests.json` среди файлов выпуска.

Вложения: 27 JAR, архив плагинов, архив исходников, полный архив, модели, баланс ресурсов и SHA256SUMS. Удалите прежние версии JAR при замене.
