# NeverLand Towny Suite 0.40.0

Добавлен **NeverLandTownyEnvironment** — экология города.

- Загрязнение 0–100: промышленность повышает нагрузку; парки, лесничество и зелёные зоны очищают город.
- Высокое загрязнение снижает довольство Population и выпуск еды аграрных зданий Resources.
- `/t environment`: состояние, прогноз, источники, очистка и штрафы; русский интерфейс.
- Пауза, возобновление, повторная проверка, безопасное отключение через `/nltadmin`; отдельная категория экологического журнала.
- При паузе и недоступности данных загрязнение сохраняется, экологические штрафы отключаются; начислений за простой нет.
- Настраиваемые коэффициенты, атомарное хранение по UUID города и публичный API v1.

Комплект: **40 JAR**, исходники, контрольные суммы и отчёты проверок. Обновлены версии всех аддонов с общим кодом управления. Заменяйте прежние JAR, сохраняя данные и настройки.

Платформа: Java 25, Paper/Purpur 26.2, Towny 0.103.2.0.

Подробности: [обновление и баланс](docs/UPDATE_0.40.0_RU.md), [проверки](docs/VALIDATION_0.40.0_RU.md).
