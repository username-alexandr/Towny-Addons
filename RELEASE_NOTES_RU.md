# NeverLand Towny Suite 0.27.1

Исправление совместимости API для комплекта из 31 отдельного аддона.

- Market снова принимает API склада Builds: исправлена возможность `refund` и полный список необходимых операций.
- Companies и Contracts взаимодействуют через публичные сервисы с версиями и возможностями.
- Сохранённые API-подключения отклоняют вызовы после отключения или замены поставщика; диагностика различает причины отказа.
- Проверенные мутации Builds, Contracts, Events и Chronicles защищены от вызова из рабочего потока.
- Общие проверки автоматически сверяют потребителей, 33 контракта и совместимость с опубликованным API 0.27.0. Gradle `smokeTest` и сборка комплекта используют один механизм обнаружения тестов.

Проверки перед публикацией: 100 исполняемых тестов, 7 проверок инструментов, 739 элементов опубликованного API, 450 утверждений на отдельном Purpur-сервере с перезапуском. Каноническая сборка Gradle/Maven выполняется в Verify и повторяется при публикации.

Обновляются все 31 JAR; форматы игровых данных сохранены. Остановите сервер, сделайте резервную копию и удалите прежние JAR этих аддонов перед установкой новых.

[Подробности и результаты](docs/UPDATE_0.27.1_RU.md). Серверный прогон выполнен на тестовом стенде; производственный сервер этим релизом не обновлялся.
