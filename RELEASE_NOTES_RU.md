# NeverLand Towny Suite 0.36.0

Добавлен административный журнал денежных и ресурсных операций.

- `/nltaudit search|export|status`: поиск по городам, игрокам, направлению, типу, ID и датам; CSV для разбирательств.
- Банковские операции Towny, караваны и пошлины, регулярные поставки, рынок и лавки, складские перемещения, компании, муниципальные заказы и налоги.
- UUID и имена сторон, инициатор при наличии, точный товар/количество, сумма, назначение и этап. Подготовка, неизвестный результат и отмена не выдаются за завершённый перевод.
- История по месяцам с контрольными суммами. Повторная обработка квитанции не дублирует этап; ошибка записи не повторяет платёж.
- Отдельные права просмотра и экспорта, чтение вне основного потока. Работающие аддоны пишут собственный аудит и без Control.

Команды, схема записей и границы покрытия: [UPDATE_0.36.0_RU.md](https://github.com/username-alexandr/Towny-Addons/blob/v0.36.0/docs/UPDATE_0.36.0_RU.md).

Комплект: 37 JAR, архив плагинов, полные исходники, полный пакет и SHA256SUMS. Paper/Purpur 26.2, Towny 0.103.2.0, Java 25; bytecode Java 17.
