# Проверка API планирования на настоящей Folia

Используйте только новый одноразовый loopback-стенд с маркером ALLOW_DISPOSABLE_RAID_PROBE. prepare.py требует готовые JAR текущих версий; build.py компилирует probe. run.py запускает first и restart отдельно. Нужны Java 25 и Folia 26.2.

Проверяются настоящие Towny/Builds/ItemStack, пользовательские цены на 272/120/80 предметов, сохранённый фонд/склад, API и ограничения очереди. Умышленно повреждённый custom override вызывает ровно одну ожидаемую строку ошибки; остальные ошибки плагинов запрещены. Неверная цена не заменяет старый файл. До штатной остановки исходный корректный каталог восстановлен.

30 + 30 проверок. Нет сетевого игрока, финансового платежа или утверждения о завершении строительства. Результаты точных JAR находятся в docs/validation/city-systems-052/building-planning.
