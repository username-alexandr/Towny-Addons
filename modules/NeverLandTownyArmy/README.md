# NeverLandTownyArmy

Отдельная армия города: заявка и присяга, звания, четыре рода войск, дежурства, подготовка, мобилизация, военные запасы и дисциплина.

Документация, команды, permissions, API и порядок миграции: [обновление 0.31.0](../../docs/UPDATE_0.31.0_RU.md).

Сборка и все исполняемые тесты модуля: `python scripts/build_suite.py Army` из корня репозитория. Полный комплект: `python scripts/build_suite.py --stage dist/plugins`.
