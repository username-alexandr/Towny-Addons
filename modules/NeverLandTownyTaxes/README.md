# NeverLandTownyTaxes 0.1.1

Налоги, экономические санкции и соглашения для Paper/Purpur 26.2 и Towny 0.103.2.0.

## Возможности

- глобальные, государственные, городские и индивидуальные налоговые политики;
- фиксированный, подоходный и транзакционный налог;
- автоматический сбор через экономические счета Towny/Vault;
- задолженность при невозможности списания;
- серверный резерв, городские и государственные получатели;
- блокировка торговли и команд, налоговые множители;
- налоговые освобождения, торговые льготы и смягчение санкций;
- сроки действия, журнал операций и безопасное YAML-хранение;
- API и интеграция с NeverLandTownyTrade.

PlaceholderAPI: `%townytaxes_debt%`, `%townytaxes_town_debt%`, `%townytaxes_town_policies%`, `%townytaxes_town_sanctions%`, `%townytaxes_tax_multiplier%`, `%townytaxes_server_reserve%`.

## Команды

- `/t taxes` — налоги города;
- `/t sanctions` — экономические санкции;
- `/t agreements` — соглашения и сделки;
- `/n taxes`, `/n sanctions`, `/n agreements` — государственная экономика;
- `/townytaxes` — административное управление;
- `/taxytowny` — совместимый алиас.

## Установка

Установите JAR вместе с Towny и экономическим плагином Vault. После установки полностью перезапустите сервер. Горячая перезагрузка плагинов не поддерживается.
