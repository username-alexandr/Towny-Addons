# NeverLandTownyTaxes 0.1.20

Налоги, экономические санкции и соглашения для Paper/Purpur/Folia 26.2 и Towny 0.103.2.0.

## Возможности

- глобальные, государственные, городские и индивидуальные налоговые политики;
- фиксированный, подоходный и транзакционный налог;
- автоматический сбор через экономические счета Towny/Vault;
- задолженность при невозможности списания;
- серверный резерв, городские и государственные получатели;
- блокировка торговли и команд, налоговые множители;
- налоговые освобождения, торговые льготы и смягчение санкций;
- сроки действия, журнал операций и безопасное YAML-хранение;
- API и интеграция с NeverLandTownyTrade.

PlaceholderAPI: `%townytaxes_debt%`, `%townytaxes_town_debt%`, `%townytaxes_town_policies%`, `%townytaxes_town_sanctions%`, `%townytaxes_tax_multiplier%`, `%townytaxes_server_reserve%`.

## Команды

- `/t taxes` — налоги города;
- `/t sanctions` — экономические санкции;
- `/t agreements` — соглашения и сделки;
- `/n taxes`, `/n sanctions`, `/n agreements` — государственная экономика;
- `/townytaxes` — административное управление;
- `/taxytowny` — совместимый алиас.

## Установка

Установите JAR вместе с Towny, поддерживаемым экономическим провайдером и необходимым ему мостом (например, Vault). Один Vault без провайдера не создаёт экономику. После установки полностью перезапустите сервер. Горячая перезагрузка плагинов не поддерживается.

## Исправление 0.1.20

Перед созданием счетов и финансовыми операциями проверяется `TownyEconomyHandler.isActive()`. Если адаптер отсутствует или экономика Towny выключена, Taxes приостанавливает сборы и погашение долгов: без списаний, новых долгов и записей о неудачных сборах. Предупреждение выводится один раз за простой. Управление политиками, санкциями и соглашениями остаётся доступно.

После восстановления сбрасывается база сравнения доходов, пропущенные фиксированные сборы переносятся на следующий интервал. Пауза сохраняется в `data.yml`, поэтому перезапуск не вызывает взысканий за простой. Уже существующие долги сохраняются. Ошибка провайдера при списании не создаёт новый долг.

При обновлении остановите сервер, замените `NeverLandTownyTaxes-0.1.19.jar` на `NeverLandTownyTaxes-0.1.20.jar` и запустите сервер. Сохраняйте существующую папку данных. Исправление защищает Taxes; для работы денежных операций необходимо восстановить экономический адаптер Towny.
