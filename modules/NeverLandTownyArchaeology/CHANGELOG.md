# 0.1.6

- Добавлены 12 артефактов и шесть отдельных коллекций для новой очереди Чудес Света.
- Все новые реликвии включены в таблицы добычи существующих археологических участков.
- Музей хранит требования для всех 11 Чудес и показывает их русские названия.

# 0.1.5

- Убран циклический порядок загрузки с Builds и Reputation.
- Интеграция с Builds продолжает работать через Bukkit Services API во время обращения.

# 0.1.4

- Артефакты из одного вызова `/artifact give` теперь складываются в обычные стаки.
- Стаки можно безопасно разделять и объединять до передачи городскому музею.
- Музей учитывает каждый экземпляр партии и не позволяет сдать больше подписанного количества.
- Сохранена проверка старых одиночных артефактов и прежних серийных номеров.

# 0.1.3

- Добавлена короткая админ-команда `/artifact give <игрок> <артефакт> [количество]`.
- Добавлено отдельное право `townyarchaeology.admin.give`.
- Добавлено автодополнение игроков, ID артефактов и количества.
- Сохранена совместимость с `/townyarchaeology give`.

# 0.1.2

- Добавлены `/t archaeology`, `/t arch` и сохранена `/t museum`.
- Прямая `/archaeology` оставлена запасной формой, администрирование выполняется через `/townyarchaeology`.

# 0.1.1

- Плагин переименован в `NeverLandTownyArchaeology` с безопасной миграцией данных.
- Сохранена совместимость PDC существующих артефактов, серий, подписей и участков раскопок.
- Обновлены зависимости пакета и защита PlaceholderAPI.
- Проверены русские названия коллекций, артефактов и элементов GUI.

# 0.1.0

- четыре типа процедурных раскопок;
- шестнадцать артефактов пяти редкостей;
