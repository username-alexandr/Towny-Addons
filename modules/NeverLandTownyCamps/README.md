# NeverLandTownyCamps 0.1.6

Процедурные временные лагеря для Paper/Purpur 26.2. Плагин работает самостоятельно на survival/RPG/Civs-серверах и дополнительно учитывает территории Towny. Для сервера требуется Java 25.

## Установка

1. Положите `NeverLandTownyCamps-0.1.6.jar` в `plugins/`.
2. При необходимости установите Towny, ItemsAdder и PlaceholderAPI — все три интеграции необязательны.
3. Запустите сервер и настройте файлы в `plugins/NeverLandTownyCamps/`. Старая папка переносится автоматически.
4. Применяйте правки командой `/townycamps reload`.

Плагин не использует NMS. Иконки ItemsAdder автоматически заменяются ванильными, если ItemsAdder отсутствует или указанный ID не найден.

## Архитектура лагерей

- Уровень 1: палатка 3×3, коврик, бочка на 9 слотов, костёр с обкладкой и пенёк.
- Уровень 2: палатка 5×4, коптильня, верстак, двухместная кровать, четыре факельных столба и схрон на 18 слотов.
- Уровень 3: павильон 7×5, каменный фундамент, печи, наковальня, люстра, палисад, четыре башни, флагшток и схрон на 27 слотов.

Структуры строятся алгоритмически и поворачиваются по направлению игрока. Палитра выбирается по биому: равнины, тайга, пустыня, джунгли, саванна, снежные горы или Нижний мир. Все материалы находятся в `styles.yml`.

Перед изменением каждого блока сохраняются материал, BlockData и содержимое исходного контейнера. При улучшении старый уровень снимается, свободное место проверяется повторно, после чего строится новый. При `/camp pack` или распаде восстанавливается весь первоначальный снимок. Предметы из виртуального схрона и рабочих печей возвращаются владельцу либо выпадают на месте лагеря.

## Команды

| Команда | Назначение | Право |
|---|---|---|
| `/camp` | Главное GUI | `mintcamps.use` |
| `/camp create` | Поставить лагерь перед игроком | `mintcamps.use` |
| `/camp spawn [владелец]` | Телепорт в свой или доверенный лагерь | `mintcamps.use` |
| `/camp trust <ник>` | Добавить соратника | `mintcamps.use` |
| `/camp untrust <ник>` | Удалить соратника | `mintcamps.use` |
| `/camp storage` | Открыть схрон | `mintcamps.use` |
| `/camp barrier` | Переключить священный купол | `mintcamps.use` |
| `/camp pack` | Свернуть лагерь | `mintcamps.use` |
| `/townycamps edit` | Редактор стоимости уровней | `mintcamps.admin` |
| `/townycamps reload` | Перезагрузить настройки | `mintcamps.admin` |
| `/townycamps info <ник>` | Диагностика лагеря | `mintcamps.admin` |
| `/townycamps pack <ник>` | Принудительно свернуть лагерь | `mintcamps.admin` |

Дополнительные права: `mintcamps.bypass.protection` и `mintcamps.bypass.placement`.

- `%mintcamps_time_left%`
- `%mintcamps_level%`

Расширение регистрируется самим плагином; отдельная загрузка через eCloud не требуется.

## Файлы настроек

- `config.yml` — лимиты, топливо, защита, телепорт, голограммы и ID иконок ItemsAdder.
- `styles.yml` — названия и материалы семи биомных стилей.
- `messages.yml` — вся локализация, GUI и строки TextDisplay с поддержкой `&#HEX`.
- `upgrade-costs.yml` — полные ItemStack-цены трёх уровней.
- `item-names.yml` — серверные русские названия ресурсов. В GUI любой ванильный предмет дополнительно использует официальный клиентский translation key, поэтому новые материалы Minecraft тоже локализуются.
- `camps.yml` — активные лагеря, снимки блоков, схроны, таймеры и доверенные игроки. Редактировать вручную при работающем сервере нельзя.

В `/townycamps edit` выберите уровень, перенесите предметы в верхние 45 слотов и нажмите «Сохранить». Сохраняются количество, компоненты, NBT, зачарования и данные ItemsAdder. Пустая цена требует повторного подтверждения.

## Защита и производительность

TextDisplay создаётся один на лагерь и обновляется раз в секунду только в загруженном чанке. Купол также проверяет только загруженные лагеря. Враждебные мобы внутри удаляются святым пламенем; моб снаружи не может выбрать целью или ударить игрока внутри. Взрывы, огонь, жидкости и поршни не изменяют защищённую территорию.

Towny подключается через публичный API без жёсткой зависимости. По умолчанию лагерь разрешён только в Wilderness; размещение в своём городе можно включить в `settings.placement.towny`.

## Сборка из исходников

```bash
mvn clean package
```

Нужны JDK 25 и Maven 3.9+. Готовый файл появится в `target/NeverLandTownyCamps-0.1.4.jar`.
