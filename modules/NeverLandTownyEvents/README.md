# NeverLandTownyEvents 0.4.10

Городские события для **Paper/Purpur/Folia 26.2**, **Towny 0.103.2.0** и **Java 25**.

Автор: **Александр Соколов**  
Проект: **NeverLand**

Набеги теперь зависят от завершённых зданий города и их уровней. Сложность и состав волн сохраняются при начале рейда; остановка, перезагрузка и рестарт не пересчитывают текущий рейд. Настройки, установка и проверка: [развитие города и набеги](../../docs/RAID-DEVELOPMENT-0.4.10-RU.md).

## Реализованные события

- **Эпидемия** — ослабляет жителей; Священный Храм, Великая Библиотека, Небесный оррерий и идеология «Здравоохранение» снижают тяжесть.
- **Засуха** — замедляет рост культур; Мировое древо, Великий канал и профильные здания защищают поля.
- **Городской пожар** — создаёт безопасный для построек кризис; Великий канал и Мировое древо помогают тушению.
- **Набег разбойников** — создаёт ограниченные волны мобов без разрушения блоков и фарма дропа; Терракотовая армия и Колосс усиливают оборону.
- **Городской фестиваль** — даёт жителям полезные эффекты; Хрустальный дворец становится главным центром подготовки.

## Общая механика

У каждого события есть длительность, общая городская цель, список принимаемых предметов и очки за каждый предмет. Цель масштабируется по числу жителей. Защита от построек и идеологий:

1. снижает силу отрицательного игрового эффекта;
2. уменьшает здоровье и урон врагов набега;
3. добавляет до `+50%` от итоговой защиты к очкам каждого вклада.

Защита ограничивается индивидуальным `mitigation-cap` события. Все коэффициенты находятся в `events.yml`.

## Команды

| Команда | Назначение | Право |
|---|---|---|
| `/t events` | Открыть меню события и вкладов | `mintevents.use` |
| `/t events contribute` | Открыть меню вкладов | `mintevents.contribute` |
| `/t events history` | История событий города | `mintevents.use` |
| `/t events start <id> <город>` | Принудительно запустить событие | `mintevents.admin` |
| `/t events stop <город> [success\|fail]` | Завершить событие | `mintevents.admin` |
| `/t events list` | Список активных событий | `mintevents.admin` |
| `/t events raidwave <город>` | Немедленно создать тестовую волну активного набега | `mintevents.admin` |
| `/t events reload` | Перезагрузить конфигурацию | `mintevents.admin` |

Из консоли те же административные действия выполняются через `/townyevents`.

## Интеграция развития города

Для силы нового набега завершённые уровни читаются через публичный API `NeverLandTownyBuilds`; отключённое производство не уменьшает развитие. При недоступном API запускается обычный набег. Совместимость проверена с Builds 0.8.34, обновлять его для этой функции не требуется. Существующая защита от зданий продолжает использовать свои источники данных и учитывать работоспособность зданий.

Для идеологий поддерживаются два способа:

- чтение `MintTownyIdeologies/town-data.yml` по путям из `config.yml`;
- регистрация `TownDevelopmentProvider` через Bukkit `ServicesManager`. Этот способ имеет приоритет и подходит для будущей прямой интеграции.

## API

`MintTownyEventsApi` регистрируется в Bukkit `ServicesManager`. Другие плагины могут узнать активное событие, защиту города и безопасно добавить очки прогресса.

## Установка

1. Установите Towny 0.103.2.0 и экономический плагин, необходимый Towny.
2. Поместите `NeverLandTownyEvents-0.4.8.jar` в `plugins`.
3. Полностью перезапустите Paper/Purpur/Folia 26.2. Не используйте PlugMan.
4. Проверьте коэффициенты, длительность и ресурсы в `events.yml`.

ItemsAdder и PlaceholderAPI необязательны. Активные события, прогресс и история сохраняются в `events-data.yml` и переживают перезапуск.

## Исправление названия 0.4.8

При запуске и `/townyevents reload` старые отображаемые имена `MintEvents` и `MintTownyEvents` автоматически заменяются на `NeverLand • События` в сохранённом `messages.yml`, в том числе в списках и вложенных строках. Сохраняются цвета, пользовательский текст, команды, права и плейсхолдеры. Повторная загрузка не меняет уже исправленные сообщения.

Остановите сервер, замените предыдущий JAR Events на `NeverLandTownyEvents-0.4.8.jar` и запустите сервер. Папку конфигурации и данные событий сохраняйте. Это отдельное исправление модуля Events для Suite 0.41.0.
