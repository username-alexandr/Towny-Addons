# NeverLandTownyContracts 0.1.2

Доска городских заказов и совместных заданий для **Paper/Purpur 26.2**, **Towny 0.103.2.0**, **NeverLandTownyBuilds 0.1.0** и **Java 25**.

Автор: **Александр Соколов**  
Проект: **NeverLand**

## Механика

- Мэр или заместитель выбирает шаблон на доске `/t contracts`.
- Полная награда сразу снимается из казны и резервируется плагином.
- Все жители совместно выполняют цель.
- В заказах `DELIVERY` предметы физически перемещаются из инвентаря игрока в существующий склад `/t inv`.
- В заданиях `MOB_KILL`, `BLOCK_BREAK` и `FISH` прогресс учитывается автоматически.
- После выполнения резерв распределяется между участниками пропорционально их вкладу.
- При истечении срока или отмене оплачивается выполненная доля, остаток возвращается в казну.
- Неудавшиеся выплаты сохраняются и доступны через `/t contracts claim`.

## Безопасность склада

Плагин работает с живым хранилищем `NeverLandTownyBuilds`, поэтому отдельного склада-дубля нет. Если GUI `/t inv` открыт, доставка временно блокируется, чтобы закрытие старого окна не перезаписало новые предметы. При нехватке места принимается только реально вместившееся количество.

## Команды

| Команда | Назначение |
|---|---|
| `/t contracts` | Доска активных и доступных заказов |
| `/t contracts start <шаблон>` | Опубликовать заказ |
| `/t contracts cancel <ID>` | Закрыть заказ с частичным расчётом |
| `/t contracts claim` | Получить отложенную выплату |
| `/t contracts history` | История города |
| `/townycontracts start <шаблон> <город>` | Административный запуск |
| `/townycontracts cancel <ID> <город>` | Административная отмена |
| `/townycontracts list` | Все активные заказы |
| `/townycontracts reload` | Перезагрузка конфигурации |

## Права

- `mintcontracts.use` — просмотр доски;
- `mintcontracts.contribute` — внесение ресурсов;
- `mintcontracts.manage` — публикация и отмена, дополнительно проверяется роль Towny;
- `mintcontracts.admin` — административные команды.

## PlaceholderAPI

- `%mintcontracts_active_count%`
- `%mintcontracts_pending_reward%`
- `%mintcontracts_town%`
- `%mintcontracts_total_progress%`

## Конфигурация

- `contracts.yml` — тип, цель, предмет/моб/блок, количество, награда, срок и слот каждого шаблона;
- `config.yml` — лимиты, частичные выплаты, ранги управляющих, склад и GUI;
- `messages.yml` — русская локализация;
- `contract-data.yml` — активные заказы, вклады, резерв, история и отложенные выплаты.

Для ItemsAdder-предмета укажите `target: "itemsadder:namespace:id"`. Без ItemsAdder используются ванильные предметы.

## Установка

1. Установите Towny 0.103.2.0, экономику Towny и `NeverLandTownyBuilds 0.1.0`.
2. Поместите JAR в папку `plugins`.
3. Полностью перезапустите сервер.
4. Откройте `/t contracts` и опубликуйте тестовый заказ.

Не используйте PlugMan и аналогичные перезагрузчики.
