# NeverLandTownySeasons

Отдельный аддон сезонной экономики Towny. Собственный календарь, тики мира или чтение RealisticSeasons; сезонный выпуск стратегических ресурсов и веса городских событий.

Игрокам: `/t seasons`. Администраторам: `/tseasons help`.

[Установка, настройки, API и ограничения](../../docs/UPDATE_0.33.0_RU.md).
