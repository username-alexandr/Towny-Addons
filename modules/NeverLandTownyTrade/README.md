# NeverLandTownyTrade 0.1.3

Торговые договоры, караваны, транзитные пошлины и экспорт для **Paper/Purpur 26.2**, **Towny 0.103.2.0**, **NeverLandTownyBuilds 0.1.0** и **Java 25**.

Автор: **Александр Соколов**  
Проект: **NeverLand**

## Как работает торговля

1. У обоих городов должен быть построен Рынок в `NeverLandTownyBuilds`.
2. Мэр или заместитель экспортёра создаёт предложение: `/t trade propose <город> <экспорт>`.
3. Город-получатель принимает предложение на доске `/t trade` или командой `/t trade accept <ID>`.
4. Товар атомарно снимается с живого склада экспортёра `/t inv`, а полная цена и пошлины резервируются из казны покупателя.
5. Караван идёт между точками появления городов. Активные лагеря `NeverLandTownyCamps`, принадлежащие жителям этих городов и расположенные рядом с маршрутом, становятся перевалочными пунктами.
6. После прибытия весь груз помещается в `/t inv` покупателя. Цена поступает в казну экспортёра, транзитные пошлины — городам, по территории которых прошёл маршрут.

Если склад получателя заполнен или открыт, караван безопасно ожидает. Визуальный странствующий торговец с ламами появляется только рядом с игроками и только в уже загруженных чанках.

## Команды

| Команда | Назначение |
|---|---|
| `/t trade` | Открыть торговую доску |
| `/t trade propose <город> <экспорт>` | Предложить поставку |
| `/t trade accept <ID>` | Принять договор |
| `/t trade reject <ID>` | Отклонить входящий договор |
| `/t trade cancel <ID>` | Отменить исходящее предложение |
| `/t trade tariff <процент>` | Установить транзитную пошлину |
| `/t trade history` | История торговли |
| `/townytrade list` | Список активных караванов |
| `/townytrade complete <ID>` | Принудительно доставить караван |
| `/townytrade cancel <ID>` | Аварийно вернуть груз и резерв |
| `/townytrade reload` | Перезагрузить конфигурацию |

## Файлы

- `exports.yml` — товар, размер партии, цена, иконка и описание;
- `config.yml` — лимиты Рынка, скорость, задержки, лагеря, пошлины и визуализация;
- `messages.yml` — русская локализация;
- `trade-data.yml` — предложения, караваны, маршруты, пошлины, история и отложенные выплаты.

Для ItemsAdder-предмета используйте `item: "itemsadder:namespace:id"`. `NeverLandTownyCamps`, ItemsAdder и PlaceholderAPI необязательны; без лагерей маршрут строится напрямую.

## Установка

1. Установите Towny 0.103.2.0, экономику Towny и `NeverLandTownyBuilds 0.1.0`.
2. При необходимости установите `NeverLandTownyCamps 0.1.4`.
3. Поместите JAR в `plugins` и полностью перезапустите сервер.
4. Постройте Рынок минимум I уровня в двух тестовых городах.

Не используйте PlugMan и другие горячие перезагрузчики.
