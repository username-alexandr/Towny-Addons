# NeverLandTownyChronicles 0.1.3

Автоматическая история городов для Paper/Purpur 26.2 и Towny 0.103.2.0.

Плагин сохраняет основания, переименования и исчезновения городов, смены мэров и наций, завоевания, войны SiegeWar, Чудеса Света `NeverLandTownyBuilds` и достижения по населению, территории, казне и возрасту.

## Команды

- `/t chronicles` и `/t history` — GUI летописи;
- `/t chronicles book` — книга-летопись;
- `/t chronicles stats` — статистика;
- `/t chronicles <категория>` — фильтр;
- `/townychronicles add <город> <категория> <текст>` — ручная запись;
- `/townychronicles remove <ID>` — удалить запись;
- `/townychronicles rescan` — сверить города;
- `/townychronicles reload` — перезагрузить настройки.
