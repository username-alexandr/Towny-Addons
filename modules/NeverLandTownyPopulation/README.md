# NeverLandTownyPopulation 0.1.0

Население городов Towny: рост, жильё, довольство, безработица, еда и вода.

Требует Towny и NeverLandTownyBuilds. Меню: `/t population`.

[Установка и настройка](../../docs/UPDATE_0.7.9_RU.md).

Сборка и проверки: `gradle --no-daemon clean jar smokeTest` на Java 25.
