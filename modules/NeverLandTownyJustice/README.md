# NeverLandTownyJustice

Отдельный суд города: штрафы с добровольной оплатой, публичный розыск, нативные тюрьмы Towny и заранее обеспеченные награды. `/t justice`, `/justice help`.

[Установка, команды, permissions, API и восстановление](../../docs/UPDATE_0.30.0_RU.md).

Сборка и все исполняемые проверки: `python scripts/build_suite.py NeverLandTownyJustice` (параметры см. `--help`). Денежные операции и сохранения выполняются в серверном потоке, pending не повторяются без подтверждения банка. Удалять финансовый журнал при существующих обязательствах нельзя.
