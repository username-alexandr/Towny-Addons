# NeverLandTownySieges+ 0.1.0

Оборонительные постройки Builds ограничивают атакующих во время боевых сессий SiegeWar. Установка: Towny, Builds и SiegeWar **3.6.2**; Army и Diplomacy подключаются при наличии. Без SiegeWar доступен обзор построек, осадные ограничения не включаются. В ZIP комплекта входят аддоны NeverLand; SiegeWar устанавливается отдельно.

Открыть меню: `/sieges`, `/sieges menu [город]`, `/t sieges`. Диагностика: `/sieges status`; настройки: `/sieges reload` (permission `neverlandtownysiegesplus.admin`).

Правила, API, ограничения и сведения о проверке: [обновление 0.32.0](../../docs/UPDATE_0.32.0_RU.md).
