# NeverLandTownyExpeditions 0.1.5

Аддон экспедиций для Paper/Purpur 26.2, Towny 0.103.2.0 и NeverLandTownyCamps 0.1.6.

## Возможности

- шесть настраиваемых экспедиций трёх типов: руины, кораблекрушения и аномалии;
- старт только из собственного активного лагеря;
- списание припасов из живого схрона NeverLandTownyCamps;
- группа из владельца и доверенных игроков рядом с лагерем;
- асинхронный поиск дикой территории и загрузка чанка;
- процедурные временные объекты с сохранением BlockData и содержимого контейнеров;
- точное восстановление участка после успеха, провала или отмены;
- общие цели, боевые волны, таймер и BossBar;
- после старта участникам показываются мир и координаты цели — автоматической телепортации к событию нет;
- эндермены и другие мобы удерживаются внутри зоны экспедиции;
- точки появления проверяются на опору, свободное пространство и безопасную высоту;
- мобы события защищены от падения, пустоты, удушья и утопления, а случайно погибшие без зачтённого убийства появляются повторно;
- сохранение активных экспедиций, прогресса, истории и невостребованных наград;
- ItemsAdder-предметы в ценах и наградах через `itemsadder:namespace:id`.
- город с построенным Небесным оррерием получает настраиваемые 25% дополнительного времени на выполнение экспедиции; Builds остаётся необязательной зависимостью.

## Команды

- `/t expeditions` — доска экспедиций;
- `/t expeditions start <id>` — начать экспедицию;
- `/t expeditions status`, `/t expeditions return`, `/t expeditions claim`, `/t expeditions history`;
- `/townyexpeditions list|complete|cancel|reload` — администрирование.

Команда `/expedition` сохранена как прямая запасная форма.

Установите JAR вместе с Towny 0.103.2.0 и NeverLandTownyCamps 0.1.6, затем полностью перезапустите сервер.
